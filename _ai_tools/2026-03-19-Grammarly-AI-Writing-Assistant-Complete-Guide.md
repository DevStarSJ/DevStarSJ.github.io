## Core Features Explained

### 1. GrammarlyGO — AI Writing Partner

GrammarlyGO is Grammarly's generative AI that goes beyond correction:

**Generate from scratch:**
```
Prompt: "Write a professional email declining a meeting request 
but leaving the door open for future collaboration"
```

**Improve existing text:**
```
Your draft: "Hey, need you to look at this report by Friday ok?"
GrammarlyGO result: "Hi [Name], Could you review the attached report 
by end of day Friday? Your input would be greatly appreciated. 
Please let me know if you have any questions or need additional context."
```

**Continue your writing:**
Start a document and use GrammarlyGO to continue in your established voice and style.

**Adjust length:**
- Shorten: "Make this email 30% shorter while keeping all key points"
- Expand: "Elaborate on the third point with two supporting examples"

### 2. Real-Time Suggestions

As you type, Grammarly provides layered feedback:

**Correctness (Red):**
- Grammar errors
- Spelling mistakes
- Punctuation issues

**Clarity (Blue):**
- Overly complex sentences
- Unclear pronoun references
- Wordy phrases (e.g., "due to the fact that" → "because")

**Engagement (Green):**
- Overused words
- Passive voice overuse
- Repetitive sentence structure

**Delivery (Purple):**
- Tone mismatches for context
- Potentially offensive language
- Formality level suggestions

### 3. Tone Detector

This feature is underrated. Grammarly reads your current tone and shows:

- Confident / Uncertain
- Formal / Informal
- Direct / Diplomatic
- Friendly / Professional

**Why it matters:** A message that reads as "aggressive" to you might read as "confident" to the recipient. Grammarly's tone analysis helps you calibrate.

**Example:**
```
Draft: "I need the report now. This is already late."

Tone detected: Direct, Urgent, Slightly Terse

Suggestion: Consider softening with context: 
"The report is now overdue — could you send it over today? 
It's needed for the [meeting] review."
```

## Tips to Get More From Grammarly

### Set Up a Personal Writing Style

In Settings → Profile → Define:
- Your primary audience (general, expert, technical)
- Writing domain (business, academic, casual)
- Formality preference

This calibrates suggestions to your actual use case.

### Use the "Goals" Feature

Before writing, set goals for each document:
- **Audience:** General/Expert/Technical
- **Formality:** Informal/Neutral/Formal
- **Domain:** Business/Academic/Email/Creative
- **Intent:** Inform/Describe/Convince/Tell a story

Grammarly prioritizes suggestions to match these goals.

### Weekly Writing Stats

Grammarly's weekly email shows:
- Words checked
- Accuracy vs. other users
- Common mistake patterns
- Vocabulary diversity score

Use this to identify your personal writing weaknesses.

### Learn From Each Correction

Don't just accept suggestions — read the explanations. Grammarly explains *why* something is wrong, which helps you write better over time without the crutch.

## Limitations

- **Over-suggests formality:** Sometimes marks informal-but-appropriate writing as needing changes
- **Context misses:** Doesn't always understand technical jargon or niche industry language
- **Privacy:** All text goes to Grammarly servers (enterprise has private processing)
- **Creative writing:** Rules-based suggestions can work against intentional stylistic choices
