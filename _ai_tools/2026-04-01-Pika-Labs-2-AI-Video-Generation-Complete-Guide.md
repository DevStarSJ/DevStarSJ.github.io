## What is Pika Labs 2.0?

## Getting Started with Pika 2.0

### Step 1: Access Pika
1. Visit [pika.art](https://pika.art)
2. Sign in with Google or Discord
3. Start with 250 free credits (monthly refresh)

### Step 2: Create Your First Video

**Text-to-Video:**
1. Click **"Create"**
2. Select **"Text to Video"**
3. Type your prompt
4. Choose aspect ratio (16:9, 9:16, 1:1)
5. Select duration (3, 5, 10, or 15 seconds)
6. Choose motion intensity (Low, Medium, High)

**Image-to-Video:**
1. Click **"Create"**
2. Select **"Image to Video"**
3. Upload your reference image
4. Add a motion description: "camera slowly zooms in"
5. Adjust motion strength
6. Generate

### Step 3: Refine Your Results
If the first result isn't perfect:
- Add more details to your prompt
- Try different motion settings
- Use "Modify Region" to fix specific areas
- Generate multiple variations and pick the best

## Prompt Engineering for Pika 2.0

### The Formula
```
[Subject] + [Action] + [Setting] + [Style] + [Technical details]
```

**Example:**
```
[A chef] [tosses pasta in a pan with dramatic flames] 
[in a rustic Italian kitchen] [cinematic, warm lighting] 
[slow motion, 120fps, shallow depth of field]
```

### Style Keywords That Work Well

**Cinematic Styles:**
- `cinematic`, `film grain`, `IMAX`, `anamorphic lens`
- `golden hour`, `blue hour`, `magic hour`
- `bokeh`, `shallow depth of field`, `lens flare`

**Animation Styles:**
- `anime style`, `Pixar style`, `Studio Ghibli aesthetic`
- `claymation`, `stop motion`, `2D cartoon`

**Photography Styles:**
- `drone footage`, `GoPro style`, `timelapse`
- `macro lens`, `fisheye lens`, `tilt-shift`

**Mood/Atmosphere:**
- `dramatic`, `ethereal`, `mysterious`, `vibrant`
- `nostalgic`, `futuristic`, `vintage film`

### Common Mistakes to Avoid

❌ **Too vague**: "a video of nature"  
✅ **Specific**: "aerial drone shot of a misty forest at dawn, rays of sunlight through trees"

❌ **Too many elements**: "a cat and a dog and a bird flying and a city and rain"  
✅ **Focused**: "a tabby cat sitting on a rainy windowsill watching the storm outside"

❌ **Contradictory**: "fast and slow motion cinematic IMAX 4K 8K HDR"  
✅ **Clean**: "slow motion, cinematic, 4K"

## Tips for Professional Results

### 1. Start with a Reference Image
Instead of text-only, provide a reference image for better control over the final look.

### 2. Use Motion Presets
Save time with Pika's built-in motion presets for common movements:
- "Orbit" for product videos
- "Dolly in" for dramatic reveals
- "Pan across" for landscape shots

### 3. Batch Generate
Generate 4-6 variations simultaneously, then pick the best one.

### 4. Extend Strategically
Generate a 5-second video, then extend to 10, then to 15. Each extension maintains better coherence than a single 15-second generation.

### 5. Combine with Other Tools
- **Pika** → Generate base video
- **Adobe Premiere** → Add music, captions
- **ElevenLabs** → Add voiceover
- **CapCut** → Quick social media edits

## API Access for Developers

Pika offers a developer API for integrating video generation into applications:

```python
import requests

API_KEY = "your-pika-api-key"

def generate_video(prompt, duration=5, aspect_ratio="16:9"):
    response = requests.post(
        "https://api.pika.art/v2/generate",
        headers={"Authorization": f"Bearer {API_KEY}"},
        json={
            "prompt": prompt,
            "duration": duration,
            "aspectRatio": aspect_ratio,
            "motionStrength": "medium",
            "resolution": "1080p"
        }
    )
    return response.json()

video = generate_video(
    "A coffee cup steaming on a wooden table, morning sunlight",
    duration=5
)
print(f"Video URL: {video['url']}")
```
