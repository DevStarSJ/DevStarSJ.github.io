## Understanding Prompts

### Basic Structure
```
[Subject] [Style] [Mood] [Technical specs]
```

**Good prompt example:**
```
A futuristic cityscape at dusk, neon lights reflecting on wet streets, 
cyberpunk aesthetic, cinematic lighting, ultra-detailed, 8K resolution
```

### Key Parameters

| Parameter | Effect | Example |
|-----------|--------|---------|
| `--ar` | Aspect ratio | `--ar 16:9` |
| `--v 7` | Model version | `--v 7` |
| `--q` | Quality (0.25–2) | `--q 2` |
| `--chaos` | Variation level | `--chaos 50` |
| `--style raw` | Less stylized | `--style raw` |
| `--weird` | Abstract creativity | `--weird 500` |

## V7 Exclusive Features

### 🎨 Personalization
After rating 200+ images, Midjourney builds a personal style profile. Add `--p` to any prompt to apply your learned preferences. Your results start skewing toward what you've historically liked.

### ⚡ Draft Mode
Use `--draft` to generate quick previews at 10x speed and lower cost. Perfect for:
- Exploring concepts before committing
- Testing prompts at scale
- Quick client mood boards

### 👤 Character Reference (--cref)
Keep a character consistent across multiple images:
```
A fantasy warrior in a forest --cref [character image URL] --cw 100
```
`--cw` controls how strictly the character reference is followed (0-100).

### 🖼️ Style Reference (--sref)
Apply the visual style of a reference image to new prompts:
```
A mountain landscape at sunrise --sref [style image URL]
```

## Prompting Tips That Actually Work

### Be Specific About Artists/Styles
Instead of "painterly style," try: `in the style of Edward Hopper` or `baroque oil painting style`

### Use Lighting Descriptors
- `golden hour lighting` — Warm, soft outdoor light
- `Rembrandt lighting` — Dramatic shadows with key light
- `volumetric fog` — Atmospheric depth
- `neon rim lighting` — Cyberpunk, vivid edge glow

### Camera Language
- `shot on 35mm film` — Film grain aesthetic
- `f/1.4 bokeh` — Shallow depth of field
- `aerial view` — Bird's eye perspective
- `macro photography` — Extreme close-up

### Negative Prompting
Add `--no [things to exclude]` at the end:
```
Forest scene with deer --no cars, humans, text, watermark
```

## Common Mistakes to Avoid

❌ **Vague prompts** — "A nice scene" gives average results; specificity wins
❌ **Too many concepts** — Focus on 1-2 main ideas per image
❌ **Ignoring aspect ratio** — Always set `--ar` for your intended use
❌ **Skipping variations** — Always use V (vary) and U (upscale) to explore options
❌ **Not upscaling** — Upscaled images have dramatically more detail
