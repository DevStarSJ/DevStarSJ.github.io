## What Is Bardeen?

Bardeen is a **browser extension + AI automation platform** that combines:
- **Browser automation** — control web pages like a robot
- **AI-powered scraping** — extract structured data from any website
- **Integration hub** — connect 100+ apps (Salesforce, HubSpot, Notion, Slack, etc.)
- **AI Magic Actions** — describe workflows in natural language and they're built for you

It's the intersection of browser automation (like Selenium), workflow automation (like Zapier), and AI-powered data extraction — in one tool you control from a browser extension.

## Core Concepts

### Playbooks
Playbooks are Bardeen's automation workflows — sequences of actions that run automatically. They can:
- Trigger on a schedule, a shortcut key, or when you visit a specific URL
- Scrape data from web pages
- Create records in CRM/database tools
- Send messages or emails
- Process data with AI

### Scraper Templates
Pre-built scrapers for popular sites (LinkedIn, GitHub, Twitter, Amazon, Google Search, etc.). Extract structured data from these sites without writing code.

### AI Magic Actions
Describe a task in natural language, and Bardeen's AI builds the automation:
> *"When I'm on a LinkedIn profile, save their name, job title, company, and email to my HubSpot CRM as a new contact"*

Bardeen generates the workflow automatically.

## Getting Started

### Installation
1. Install the **Bardeen Chrome extension** from the Chrome Web Store
2. Create a free account at bardeen.ai
3. Click the Bardeen icon in your browser to open the dashboard

### Building Your First Playbook

**Option A: Use AI Builder**
1. Click "New Playbook" → "AI Builder"
2. Describe your workflow: *"Scrape the job listings from this page and add them to my Notion database"*
3. Bardeen generates the workflow
4. Review and activate

**Option B: Use a Template**
1. Browse the **Playbook Library** (1,000+ pre-built automations)
2. Find one matching your use case
3. Connect your apps
4. Customize and run

**Option C: Build Manually**
1. Click "New Playbook" → "Build"
2. Add trigger (shortcut, schedule, URL visit)
3. Add actions from the library
4. Configure each action
5. Test and save

## Advanced Tips

### Use AI Summarization in Workflows
When scraping company pages, add an "AI Summarize" action to compress the information into a one-line description for your CRM notes field. This saves reading time downstream.

### Chain Playbooks
Complex workflows can be split into smaller playbooks that trigger each other. This makes them easier to debug and maintain.

### Use Shortcuts for On-Demand Automations
Set up keyboard shortcuts (e.g., `Cmd+Shift+B`) for your most-used automations. When you're on a LinkedIn profile, one keypress saves the contact to CRM and queues outreach.

### Monitor With Automation Logs
Always check the **Automation Logs** panel to see what ran, what succeeded, and what failed. This is essential for debugging and trust.

### Start With Templates
Don't build from scratch. Bardeen has 1,000+ templates. Find the closest one, customize it, and you'll be running in minutes.

## Privacy & Ethics Note

Bardeen is powerful — use it responsibly:
- **Respect robots.txt** — don't scrape sites that explicitly prohibit it
- **Rate limit** your automations — don't hammer servers
- **GDPR compliance** — if collecting personal data, ensure proper legal basis
- **LinkedIn ToS** — LinkedIn limits automation; use respectfully to avoid account suspension
- **Data storage** — be mindful of where extracted data is stored
