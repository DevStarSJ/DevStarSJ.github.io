## Linear AI Features

### 🤖 AI Issue Creation

Describe a bug or feature in plain English. Linear AI will:
- Write a clear, structured issue title
- Draft a detailed description with context
- Suggest the appropriate **team, project, and priority**
- Add relevant **labels** automatically
- Link to related issues it finds in your backlog

What used to take 5 minutes of careful writing now takes 30 seconds.

### 📋 AI Sub-Issue Generation

Give Linear a large feature or epic. AI will break it down into:
- Actionable sub-tasks with reasonable scope
- Clear acceptance criteria for each
- Logical sequencing and dependencies

Great for sprint planning — turn a product spec into a full task breakdown instantly.

### 🔍 AI Triage

For teams with high bug volume, Linear AI can:
- Auto-classify incoming issues by type (bug/feature/improvement)
- Detect duplicate issues before they're filed
- Suggest priority based on severity language
- Route issues to the right team automatically

### 📊 Project Progress & Forecasting

Linear AI analyzes your team's velocity and provides:
- **Completion forecasts** with confidence ranges
- **Scope creep detection** when new issues are added mid-cycle
- **Blockers identification** — issues waiting too long for review
- **Burndown predictions** for upcoming milestones

### ✍️ AI Writing Assistant

Anywhere text appears in Linear — issue descriptions, comments, project updates — the AI assistant can:
- Improve clarity and structure
- Translate technical jargon for non-technical stakeholders
- Summarize long discussion threads
- Write status update summaries for weekly reports

## Key Workflows for Engineering Teams

### Sprint Planning with AI

1. Create an Epic with a product spec
2. Use "Generate sub-issues" — Linear AI breaks it into stories
3. Estimate using story points or time
4. Drag issues into the current Cycle (Linear's term for sprint)
5. AI forecasts whether the scope is achievable

### Bug Triage Automation

Connect your error monitoring (Sentry, Datadog) to Linear. When a new error fires:
1. Webhook creates a Linear issue automatically
2. AI classifies severity and suggests priority
3. Duplicate detection prevents clutter
4. Issue is routed to the on-call engineer

### GitHub Integration Flow

Link a Linear issue to a PR. When the PR is merged:
1. Issue status automatically moves to "Done"
2. Git commit references appear in the timeline
3. Release notes can be auto-generated from merged issues
