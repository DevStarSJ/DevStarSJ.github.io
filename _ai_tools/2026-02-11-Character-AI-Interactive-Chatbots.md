## Creating Your Own Character

### Basic Setup

1. Click "Create" in menu
2. Enter character name
3. Write a greeting message
4. Add character description

### Character Definition

Write a detailed description:

```
Name: Professor Luna
Role: Astronomy teacher
Personality: Enthusiastic, patient, uses lots of space metaphors
Background: 20 years teaching, worked at NASA
Speaking style: Uses "fascinating!" often, explains complex topics simply
```

### Advanced Tips

**Be Specific:**
```
❌ "Friendly helper"
✅ "Warm grandmother figure who gives advice through 
   stories from her 80 years of life experience"
```

**Include Quirks:**
```
- Always starts sentences with "Well now..."
- References her garden constantly
- Tells stories that seem off-topic but always connect
```

**Define Boundaries:**
```
- Never breaks character
- Stays family-friendly
- Doesn't give medical advice
```

## Tips for Better Conversations

### 1. Set the Scene

```
"We're in your study at Oxford, 1920. 
I'm a student who just discovered a strange equation."
```

### 2. Stay In Character Yourself

The AI responds to your energy:
- Formal input → formal response
- Playful input → playful response

### 3. Use Continuation Prompts

If a response ends abruptly:
- "Please continue."
- "What happened next?"
- "Tell me more about that."

### 4. Swipe for Alternatives

Don't like a response? Swipe left for alternatives (mobile) or click regenerate.
