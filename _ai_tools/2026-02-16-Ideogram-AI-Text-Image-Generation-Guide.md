**Key Rules:**

- Add context for placement

## Tips for Perfect Results

### 1. Keep Text Short

**Works Well:**
- Single words: "LOVE", "DREAM"
- Short phrases: "STAY COOL", "NEW YORK"
- Names: "EMMA", "COFFEE CO"

**Struggles:**
- Long sentences
- Paragraphs
- Multiple text blocks

### 2. Describe Typography

Be specific about font characteristics:
- **Serif/Sans-serif**
- **Bold/Light weight**
- **Uppercase/Lowercase**
- **Spacing and alignment**

### 3. Multiple Attempts

Text accuracy varies:
- Generate multiple versions
- Select best text rendering
- Use variations feature
- Regenerate with tweaks

### 4. Style Consistency

Match text to image style:
```
Rustic sign → Hand-painted letters
Tech logo → Clean geometric font
Vintage poster → Period-appropriate typography
```

## Common Issues

### Misspelled Text

**Solutions:**
- Regenerate (it varies)
- Simplify the text
- Use shorter words
- Try different phrasing

### Wrong Font Style

**Solutions:**
- Be more explicit about typography
- Reference specific eras or styles
- Describe letterforms in detail

### Text Placement Issues

**Solutions:**
- Specify exact position
- Use terms like "centered", "bottom third"
- Describe background clearly
