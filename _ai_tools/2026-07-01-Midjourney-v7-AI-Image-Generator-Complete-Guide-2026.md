## Prompt Crafting 101

The quality of your output depends heavily on your prompts. Here's a framework that consistently produces great results:

```
/imagine [subject] [style] [lighting] [mood] [technical specs]
```

**Example:**
```
/imagine A serene Japanese tea garden at dusk, 
soft golden hour lighting, mist rising from the water, 
Studio Ghibli style, 8K, ultra detailed, cinematic --ar 16:9 --v 7
```

### Key Parameters

| Parameter | Usage | Example |
|---|---|---|
| `--ar` | Aspect ratio | `--ar 16:9`, `--ar 1:1` |
| `--v` | Version | `--v 7` |
| `--style raw` | Less opinionated | More photographic |
| `--cref` | Character reference | Use existing character |
| `--sref` | Style reference | Apply visual style |
| `--chaos` | Variation (0-100) | Higher = more varied |
| `--quality` | Detail level (0.25-2) | Higher = more detail |

## Tips for Getting Professional Results

1. **Reference artists**: Include artistic references like "in the style of Edward Hopper" or "like a Pixar concept painting"

2. **Lighting is everything**: Specify lighting precisely — "dramatic side lighting," "soft diffused light," "golden hour"

3. **Use negative prompts**: Add `--no blurry, low quality, watermark` to avoid common issues

4. **Iterate with variations**: Use the V1-V4 buttons to explore variations of a good result

5. **Use `--cref` for consistency**: If you need the same character across multiple images, use character reference URLs

6. **Study the community**: The Midjourney Discord and web gallery are goldmines of prompt inspiration
