## What is Taskade AI?

Taskade is an **AI-native productivity platform** that goes beyond traditional project management. At its core:

- **AI Agents**: Custom AI assistants that can research, write, plan, and execute tasks
- **Project Management**: Tasks, projects, and workflows with real-time collaboration

Unlike tools like Notion or Asana that bolt AI on as an afterthought, Taskade was built from the ground up with AI as the central component.

## Key Features

### 1. AI Agents — The Killer Feature
Taskade's AI Agents are custom AI assistants you can create, train, and deploy for specific tasks:

**Pre-built agent templates:**
- **Research Agent**: Summarize web content, find facts, compile reports
- **Writing Agent**: Draft emails, blog posts, meeting notes
- **Code Agent**: Review code, explain functions, suggest improvements
- **Data Agent**: Analyze spreadsheets, create charts, find patterns
- **Project Manager Agent**: Break down goals into tasks, estimate timelines

**Creating a custom agent:**
```
1. Go to "Agents" → "Create Agent"
2. Name your agent (e.g., "Content Strategy Agent")
3. Write the system prompt:
   "You are an expert content strategist specializing in B2B SaaS. 
    Help create content calendars, SEO strategies, and blog outlines.
    Always consider the target audience: technical developers and product managers."
4. Add knowledge sources (upload docs, URLs, or Taskade projects)
5. Deploy → Your agent is ready to chat
```

## Getting Started with Taskade

### Step 1: Create Your Workspace
1. Visit [taskade.com](https://taskade.com)
2. Sign up with Google or email
3. Create a Workspace (your organization or personal space)
4. Invite team members

### Step 2: Create Your First Project
```
Option 1: Manual
- Click "+" → "New Project"
- Choose a template or start blank
- Add tasks by typing

Option 2: AI Generate
- Click "+" → "New Project"
- Choose "Generate with AI"
- Describe your project:
  "Plan a 3-month product launch for a mobile app. 
   Include marketing, development milestones, and beta testing phases."
- Taskade creates a complete project structure
```

### Step 3: Set Up an AI Agent
1. Click "Agents" in the sidebar
2. Choose a pre-built template or create custom
3. Add your knowledge sources
4. Start chatting with your agent

### Step 4: Automate Repetitive Tasks
1. Go to "Automations"
2. Create a trigger: "When task is completed..."
3. Set an action: "AI generates a summary and sends to Slack"
4. Activate the automation
