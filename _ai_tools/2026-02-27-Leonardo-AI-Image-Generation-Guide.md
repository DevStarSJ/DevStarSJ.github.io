## Advanced Features Deep Dive

### ControlNet — Precision Composition Control

ControlNet lets you guide composition using reference images:

**Depth Control**: Maintain 3D spatial relationships from a reference  
**Edge Control**: Follow the exact outlines of a reference image  
**Pose Control**: Match human body poses to a reference  
**Character Reference**: Maintain consistent character appearance across images

This is especially powerful for **character sheet creation** — generate consistent characters from multiple angles.

### Image-to-Image Generation

Upload any image and transform it:
1. Upload your base image
2. Set the **strength** (0.3 = subtle changes, 0.9 = radical transformation)
3. Describe what you want to add/change
4. Generate variations while preserving the core composition

**Use cases:**
- Transform sketches into polished art
- Apply a consistent style to product photos
- Generate variations of existing artwork
- Upscale and enhance old images

### Real-Time Canvas

Leonardo's standout feature for concept artists:
1. Open Real-Time Canvas
2. Sketch rough shapes
3. Watch AI generate as you draw — with sub-second updates
4. Refine, iterate, and lock elements you want to keep

This workflow bridges the gap between human creativity and AI generation.

### Motion AI (Video Generation)

Turn any static image into a short video clip:
- 2-4 second animations
- Subtle environmental motion (wind, water, fire)
- Character expression changes
- Camera movement simulation

## Tips for Better Results

### Use Negative Prompts
Tell the AI what to avoid:
```
Negative: blurry, low quality, distorted faces, extra limbs, 
watermark, text, bad anatomy, ugly, duplicate
```

### Master the Aspect Ratio
Match your output to its intended use:
- **1:1** — Social media profile/post
- **16:9** — YouTube thumbnails, banners
- **9:16** — Instagram/TikTok Stories
- **3:4** — Print and portrait photography

### Guidance Scale Sweet Spots

| Guidance Scale | Effect |
|----------------|--------|
| 3-5 | More creative, less prompt-accurate |
| 7-9 | Balanced (recommended for most cases) |
| 12-15 | Very literal interpretation |

### Use Model Fine-Tunes

Train a custom LoRA (Low-Rank Adaptation) on your own images:
1. Upload 10-30 high-quality images
2. Set trigger word and training steps
3. Use in any generation prompt for consistent style
