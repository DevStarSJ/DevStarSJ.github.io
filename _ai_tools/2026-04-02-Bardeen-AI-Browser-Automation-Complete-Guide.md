**Bardeen** is an AI-powered browser automation tool that runs as a Chrome extension, letting you automate repetitive web tasks without writing code. While Zapier automates between APIs and Make handles complex workflows, Bardeen uniquely specializes in **automating actions within the browser itself** — clicking, scraping, form-filling, data extraction, and more.

## What is Bardeen?

Bardeen is a **browser automation platform** that combines:

- **Playbooks**: Pre-built or custom automation workflows
- **Scraper**: Extract data from any website
- **AI Magic Actions**: Use AI to process, transform, and categorize data
- **Integrations**: Connect data to 70+ tools (CRM, Google Sheets, Notion, Slack, etc.)
- **Background automation**: Run automations even when your browser is closed

Think of Bardeen as a "smart macro recorder" for the web — but powered by AI that can understand context, not just record clicks.

## Core Features

### 1. Playbooks — Automation Workflows
Playbooks are Bardeen's automation sequences — the equivalent of workflows in Zapier.

**Structure of a Playbook:**
```
Trigger → Actions → Outputs

Example:
Trigger: I click a LinkedIn profile
Actions: 
  1. Scrape: name, title, company, email
  2. AI Magic: Classify company size, write personalized message
  3. Save to Salesforce contact
  4. Add task: "Follow up in 3 days"
Output: LinkedIn prospect → Salesforce CRM in one click
```

**Where Playbooks run:**
- **On-demand**: Click to run manually
- **Scheduled**: Run at set times
- **Background**: Run when a condition is met
- **Triggered**: Activated by visiting specific URLs or pages

### 2. Scraper — No-Code Web Data Extraction
Bardeen's Scraper lets you extract structured data from any website:

**How it works:**
1. Navigate to any web page

**Data types it handles:**

- Infinite scroll content

**Output destinations:**
- Google Sheets

- Any connected integration

**Practical scraping examples:**
```
LinkedIn profiles → Prospect database
Google Maps listings → Sales leads
Amazon reviews → Competitor analysis

E-commerce prices → Competitive pricing

```

### 3. AI Magic Actions
This is where Bardeen differentiates from simple automation tools. AI Magic Actions use GPT-4 or Claude to process data intelligently:

**AI Magic Actions include:**

| Action | What it does |
|--------|-------------|
| Classify | Categorize items into your defined categories |
| Extract | Pull specific info from unstructured text |
| Summarize | Condense long content into key points |
| Write | Generate content based on context |
| Translate | Convert text to another language |
| Score | Rate or rank items based on criteria |
| Research | Look up additional info about a person/company |

**Example workflow using AI Magic:**
```
Scrape 50 LinkedIn profiles
→ AI Magic: Extract company size, funding stage, tech stack from bios
→ AI Magic: Score each lead 1-10 based on ICP criteria
→ AI Magic: Write personalized outreach message for each
→ Push top 20 leads to HubSpot
→ Create draft emails in Gmail
```

What would take a sales rep 8-10 hours manually takes Bardeen 20-30 minutes automatically.

1. Navigate to any website (e.g., a LinkedIn search results page)
2. Click Bardeen extension → "Scraper"
3. Click elements on the page to define what to extract
4. Preview extracted data
5. Choose output: Google Sheets, Airtable, etc.
6. Run

### Step 4: Add AI Magic
1. In your playbook, add an AI Magic action
2. Choose action type: Classify, Extract, Write, etc.
3. Define the prompt:
   ```
   "Based on the company description, classify the company size as:
   - Startup (1-50 employees)
   - SMB (51-500 employees)  
   - Enterprise (500+ employees)
   Only return the category name."
   ```
4. Map input and output fields
5. Test and deploy

## Privacy & Legal Considerations

**Important**: Web scraping can violate Terms of Service on some platforms.

**Safe to scrape:**
- Your own data/accounts
- Public business directories
- News sites and publicly available content
- APIs with explicit scraping permissions

**Check ToS before scraping:**
- LinkedIn (has strict anti-scraping policies)
- Social media platforms
- E-commerce platforms
- Any site with authentication

**Best practices:**
- Rate limit your scraping (don't hammer sites)
- Respect robots.txt
- Don't scrape personal data without consent (GDPR compliance)
- Use for professional/business information, not personal data
