## What Is Midjourney?

Midjourney is a text-to-image AI model accessible via Discord (and now its own web interface). You type a description — called a **prompt** — and it generates four image variations in under a minute.

It's known for producing images with exceptional aesthetic quality, strong artistic sensibility, and beautiful lighting — qualities that have made it the preferred tool of professional creatives who want AI assistance without sacrificing visual excellence.

## What's New in V7?

V7 brought significant upgrades over V6.1:

### 🎨 Dramatically Better Photorealism
V7 produces images that are often indistinguishable from studio photography. Skin texture, hair detail, fabric folds, and environmental lighting have all been improved substantially.

### 🧠 Stronger Prompt Understanding
V7 follows complex, multi-part prompts more faithfully. You can specify intricate scene compositions, moods, camera angles, and stylistic references and expect them to actually appear in the output.

### 👤 Consistent Characters (Draft Mode)
A major V7 feature: **Character References** allow you to maintain a consistent character across multiple images — crucial for storyboards, comics, and brand mascots.

### 🖼️ Native Web Interface
V7 coincided with a much-improved web UI at [midjourney.com](https://midjourney.com), reducing dependence on Discord for casual users.

### 🎭 Personalization
Midjourney can now learn your aesthetic preferences over time, adjusting its default outputs to match what you tend to upscale and use.

## How to Use Midjourney

### Getting Started
1. Go to [midjourney.com](https://midjourney.com) and sign up
2. Subscribe to a plan (no free tier in 2026)
3. Use the web interface or join the Discord server
4. Type `/imagine` followed by your prompt

### Writing Prompts

Basic structure:
```
/imagine [subject] [environment] [mood/lighting] [style] [camera/technical]
```

Example:
```
/imagine a lone astronaut standing on a red sand dune at golden hour, 
cinematic lighting, ultra-detailed, 8K, shot on Hasselblad --ar 16:9 --v 7
```

### Key Parameters

| Parameter | Effect | Example |
|-----------|--------|---------|
| `--ar 16:9` | Aspect ratio | `--ar 1:1`, `--ar 9:16` |
| `--v 7` | Use V7 model | (default in 2026) |
| `--stylize 750` | Aesthetic intensity (0-1000) | Higher = more artistic |
| `--chaos 20` | Variation level | Higher = more diverse |
| `--no` | Negative prompt | `--no text, watermark` |
| `--cref [url]` | Character reference | Maintain character consistency |
| `--sref [url]` | Style reference | Match a reference image's style |

### Upscaling
After generation, click **U1-U4** to upscale your favorite variant to full resolution. V7 upscales add fine detail rather than just enlarging.

## Limitations

- **No free tier** — Midjourney requires a subscription, making it less accessible for casual exploration
- **Text rendering** — Still imperfect at embedding readable text in images (though V7 improved it)
- **Hands and anatomy** — Better in V7 but complex poses can still produce anatomical oddities
- **Limited editing** — No inpainting/outpainting in the web UI yet; mostly generation-focused
- **Discord dependency** — Power users still prefer Discord for advanced community features
