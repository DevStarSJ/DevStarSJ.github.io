# Sider AI: The All-in-One AI Browser Assistant for Every Task

![Browser Extension](https://images.unsplash.com/photo-1551650975-87deedd944c3?w=800)
*Photo by [Sigmund](https://unsplash.com/@sigmund) on Unsplash*

Sider AI is a browser extension that integrates multiple AI models—including ChatGPT, Claude, and Gemini—directly into your browsing experience. With over 4 million users, it's become one of the most popular ways to access AI assistance without switching between tabs.

## What is Sider AI?

Sider (short for "Sidebar") places a powerful AI assistant alongside any webpage you're viewing. Instead of copy-pasting text to ChatGPT, Sider lets you:

- Summarize articles instantly
- Translate content in real-time
- Generate replies to emails
- Explain complex topics
- Research while browsing
- Write and rewrite text

All without leaving your current page.

### Key Advantages

- **Context-aware**: AI sees what you're reading
- **Multi-model**: Access GPT-4, Claude, Gemini, and more
- **Instant access**: Always one click away
- **No tab switching**: Work stays in flow

## Getting Started

### Installation

1. Visit [sider.ai](https://sider.ai) or Chrome Web Store
2. Click "Add to Chrome" (also available for Edge, Firefox)
3. Create account or sign in
4. Pin extension to toolbar for quick access

### Basic Usage

**Opening Sider:**
- Click the Sider icon in toolbar
- Use keyboard shortcut (Cmd/Ctrl + P)
- Right-click and select "Ask Sider"

**Quick Actions:**
1. Select text on any webpage
2. Sider popup appears automatically
3. Choose action (summarize, translate, etc.)
4. View result in sidebar or popup

### Customization

Configure Sider to match your workflow:
- **Default model**: Choose your preferred AI
- **Keyboard shortcuts**: Set custom hotkeys
- **Appearance**: Light/dark mode, sidebar position
- **Auto-actions**: Set default behaviors for text selection

## Tips for Best Results

### 1. Be Specific
Instead of "summarize this," try:
> "Summarize this article in 3 bullet points focusing on the main argument and supporting evidence"

### 2. Use the Right Model
- **Quick queries**: GPT-4o or Gemini
- **Long documents**: Claude (200K context)
- **Current events**: Gemini with web access
- **Coding**: GPT-4 or Claude

### 3. Leverage Page Context
Sider works best when you reference the current page:
> "Based on this article, what are the implications for [topic]?"

### 4. Build Your Prompt Library
Save prompts you use frequently:
- "Translate to Korean, maintain formal tone"
- "Explain like I'm a beginner in this field"
- "Generate 5 tweet-length summaries"

## Common Issues

### "Sider isn't seeing my page"
- Ensure extension has permission for the site
- Try refreshing the page
- Check if site blocks extensions

### "Slow responses"
- Try a faster model (GPT-4o vs GPT-4)
- Check query complexity
- Verify internet connection

### "Limited features on some sites"
- Some sites (banking, etc.) block extensions
- Use screenshot/copy for these cases
