## Mastering Midjourney Prompts

### Basic Prompt Structure
```
[subject], [setting/environment], [mood/atmosphere], [style], [technical parameters]
```

**Example:**
```
a Japanese tea ceremony, misty mountain background, peaceful and serene, 
watercolor painting style, soft muted colors --ar 16:9 --v 7
```

### Essential Parameters

**`--ar` (Aspect Ratio)**
```
--ar 1:1    → Square (social media)
--ar 16:9   → Widescreen (desktop, YouTube)
--ar 9:16   → Portrait (Instagram stories, mobile)
--ar 4:3    → Traditional photo
```

**`--v` (Version)**
```
--v 7   → Latest (best quality, default in 2026)
--v 6   → Previous version (sometimes preferred for certain styles)
```

**`--s` (Stylize, 0-1000)**
Controls how "artistic" vs literal the interpretation is:
```
--s 0    → Very literal, less artistic
--s 100  → Default balance
--s 750  → Highly stylized, artistic
```

**`--chaos` (0-100)**
Controls variation in results:
```
--chaos 0   → Consistent, predictable
--chaos 50  → Moderate variation
--chaos 100 → Wild, unpredictable results
```

**`--no` (Negative prompting)**
```
--no text, watermark, blurry, ugly
```

### Advanced Techniques

**Style References (`--sref`)**
Reference an existing image to guide the visual style:
```
a futuristic cityscape --sref [image_url] --sw 100
```

**Character References (`--cref`)**
Keep a character consistent across multiple images (V7 feature):
```
[character_description] --cref [reference_image_url]
```

**Personalization (`--p`)**
After training your profile with likes/dislikes, add `--p` to any prompt and Midjourney tailors results to your aesthetic.

**Multi-Prompts (`::`)**
Give different weights to different parts of your prompt:
```
forest::2 fog::1 ancient ruins::3
```
This prioritizes "ancient ruins" most, then "forest", then "fog."

## Tips for Better Results

**Be specific about lighting:** "golden hour lighting," "studio three-point lighting," "overcast natural light" — lighting dramatically changes the feel.

**Mention camera/lens if photorealistic:** "shot on Leica M10," "85mm portrait lens," "medium format film" signals the kind of photo you want.

**Reference art styles:** "in the style of Art Nouveau," "impressionist painting," "Studio Ghibli aesthetic" give strong directional guidance.

**Iterate, don't restart:** Use V buttons to vary what's working rather than reprompting from scratch.

**Save prompts that work:** Keep a personal prompt library. When you find a formula that works for your use case, save it.
