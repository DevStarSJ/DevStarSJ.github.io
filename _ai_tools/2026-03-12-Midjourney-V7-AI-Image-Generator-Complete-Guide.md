## Key Features

### 1. Photorealistic Quality
Midjourney V7 produces images with accurate lighting, realistic textures, and natural depth of field. Architecture, portraits, product shots, and food photography all look professional-grade.

### 2. Artistic Styles
V7 handles an extraordinary range of styles:
- Oil painting, watercolor, pencil sketch
- Anime and manga
- 3D render, isometric design
- Film photography, Polaroid, vintage
- Abstract and surrealist art

### 3. Personalization (New in V7)
Rate ~200 generated images to create a personal "profile" — Midjourney learns your aesthetic preferences and biases future generations toward your style automatically using `--p` flag.

### 4. Draft Mode
Use `--draft` to generate 4 variants in seconds at lower resolution. Iterate quickly, then upscale only your favorite.

### 5. Style Reference (`--sref`)
Provide reference images and V7 matches their visual style, color palette, and mood — essential for brand consistency.

## How to Use Midjourney V7

### Getting Started
1. Visit [midjourney.com](https://midjourney.com) and sign in (Discord or Google)
2. Navigate to **Create** in the web interface
3. Type your prompt in the text box

### Prompt Tips

**Basic prompt:**
```
A golden retriever puppy playing in autumn leaves, soft sunlight, bokeh background
```

**Advanced prompt with parameters:**
```
Cinematic portrait of a jazz musician on stage, dramatic lighting, 
film grain, shallow depth of field --v 7 --ar 16:9 --style raw
```

**Key parameters:**
| Parameter | Usage | Example |
|---|---|---|
| `--v 7` | Use V7 model | `--v 7` |
| `--ar` | Aspect ratio | `--ar 16:9` |
| `--style raw` | Less stylized, more realistic | `--style raw` |
| `--q 2` | Higher quality (slower) | `--q 2` |
| `--no` | Exclude elements | `--no text, logos` |
| `--draft` | Fast draft mode | `--draft` |
