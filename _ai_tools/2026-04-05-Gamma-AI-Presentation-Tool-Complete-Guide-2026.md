## What Is Gamma AI?

Gamma is an AI-powered presentation and document tool that generates structured, beautifully designed content from simple text prompts. Unlike PowerPoint or Google Slides, Gamma:

- Generates complete decks from a single prompt
- Applies professional design automatically
- Creates responsive layouts that work on any screen
- Lets you embed interactive content (videos, forms, charts)
- Enables one-click sharing via link (no exports needed)

It's used by product managers, marketers, educators, founders, and consultants who need to communicate ideas quickly and professionally.

## Getting Started

### Sign Up & First Presentation

1. Visit [gamma.app](https://gamma.app) and sign up (free tier available)
2. Click **"New"** → **"Generate"**
3. Type your topic or paste an outline
4. Choose a theme and card count (slides)
5. Click **"Generate"** — wait ~10 seconds
6. Edit, customize, and share

That's it. Your first AI-generated deck in under a minute.

### Three Generation Modes

**From a prompt:**
```
Create a 10-slide pitch deck for a B2B SaaS tool that helps 
remote teams manage async communication.
Include: problem, solution, market size, demo, pricing, roadmap.
```

**From an outline:**
Paste an existing outline or document — Gamma converts it into structured slides while preserving your hierarchy and key points.

**From a file:**
Upload a Word doc, PDF, or PowerPoint and Gamma will restructure it with fresh design.

## Core Features

### 1. AI Card Generation

Each "card" in Gamma is a flexible canvas rather than a rigid slide. Cards can contain:

- Text (headers, body, bullets)
- Images (AI-generated or uploaded)
- Videos (YouTube embeds, Loom)
- Charts and tables
- Code blocks
- Interactive polls and forms
- Web embeds (Figma, Notion, GitHub)

The AI populates each card with appropriate content based on your prompt, then you can refine.

### 2. Theme System

Gamma's theme engine handles:

- **Color palettes:** 30+ curated options, custom hex codes
- **Typography:** Pairing of heading and body fonts
- **Layout patterns:** Varied card layouts per presentation
- **Imagery style:** Consistent visual language throughout

One click on "Retheme" regenerates the entire visual design while keeping your content intact.

### 3. AI Rewrite & Edit

Within any card, select text and the AI can:

- **Expand:** Add more detail and examples
- **Condense:** Tighten verbose content
- **Rephrase:** Change tone (formal, casual, persuasive)
- **Translate:** Convert to another language
- **Fix grammar:** Clean up drafts

### 4. Presenter Mode

Gamma includes a presentation mode with:

- Full-screen display
- Speaker notes (AI-generated or manual)
- Laser pointer simulation
- Remote control via phone

## Advanced Customization

### Custom Brand Kit

Gamma Pro allows importing your brand:

1. Go to **Settings** → **Brand**
2. Upload your logo
3. Add brand colors (hex codes)
4. Select preferred fonts (Google Fonts supported)
5. Save as default theme

All future presentations start with your brand applied automatically.

### Custom Layouts

For cards where you need specific control:

- Drag-and-drop element positioning
- Grid layouts (2-col, 3-col, asymmetric)
- Full-bleed image backgrounds
- Split layouts (text left, image right)

### AI Image Generation

Within any card, click **"AI Image"** to generate:

```
Prompt: "Abstract visualization of neural network connections, 
dark blue and purple, minimalist, suitable for tech presentation"
```

Images are generated on-demand and automatically styled to match your theme.

## Sharing & Collaboration

### Link Sharing

Unlike traditional presentations, Gamma's output is a web URL:

- No downloads or file attachments
- Always shows the latest version
- Works on any device without software
- Track views and engagement analytics

**Share settings:**
- **Public:** Anyone with link can view
- **Private:** Only invited collaborators
- **Password-protected:** Optional access control
- **Embed:** Paste anywhere (Notion, Confluence, websites)

### Real-Time Collaboration

Multiple editors can work simultaneously:

- See collaborator cursors in real time
- Comment on specific cards
- Assign tasks and revisions
- Version history with rollback

### Export Options

When you need traditional formats:

- **PDF:** Print-quality export
- **PowerPoint:** Editable PPTX for clients requiring it
- **PNG:** Individual slide exports

## Tips for Better Results

### Prompt Engineering for Gamma

**Be specific about structure:**
```
❌ "Make a presentation about climate change"
✅ "Create a 12-card presentation on climate tech solutions:
   - 2 cards: problem overview with statistics
   - 5 cards: solution categories (solar, wind, carbon capture, EVs, grid storage)
   - 2 cards: investment trends and market opportunity
   - 2 cards: key challenges
   - 1 card: call to action"
```

**Specify audience:**
```
"Presentation for C-suite executives (non-technical).
Focus on business impact and ROI, not technical details."
```

**Set tone:**
```
"Professional but conversational tone.
Use data visualizations where possible.
Avoid jargon."
```
