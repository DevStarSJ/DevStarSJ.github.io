매달 말이 되면 "돈이 어디 갔지?"라는 생각이 든다면, **제로베이스 예산법(Zero-Based Budgeting, ZBB)**이 당신의 재정을 바꿀 시스템이 될 수 있습니다. 기존의 지출 추적 방식과 달리, ZBB는 **월초에 수입의 모든 원 하나하나에 용도를 미리 지정**하는 방법입니다.

목표: 수입 - 지출 = **0원**. 다 써버린다는 뜻이 아니라, 모든 돈에 역할이 있다는 의미입니다.

## 핵심 원칙: 모든 돈에 역할을 준다

월 소득이 500만 원이라면, 500만 원 전부를 — 월세, 식비, 저축, 투자, 부채 상환, 여가비 등으로 — 배분합니다. 어디론가 사라지는 "나머지 돈"이 없습니다.

이는 기존 방식과 완전히 다릅니다:
- **한도 설정식 예산**: 식비를 40만 원으로 잡는다. (결과: 60만 원 쓴다.)
- **사후 추적식 예산**: 지출을 기록하고 죄책감을 느낀다. 아무것도 바뀌지 않는다.
- **예산 없음**: 그냥 잘 되길 바란다.

ZBB는 의도성을 강제합니다. 모든 지출 항목이 우연이 아닌 의식적인 결정이 됩니다.

## 제로베이스 예산법 실행 방법

### 1단계: 수입 파악
세후 **실수령 월급**을 기준으로 합니다. 수입이 불규칙하다면, 예상되는 최소 월 수입을 기준으로 삼으세요.

### 2단계: 모든 지출 항목 작성

**고정 지출** (매달 동일):
- 월세/주택담보대출
- 자동차 할부
- 보험료
- 구독 서비스

**변동 필수 지출**:
- 식료품
- 교통비/주유비
- 공과금
- 의료비

**재정 목표** (고정비처럼 취급!):
- 비상금 적립
- 퇴직연금/IRP 납입
- 대출 추가 상환
- 싱킹 펀드 (자동차 수리, 여행, 경조사)

**생활/여가**:
- 외식
- 엔터테인먼트
- 의류
- 취미

### 3단계: 합산이 0이 될 때까지 배분

모든 항목에 금액을 배정해 나갑니다:
```
수입 (500만 원) - 모든 배정 금액 합계 = 0원
```

배분 후 남는 돈이 있다면, **그것도 문제**입니다 — 그 돈에도 역할을 주세요 (추가 대출 상환? 여행 저축? 투자 증액?).

마이너스가 된다면, 항목들을 줄여서 균형을 맞추세요.

### 4단계: 한 달 내내 추적하기

지출할 때마다 해당 항목에서 빼나갑니다. 항목 예산이 0이 되면 — 그 항목은 더 이상 지출하지 않습니다.

이를 자동으로 도와주는 앱:
- **YNAB (You Need A Budget)** — ZBB의 표준 앱
- **뱅크샐러드** — 국내 은행 연동 자동 분류
- **카카오뱅크 가계부** — 간편한 입문용

## 월 500만 원 제로베이스 예산 예시

| 항목 | 금액 |
|---|---|
| 월세/주거비 | 80만 원 |
| 공과금/통신비 | 15만 원 |
| 식료품 | 30만 원 |
| 교통비 | 15만 원 |
| 보험료 | 15만 원 |
| 구독 서비스 | 5만 원 |
| 비상금 적립 | 30만 원 |
| 연금/IRP | 50만 원 |
| 대출 추가 상환 | 30만 원 |
| 자동차 수리 적립 | 10만 원 |
| 외식비 | 20만 원 |
| 엔터테인먼트 | 10만 원 |
| 의류 | 10만 원 |
| 경조사/선물 | 10만 원 |
| 여행 저축 | 30만 원 |
| 기타/여유 | 30만 원 |
| **합계** | **500만 원** |

저축과 투자가 **가장 먼저** 배정됩니다. 남는 돈이 아닙니다.

## ZBB가 다른 예산법보다 효과적인 이유

### 1. 숨겨진 지출을 드러낸다
처음 ZBB를 작성하는 대부분의 사람들이 놀랍니다. "저축 30만 원이 너무 많아"가 "배달 앱에 60만 원을 쓰고 있었구나"로 바뀝니다.

### 2. 라이프스타일 인플레이션을 막는다
모든 돈을 배정해야 하므로 충동구매와 구독 누적이 즉시 눈에 보입니다.

### 3. 돈이 가치관과 일치하게 된다
취미에 40만 원을 쓰기로 결정했다면, 그건 낭비가 아니라 의도입니다. ZBB는 임의적 규칙이 아닌 *당신의* 우선순위로 항목을 판단합니다.

### 4. 싱킹 펀드로 긴급 부채를 방지한다
자동차 수리비, 의료비, 연간 청구서를 미리 적립해두면 카드 대출에 의존할 일이 없습니다.

## 이번 달부터 시작하기

1. **지금 당장 월 실수령액을 적으세요**
2. **모든 지출 항목 작성** — 지난 3개월 카드/통장 명세서 확인
3. **금액 배정** — 필수 지출 먼저, 그다음 재정 목표, 마지막에 여가
4. **가계부 앱 설치** — 수동 추적이 ZBB를 습관으로 만드는 핵심
5. **매주 10분 점검** — 항목 간 금액 조정 및 재균형

첫 예산이 완벽할 필요는 없습니다. 목표는 돈이 어디로 갔는지 의아해하는 대신, 의식적으로 결정하는 연습을 하는 것입니다.

모든 돈에 역할을 주세요. 재정 생활이 달라집니다.
