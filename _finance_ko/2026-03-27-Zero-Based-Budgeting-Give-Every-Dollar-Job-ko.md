# 제로 기반 예산법: 모든 돈에 역할을 부여해 재정을 완전히 통제하라

대부분의 사람들은 이미 쓴 돈을 추적하는 방식으로 예산을 관리합니다. 제로 기반 예산법은 이 접근 방식을 뒤집습니다: 과거를 돌아보는 대신, **월초에 모든 돈을 미리 계획적으로 배분**합니다.

결과? 돈이 어디 갔는지 더 이상 의아해하지 않아도 됩니다 — 미리 결정했으니까요.

![예산 계획 노트](https://images.unsplash.com/photo-1554224155-6726b3ff858f?w=900&auto=format&fit=crop)

## 제로 기반 예산법이란?

**제로 기반 예산법(ZBB)**은 수입에서 계획한 지출을 뺀 결과가 0이 되도록 하는 방식입니다.

```
수입 − (지출 + 저축 + 투자) = 0원
```

이것은 모든 돈을 써버린다는 의미가 아닙니다. 저축과 투자를 포함해 모든 돈에 *목적이 부여된다*는 의미입니다. 배분되지 않은 돈 = 낭비되는 돈, 이를 없애는 것입니다.

---

## 제로 기반 예산법이 효과적인 이유

전통적인 예산이 실패하는 이유:
- 한 번 만들고 무시함
- 계획에 없던 돈이 충동적으로 지출됨
- "남은 돈"이 저축 목표에 도달하지 못함

ZBB가 효과적인 이유:
✅ 모든 돈에 대한 의도적인 결정 강제
✅ 초과 지출을 즉시 명확하게 파악
✅ 실제 우선순위와 지출의 일치
✅ 달마다 재정 인식 구축

ZBB 원칙으로 예산을 관리하는 사람들은 느슨한 방식을 사용하는 사람들보다 **연간 18~20% 더 많이** 저축한다는 연구 결과가 있습니다.

---

## 단계별: 제로 기반 예산 만드는 법

### 1단계: 월 수입 계산

**모든** 수입원을 포함하세요:
- 급여 (세금 공제 후 실수령액)
- 프리랜서/부업 수입
- 임대 수입
- 배당금 또는 투자 수입
- 기타 신뢰할 수 있는 수입

보수적으로 계산하세요. 수입이 변동적이라면 지난 6개월 중 가장 낮은 달을 기준으로 하세요.

### 2단계: 모든 지출 나열

지출하는 모든 것을 분류하세요:

**고정 지출** (매달 동일한 금액):
- 월세/주택담보대출
- 자동차 할부
- 보험료
- 대출 상환금
- 구독료

**변동 필수 지출** (금액이 변동):
- 식료품
- 공과금
- 교통비/기름값
- 의료비

**재량 지출**:
- 외식
- 엔터테인먼트
- 쇼핑/의류
- 취미

**재정 목표**:
- 비상금
- 퇴직연금 (IRP, 연금저축펀드)
- 투자 계좌
- 추가 부채 상환
- 휴가/적립식 자금

### 3단계: 모든 돈 배분

이제 0이 될 때까지 각 카테고리에 수입을 배분하세요.

**예시 예산 (월 순수령액 500만 원):**

| 카테고리 | 금액 |
|----------|------|
| 월세 | 700,000원 |
| 차량 + 보험 | 300,000원 |
| 식료품 | 300,000원 |
| 공과금 | 120,000원 |
| 교통비 | 100,000원 |
| 통신비 | 60,000원 |
| 구독료 | 30,000원 |
| 외식 | 200,000원 |
| 엔터테인먼트 | 100,000원 |
| 의류 | 80,000원 |
| 건강/미용 | 80,000원 |
| 비상금 | 300,000원 |
| 퇴직연금 | 500,000원 |
| 주식 투자 | 300,000원 |
| 여행 적립 | 200,000원 |
| 추가 부채 상환 | 330,000원 |
| 기타 버퍼 | 200,000원 |
| **합계** | **5,000,000원** |

모든 돈에 역할이 있습니다. 수입 − 모든 카테고리 = 0원.

### 4단계: 한 달 내내 추적

예산은 추적할 때만 의미가 있습니다. 도구 옵션:
- **뱅크샐러드, 토스 머니플랜** — 국내 가계부 앱
- **구글 시트 / 엑셀** — 무료 스프레드시트
- **YNAB (You Need A Budget)** — ZBB 전용 앱 (해외 서비스)
- **종이와 펜** — 아날로그지만 효과적

최소 주 2회 예산을 확인하세요. 한 카테고리에서 초과 지출하면 *다른 카테고리에서 옮겨와야 합니다*.

### 5단계: 매달 조정하고 반복

매달 상황이 다릅니다. 같은 숫자를 이월하지 말고 매달 새로 시작하세요. 현재 달의 수입과 예상 지출에 맞게 매번 모든 돈을 재배분하세요.

---

## 비정기 지출 처리법

ZBB에서 흔한 어려움: 매달 발생하지 않는 지출(자동차 검사, 명절 선물, 연간 구독료).

**해결책: 적립식 자금 (Sinking Funds)**

연간 지출을 12로 나눠 매달 그 금액을 예산에 포함하세요.

예시:
- 자동차 유지비: 연 60만 원 → 월 5만 원
- 명절 선물: 연 60만 원 → 월 5만 원
- 연간 구독: 연 24만 원 → 월 2만 원
- 여행: 연 180만 원 → 월 15만 원

지출이 발생하지 않는 달에도 매달 예산에 포함하세요. 이렇게 하면 "예산을 망치는 돌발 지출"이 없어집니다.

---

## 초과 지출 시 대처법

초과 지출은 반드시 발생합니다. ZBB의 힘은 그 대응 방식에 있습니다:

1. **인정하기** — 숨기거나 무시하지 마세요
2. **원인 파악** — 계획 없었나요? 긴급 상황? 충동?
3. **자금 이동** — 낮은 우선순위 카테고리에서 옮겨오세요
4. **다음 달 조정** — 예산이 부족했나요? 해당 카테고리를 늘리세요

목표는 완벽함이 아닙니다. 인식과 의도성입니다.

---

## 제로 기반 예산법 vs. 50/30/20 규칙

| | 제로 기반 | 50/30/20 |
|---|---|---|
| 유연성 | 높음 (맞춤 카테고리) | 낮음 (고정 비율) |
| 복잡성 | 높음 | 낮음 |
| 통제력 | 최대 | 보통 |
| 최적 대상 | 세부 지향적인 사람 | 예산 초보자 |
| 소요 시간 | 월 2~4시간 | 월 30분 |

ZBB는 더 많은 노력이 필요하지만 더 큰 통제력과 결과를 제공합니다.

---

## '기타 버퍼' 규칙

항상 ZBB에 **소액의 기타 버퍼** (수입의 1~3%)를 포함하세요. 이것은 진짜 돌발 상황에 대비합니다: 주차 딱지, 잊었던 친구 생일, 갑작스러운 커피 약속.

버퍼 없이는 작은 것들로 계속 예산이 깨지고 동기를 잃게 됩니다.

---

## 실제 결과: ZBB가 가져다 주는 것

6개월 이상 ZBB를 유지한 사용자들은 일관되게 보고합니다:
- **부채를 더 빨리 상환** — 여윳돈이 사라지지 않고 부채 상환에 쓰임
- **저축 증가** — 저축이 스스로에게 먼저 내는 '청구서'가 됨
- **불안 감소** — 돈이 어디 가는지 더 이상 의아해하지 않음
- **금전 다툼 감소** — 특히 커플이 공유 예산 투명성에서 혜택을 봄
- **목표 달성** — 여행 자금, 주택 계약금, 비상금 모두 더 빨리 마련

---

## 이번 주 바로 시작하기

1일을 기다릴 필요가 없습니다. 월 중간에 ZBB를 시작하세요:

1. 이번 달 남은 수입 계산
2. 남은 모든 돈을 배분
3. 다음 달부터 완전한 ZBB 시작
4. 월말에 검토하고 조정

가장 어려운 부분은 시작입니다. 두 번째 예산은 항상 첫 번째보다 쉽습니다.
