# 제로베이스 예산법: 모든 돈에 역할을 부여하라

많은 사람들이 이런 패턴을 반복합니다. 한 달 지출을 들여다보며 '이번엔 진짜 아껴야지' 다짐하지만, 다음 달도 비슷한 결과가 나옵니다.

**제로베이스 예산법(Zero-Based Budgeting)은 접근 방식 자체를 바꿉니다.** 돈을 쓰고 나서 기록하는 대신, 월초에 모든 돈의 쓰임새를 미리 결정합니다.

## 제로베이스 예산법이란?

한 달 수입에서 모든 지출과 저축을 빼면 **0원이 되도록** 계획하는 방법입니다.

모든 돈을 다 쓰라는 뜻이 아닙니다. 모든 돈에 목적을 부여하라는 뜻입니다. 저축, 투자, 부채 상환도 모두 지출 항목입니다.

**수입 - 모든 배분 = 0원**

핵심: 돈이 '어디론가 사라지는' 게 아니라, 내가 의도적으로 어디에 쓸지 결정하는 것입니다.

---

## 단계별 제로베이스 예산 만들기

### 1단계: 월 실수령액 파악

세후 실제 받는 금액을 기준으로 하세요.

수입이 불규칙하다면 최근 몇 달 중 **가장 적게 받은 달**을 기준으로 설정하세요. 추가 수입은 생길 때 배분하면 됩니다.

- 본업 실수령: 320만 원
- 부업 수입 (보수적): 30만 원
- **월 총 수입: 350만 원**

### 2단계: 모든 지출 항목 나열

**고정 지출** (매달 동일한 금액):

| 고정 지출 | 월 금액 |
|----------|--------|
| 월세 | 75만 원 |
| 자동차 할부 | 30만 원 |
| 보험료 | 15만 원 |
| 통신비 | 5만 원 |
| 인터넷 | 3만 원 |
| 구독 서비스 | 3만 원 |
| **소계** | **131만 원** |

**변동 지출** (매달 다르지만 예측 가능):

| 변동 지출 | 월 금액 |
|----------|--------|
| 식료품 | 30만 원 |
| 교통비 | 10만 원 |
| 외식 | 20만 원 |
| 여가/취미 | 10만 원 |
| 개인 용품 | 8만 원 |
| 의류 | 5만 원 |
| **소계** | **83만 원** |

### 3단계: 저축 및 재무 목표 배분

대부분의 예산에서 빠뜨리는 핵심 단계입니다. 저축도 지출 항목으로 먼저 배정하세요:

| 저축 / 목표 | 월 금액 |
|-----------|--------|
| 비상금 | 20만 원 |
| 연금/IRP | 30만 원 |
| 여행 적금 | 10만 원 |
| 자동차 수리 준비금 | 5만 원 |
| 추가 부채 상환 | 21만 원 |
| **소계** | **86만 원** |

### 4단계: 합계 확인

- 총 수입: 350만 원
- 고정 지출: 131만 원
- 변동 지출: 83만 원
- 저축/목표: 86만 원
- **배분 합계: 300만 원**

🤔 50만 원이 남았네요! 이 돈도 배분해야 합니다:
- 비상금 추가 적립: 20만 원
- 투자 (ETF 등): 20만 원
- 비정기 지출 준비금: 10만 원

**최종 잔액: 0원** ✅

## 싱킹펀드(Sinking Fund) 전략

제로베이스 예산의 강력한 기법: **비정기 지출을 위한 싱킹펀드**

자동차 보험 연갱신, 명절 선물, 가전제품 교체 — 이런 지출들은 갑작스럽게 느껴지지만 사실 예측 가능합니다. 미리 적립하면 됩니다.

**방법:** 연간 비용을 12로 나눠 매월 조금씩 저축

| 비정기 지출 | 연간 비용 | 월 적립액 |
|-----------|---------|---------|
| 자동차 보험 | 60만 원 | 5만 원 |
| 명절/연말 선물 | 50만 원 | 4만 원 |
| 연간 구독료 | 20만 원 | 1.7만 원 |
| 집 수리 | 100만 원 | 8.3만 원 |

## 활용 가능한 도구들

**앱:**
- **YNAB (You Need A Budget)** — 제로베이스 예산 전용 앱. 가장 체계적이지만 유료
- **뱅크샐러드** — 국내 앱. 자산 연동 + 지출 분석
- **토스 가계부** — 간편하게 시작하기 좋은 국내 앱

**스프레드시트:**
- 구글 시트로 직접 만들기. 자유도 높고 커스터마이징 가능
- 네이버 블로그나 유튜브에서 무료 제로베이스 예산 양식 검색

## 흔한 어려움과 해결책

**어려움: 수입이 일정하지 않음**
해결: 최소 수입 기준으로 예산 짜기. 추가 수입은 별도 적립 후 재배분

**어려움: 예상 못한 지출 발생**
해결: '기타 비정기 지출' 항목 5~10만 원 배정. 싱킹펀드 활용

**어려움: 중간에 예산 초과**
해결: 주 1회 점검 습관화. 2주차에 발견하면 나머지 2주 조정 가능

**어려움: 가족/파트너와 의견 충돌**
해결: 월초에 30분 '예산 회의' 정례화. 함께 만든 예산은 함께 지키게 됩니다

## 제로베이스 예산법이 효과적인 이유

1. **의도적 소비** — 카테고리별 배정액이 있으니 충동 구매가 자연스럽게 줄어듦
2. **돈 불안감 감소** — 모든 돈의 행방을 알고 있으면 마음이 편안해짐
3. **저축 자동화** — 저축을 첫 항목으로 배분하면 자연스럽게 '먼저 저축'이 실천됨
4. **소비 패턴 파악** — 몇 달 하다 보면 내가 실제로 어디에 돈을 쓰는지 정확히 보임

## 이번 달 바로 시작하기

완벽한 시스템을 갖추려다 시작을 못하지 마세요:

1. **오늘**: 이번 달 수입과 주요 지출 5개 항목 작성
2. **이번 주**: 모든 고정 지출 + 변동 지출 예상값 추가
3. **다음 주**: 저축/목표 항목 추가하고 합계 맞추기
4. **월말**: 실제 지출 vs 계획 비교 후 다음 달 조정

완벽하지 않아도 됩니다. 꾸준히 하는 것이 핵심입니다.
