대부분의 사람들은 예산을 만들고는 무시합니다. 제로베이스 예산법(ZBB)은 다릅니다. 월이 시작되기 전에 모든 돈에 목적을 부여하는 방법입니다. 결과적으로 돈이 "사라지지" 않고, 지출이 실제 우선순위와 일치하게 됩니다.

## 제로베이스 예산법이란?

제로베이스 예산법은 **수입에서 모든 할당된 지출을 뺐을 때 0이 되도록** 매달 계획하는 방식입니다.

모든 돈을 다 써버린다는 뜻이 아닙니다. 모든 돈이 카테고리에 배정된다는 의미입니다. 저축, 투자, 비상금 포함해서요. 어디에 쓰이는지 모르는 돈이 없어집니다.

**공식:**
> 수입 − (지출 + 저축 + 부채 상환) = 0원

## 일반 예산법과의 차이

대부분의 사람들은 뒤를 보며 예산을 세웁니다. "지난달에 얼마 썼더라? 비슷하게 쓰자."

ZBB는 매달 처음부터 시작합니다:
- 모든 지출은 **정당화**되어야 합니다
- 자동 이월은 없습니다
- 돈을 쓰기 **전에** 각 항목을 의식적으로 결정합니다

이 반응적 → 선제적 전환이 이 시스템의 핵심 힘입니다.

## 제로베이스 예산 설정: 단계별 가이드

### 1단계: 월 수입 계산
모든 안정적인 수입원 포함:
- 세후 급여
- 프리랜서/부업 수입
- 임대 수입
- 기타 정기 수입

수입이 불규칙하다면 **최근 가장 낮은 달**을 기준으로 하세요. 예상치 못한 수입은 저축이나 부채 상환에 사용하고 계획에 포함하지 마세요.

### 2단계: 모든 지출 목록 작성

**고정 지출** (매달 동일한 금액):
- 월세/주택 담보대출
- 자동차 할부
- 보험료
- 구독 서비스
- 대출 최소 상환금

**변동 지출** (매달 변하는 금액 — 직접 결정):
- 식비
- 외식비
- 문화/여가
- 주유비
- 의류
- 개인 관리비

**비정기 지출** (분기/연간 — 12로 나눠 매달 적립):
- 자동차 세금/검사
- 연간 구독
- 명절/생일 선물
- 의료/치과 비용

### 3단계: 재무 목표를 항목으로 포함
여기서 ZBB의 진짜 힘이 나옵니다. 저축과 목표를 고정 지출처럼 처리하세요:
- 비상금 적립
- 연금/퇴직 저축
- 여행 적금
- 내 집 마련 준비금
- 부채 추가 상환

### 4단계: 합계를 0으로 맞추기
모든 항목을 더하세요. 수입 − 모든 카테고리 = 양수라면, 아직 배정되지 않은 돈이 있는 겁니다. 그 돈에 역할을 주세요:
- 더 많은 부채 상환
- 비상금 추가 적립
- 퇴직 저축 늘리기
- 여행 적금에 추가

음수라면, 목표가 달성될 때까지 재량 항목을 줄이세요.

### 예산 예시 (월 수입: 450만원)

| 카테고리 | 예산 |
|---|---|
| 월세 | 70만원 |
| 공과금 | 8만원 |
| 식비 | 30만원 |
| 외식비 | 10만원 |
| 교통비 | 20만원 |
| 문화/여가 | 10만원 |
| 개인 관리 | 5만원 |
| 의류 | 5만원 |
| 구독 서비스 | 5만원 |
| 비상금 | 20만원 |
| 연금저축 | 30만원 |
| 부채 추가 상환 | 30만원 |
| 여행 적금 | 10만원 |
| 예비비 | 10만원 |
| 비정기 지출 | 10만원 |
| **합계** | **273만원** |

※ 나머지는 투자/추가 저축으로 배정하여 총 0으로 맞추세요.

## "예비비" 항목: 안전 밸브

수입의 1~5% 정도의 소소한 예비비를 포함하세요. 삶은 절대 완벽한 계획대로 돌아가지 않습니다. 이 예비비가 전체 예산을 무너뜨리지 않고 작은 돌발 상황을 처리해 줍니다.

사용하지 않으면 월말에 저축으로 넘기세요. 같은 용도로 계속 사용한다면 별도 항목으로 만드세요.

## 월 중 추적하기

ZBB는 추적해야 작동합니다.

**앱:**
- **YNAB (You Need a Budget)** — ZBB 전용으로 설계됨, 월 $14.99
- **뱅크샐러드** — 국내 앱, 계좌 연동 지출 분석
- **토스** — 간단한 지출 분석, 자동 카테고리 분류

**스프레드시트:**
- 구글 시트 또는 엑셀 — 무료, 완전 커스터마이즈 가능
- "제로베이스 예산 템플릿"으로 검색하면 무료 양식 있음

**봉투 시스템:**
- 카테고리별 봉투에 현금을 넣는 방식
- 로우테크이지만 충동 구매 방지에 매우 효과적

## 흔한 ZBB 실수들

**비정기 지출을 잊는 것**
12월에 명절 선물이 예상 밖의 지출일 수는 없습니다. 연간 비용을 12로 나눠 매달 포함시키세요.

**너무 엄격하게 설정하는 것**
외식비를 3만원으로 잡았는데 항상 15만원 쓴다면 실패합니다. 현실적인 숫자로 시작하고 점차 줄여나가세요.

**월 중 조정을 안 하는 것**
예상 못한 일이 생기면 조정하세요. 카테고리 간 금액을 이동하세요. ZBB는 유연합니다. 엄격한 룰이 아닙니다.

**한 달 실패 후 포기하는 것**
누구나 가끔 초과 지출을 합니다. 다음 달에 리셋하세요. 이 기술은 연습할수록 나아집니다.

## ZBB는 누구에게 최적인가?

제로베이스 예산법은 이런 분들에게 가장 잘 맞습니다:
- 돈에 대해 **최대한의 통제권**을 원하는 분
- 공격적으로 부채를 갚고 있는 분
- 매달 돈이 어디로 "사라지는지" 모르는 분
- 수입이 불규칙해서 구조가 필요한 분

소극적인 예산 방법보다 노력이 더 필요하지만, 실천하는 사람들에게는 종종 삶을 바꾸는 결과를 가져다 줍니다.

## 결론

제로베이스 예산법은 가장 의도적인 재정 관리 시스템입니다. 월이 시작되기 전에 모든 돈에 목적을 부여함으로써, 재정적 낭비를 없애고, 부채 상환을 가속화하며, 실제 목표에 맞게 지출을 정렬합니다.

이번 달부터 시작하세요. 수입을 적고, 필요한 모든 항목을 나열하고, 합계를 0으로 맞추세요.

그러면 돈에 대한 느낌이 얼마나 달라지는지 직접 확인하게 될 것입니다.
