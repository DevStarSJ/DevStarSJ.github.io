# 제로 베이스 예산법: 모든 돈에 역할을 부여하라

쓰기 전에 모든 돈이 어디로 가는지 정확히 안다면 어떨까요? 제로 베이스 예산법(ZBB)은 모든 돈에 특정 목적을 부여하여 돈을 완전히 통제할 수 있게 해주는 가장 의도적인 예산 방법입니다.

![예산 계획](https://images.unsplash.com/photo-1450101499163-c8848c66ca85?w=800)

## 제로 베이스 예산법이란?

제로 베이스 예산법은 수입에서 모든 지출을 빼면 0이 되는 것을 의미합니다. 은행 잔고가 0이 아니라—할당되지 않은 돈이 0인 것입니다.

**공식:**
```
수입 - 모든 지출 = 0원
```

모든 돈에는 역할이 있습니다: 청구서, 저축, 투자, 용돈, 또는 부채 상환.

## 제로 베이스 예산법이 효과적인 이유

### 완전한 인식
- 돈이 어디로 가는지 정확히 앎
- "미스터리" 지출 없음
- 의도적인 재정 결정

### 생활 수준 상승 방지
- 이미 할당된 돈은 쓸 수 없음
- 연봉 인상분은 목표로, 무작위 지출이 아닌
- 내장된 책임감

### 가치 우선순위화
- 무엇이 중요한지 직접 결정
- 지출이 목표와 일치
- 죄책감 줄고, 목적 증가

## 제로 베이스 예산 만드는 법

### 1단계: 월 수입 계산

모든 수입원 나열:
- 급여 (세후)
- 부업 수입
- 투자 배당금
- 기타 정기 수입

**변동 수입의 경우**: 최근 가장 낮은 달 또는 최근 3개월 평균 사용.

### 2단계: 모든 지출 나열

**고정 지출:**
- 월세/주택담보대출
- 자동차 할부금
- 보험료
- 최소 부채 상환
- 구독료

**변동 지출:**
- 식료품
- 공과금
- 주유비
- 오락
- 외식
- 개인 관리

**주기적 지출:**
- 연간 구독 (12로 나누기)
- 자동차 정비
- 의료비
- 선물
- 명절

### 3단계: 카테고리 만들기

**필수 카테고리:**
1. 주거비 (수입의 25-35%)
2. 교통비 (10-15%)
3. 식비 (10-15%)
4. 공과금 (5-10%)
5. 보험 (5-10%)
6. 최소 부채 상환

**재정 목표:**
7. 비상금
8. 퇴직 저축
9. 추가 부채 상환
10. 적립금 (미래 지출용)

**라이프스타일:**
11. 오락
12. 개인 지출
13. 의류
14. 선물

### 4단계: 모든 돈 할당

수입에서 시작하여 각 카테고리를 빼면 0이 될 때까지.

**예시: 월 수입 400만 원**

| 카테고리 | 금액 |
|----------|------|
| 주거비 | 100만 원 |
| 교통비 | 32만 원 |
| 식비 | 40만 원 |
| 공과금 | 16만 원 |
| 보험 | 24만 원 |
| 최소 부채 | 24만 원 |
| 비상금 | 24만 원 |
| 퇴직 저축 | 40만 원 |
| 추가 부채 상환 | 16만 원 |
| 오락 | 16만 원 |
| 개인 | 12만 원 |
| 의류 | 8만 원 |
| 적립금 | 32만 원 |
| 기타 | 16만 원 |
| **합계** | **400만 원** |

### 5단계: 추적 및 조정

- 실시간 지출 추적
- 필요시 카테고리 간 이동
- 월말 평가
- 다음 달 예산 개선

## 제로 베이스 예산 방법

### 봉투 시스템 (현금)

변동 지출용 물리적 봉투:
- 예산된 현금 인출
- 카테고리당 하나의 봉투
- 비면 지출 중단

**적합**: 카드로 과소비하는 사람

### 디지털 봉투 시스템

봉투를 모방한 앱:
- YNAB (You Need A Budget)
- 토스 목표
- 뱅크샐러드

**적합**: 기술에 능숙한 예산 관리자

### 스프레드시트 방법

DIY 추적:
- 구글 시트 또는 엑셀
- 맞춤 카테고리
- 완전한 통제

**적합**: 세부 지향적인 사람

## 흔한 제로 베이스 예산 실수

### 1. 비정기 지출 잊기
- 연간 구독
- 자동차 등록
- 명절 지출
- **해결책**: 적립금 만들기

### 2. 너무 제한적
- 용돈 없으면 번아웃
- 오락 예산 책정
- **해결책**: 죄책감 없는 지출 포함

### 3. 월 중간에 조정 안 함
- 일이 생김
- 카테고리는 유연할 수 있음
- **해결책**: 필요시 카테고리 간 이동

### 4. 나쁜 달 한 번에 포기
- 완벽이 목표가 아님
- 매달이 연습
- **해결책**: 검토, 배우기, 개선

### 5. 변동 수입 무시
- 풍요와 기근의 달
- **해결책**: 예상 최저 수입 기준 예산

## 적립금 설명

적립금은 알려진 미래 지출을 위한 저축:

**예시:**
- 자동차 정비: 월 5만 원
- 명절 선물: 월 8만 원
- 연간 보험: 월 10만 원
- 여행: 월 15만 원
- 새 폰: 월 3만 원

지출이 발생하면 돈이 준비됨—예산 위기 없음.

## 커플을 위한 제로 베이스 예산

### 공동 예산 팁

1. **함께 예산**: 두 목소리 모두 중요
2. **개인 지출**: 각자 죄책감 없는 돈
3. **정기 회의**: 주간 또는 격주 체크인
4. **타협**: 우선순위에서 중간점 찾기
5. **같은 목표**: 주요 재정 목표 일치

### 다른 지출 스타일 다루기

- 소비자 + 저축자 = 균형
- "질문 없이" 한도 설정
- 함께 성과 축하

## 제로 베이스 예산 도구

### 앱

**YNAB (You Need A Budget)**
- ZBB의 황금 표준
- 월 $14.99 또는 연 $99
- 가파른 학습 곡선, 그만한 가치

**토스 목표**
- 한국에서 인기
- 무료
- 간단한 인터페이스

**뱅크샐러드**
- 자산/지출 통합 관리
- 무료 기본 사용
- 한국 맞춤

### 스프레드시트

- 구글 시트 (무료, 어디서나 접근)
- 엑셀 (더 강력, 오프라인)
- 노션 (정돈된 사람용)

## 월말 검토 프로세스

1. 실제 vs 예산 비교
2. 초과 지출 카테고리 파악
3. 미달 지출 카테고리 메모
4. 차이 발생 이유 이해
5. 다음 달 예산 조정
6. 성공 축하

## 오늘 시작하기

**1주차:**
- 모든 지출 추적
- 모든 수입원 나열
- 지출 카테고리 파악

**2주차:**
- 첫 예산 작성
- 추적 방법 설정

**3주차:**
- 실시간 추적
- 필요시 조정

**4주차:**
- 월말 검토
- 다음 달 계획
- 프로세스 개선

## 결론

제로 베이스 예산법은 돈과의 관계를 변화시킵니다. 모든 돈에 역할을 부여함으로써 돈이 어디로 갔는지 궁금해하는 것을 없애고 원하는 곳으로 정확히 보내기 시작합니다.

처음 몇 달은 어렵습니다. 실수할 것입니다. 하지만 3-4개월이면 이것 없이 어떻게 살았는지 궁금할 것입니다.
