대부분의 예산 계획이 실패하는 이유는 지출이 많아서가 아닙니다. 처음부터 돈이 어디로 갈지 **결정하지 않았기 때문**입니다. 제로 베이스 예산법(ZBB)은 그 근본 원인을 해결합니다.

## 제로 베이스 예산법이란?

수입에서 지출을 빼면 **0**이 되도록 만드는 방법입니다. 다 쓰는 게 목표가 아니라, 모든 돈에 역할을 부여하는 것이 목표입니다:

- 고정 지출 → 배정
- 식비 → 배정
- 저축 → 배정
- 투자 → 배정
- 여가비 → 배정

목표는 저축 제로가 아니라 **미배정 돈 제로**입니다.

## 왜 기존 예산 방법은 실패할까?

대부분의 사람들이 이렇게 합니다:
1. 월급 받음
2. 고정비 납부
3. 나머지를 "알아서" 사용
4. 돈이 어디 갔는지 의문

ZBB는 이 논리를 뒤집습니다. 먼저 배정하고, 그다음에 씁니다.

## 제로 베이스 예산 5단계 설정법

### 1단계: 월 세후 수입 파악

급여, 부업, 프리랜서 수입 등 통장에 들어오는 모든 돈을 기록합니다. 수입이 일정하지 않다면 **보수적으로** 추정합니다.

### 2단계: 모든 예상 지출 목록 작성

고정 지출:
- 월세/주거비
- 자동차 할부
- 보험료
- 구독 서비스

변동 지출:
- 식비
- 교통비/주유비
- 외식비
- 의류비

### 3단계: 저축 및 투자 목표 추가

이것도 청구서처럼 대우합니다:
- 비상금 납입
- 연금/개인연금
- 여행 적립금
- 큰 지출을 위한 싱킹 펀드

### 4단계: 0이 될 때까지 빼기

수입 – (전체 지출 + 저축) = 0

남는 돈이 있으면 어딘가에 배정합니다(추가 저축, 부채 상환 등). 마이너스가 되면 어딘가를 줄입니다.

### 5단계: 월 중에도 추적하기

매주 확인하고 실제 지출에 맞게 조정합니다. 예산은 살아있는 문서입니다.

## ZBB에 좋은 도구

| 도구 | 특징 | 비용 |
|------|------|------|
| **YNAB** | ZBB 방법론에 특화 | 월 $14.99 |
| **EveryDollar** | 심플한 UI | 무료 / 월 $17.99 |
| **구글 스프레드시트** | DIY 미니멀리스트 | 무료 |
| **네이버 가계부 / 뱅크샐러드** | 국내 앱 | 무료 |

## 자주 하는 실수

**비정기 지출 누락:** 자동차 보험 연납, 명절 선물, 연간 구독 등. 이를 위한 싱킹 펀드를 만드세요.

**너무 rigid하게 만들기:** 삶은 예측 불가능합니다. 유연성을 위한 "기타" 항목은 필요합니다.

**중간 점검 안 하기:** 예산은 보지 않으면 효과가 없습니다.

## 실전 예시

월 세후 수입: **400만 원**

| 항목 | 금액 |
|------|------|
| 월세 | 80만원 |
| 식비 | 30만원 |
| 교통/주유 | 20만원 |
| 공과금 | 10만원 |
| 구독 서비스 | 5만원 |
| 외식 | 20만원 |
| 의류/생활용품 | 15만원 |
| 비상금 | 30만원 |
| 연금/펀드 투자 | 50만원 |
| 여행 적립금 | 20만원 |
| 기타/여유 | 15만원 |
| 자기계발 | 10만원 |
| 경조사/선물 | 10만원 |
| 개인 용돈 | 5만원 |
| **합계** | **320만원** |

남은 80만원은 추가 투자나 단기 목표에 배정합니다.

## 이번 달부터 시작하기

완벽한 시스템은 필요 없습니다. 스프레드시트를 열고 수입을 적고, 지출을 적고, 모든 돈에 역할을 부여하세요. 불완전하게 시작해도 괜찮습니다. 다음 달에 조정하고, 계속하면 됩니다.

**가장 좋은 예산은 실제로 사용하는 예산입니다.**
