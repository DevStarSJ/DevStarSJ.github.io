기존 가계부를 써도 "돈이 어디 갔지?"라는 질문이 반복된다면, **제로 기반 예산(ZBB, Zero-Based Budgeting)**이 당신에게 필요한 시스템일 수 있습니다. 지출을 나중에 추적하는 대신, ZBB는 월급을 받기 전에 모든 돈의 용처를 미리 계획합니다 — 수입 빼기 지출이 항상 0이 되도록.

## 제로 기반 예산이란?

제로 기반 예산은 매달(혹은 월급날마다) 처음부터 시작해서 수입의 **모든 돈**을 특정 항목에 배분하는 방법입니다 — 공과금, 식비, 저축, 투자, 여가비 등 — 남는 금액이 0이 될 때까지.

공식:
> **수입 − 모든 배분액 = 0원**

이것이 돈을 다 써버리라는 뜻은 아닙니다. 저축, 부채 상환, 투자도 하나의 "지출 항목"으로 예산에 포함됩니다.

## 제로 기반 예산이 효과적인 이유

### 의도적인 소비 강제
이미 목적이 정해진 돈은 충동적으로 쓸 수가 없습니다. 모든 지출이 먼저 계획을 "통과"해야 합니다.

### 숨겨진 낭비 발견
처음 ZBB를 해보면 깜짝 놀라는 사람이 많습니다 — 잊고 있던 구독 서비스, 반복되는 외식비, 기억도 못 하는 멤버십 비용이 갑자기 눈에 보이기 시작합니다.

### "남은 돈" 죄책감 해소
전통적인 예산 방식 사용자들은 계획 없이 남은 돈을 보며 불안해합니다. ZBB는 그 회색 지대를 완전히 없애버립니다.

### 매달 유연하게 조정
고정된 예산과 달리, ZBB는 매달 새로 작성됩니다. 계절 지출, 불규칙 수입, 변하는 목표에 맞게 유연하게 바꿀 수 있습니다.

## 제로 기반 예산 설정하기

### 1단계: 월 수입 계산
이번 달 모든 수입원을 나열하세요:
- 세후 월급
- 부업 수입
- 임대료, 프리랜서 수입
- 예상되는 불규칙 수입

수입이 일정하지 않다면 최근 몇 달 중 가장 적었던 달을 기준으로 삼으세요.

### 2단계: 지출 항목 모두 나열
모든 소비 카테고리를 빠짐없이 적으세요:

**고정 지출:**
- 월세/주택담보대출
- 보험료
- 대출 상환금
- 정기 구독

**변동 필수 지출:**
- 식비
- 공과금
- 교통비/주유비

**선택적 지출:**
- 외식
- 여가/취미
- 의류, 쇼핑

**재정 목표:**
- 비상금 적립
- 연금/퇴직연금 납입
- 부채 추가 상환
- 여행/특별 목표 적금

### 3단계: 배분액이 0이 될 때까지

필수 지출과 재정 목표부터 배분하고, 나머지를 선택적 지출에 나눠주세요. 다음 등식이 성립할 때까지 조정하세요:

> 총 수입 − 총 배분액 = 0원

### 4단계: 한 달 내내 추적
지출이 발생할 때마다 해당 항목에서 차감하세요. 항목이 0이 되면 그 달은 거기서 그만 — 또는 다른 항목에서 의식적으로 이체하세요.

## 제로 기반 예산 추천 툴

| 툴 | 적합한 대상 | 비용 |
|----|------------|------|
| **YNAB (You Need A Budget)** | ZBB 전용 시스템, 뛰어난 UX | 월 약 2만 원 |
| **EveryDollar** | 간단한 UI, 다이렉트 방식 선호자 | 무료/유료 플랜 |
| **구글 스프레드시트/엑셀** | 완전 커스텀, 비용 없음 | 무료 |
| **뱅크샐러드/토스** | 한국 사용자, 자동 분류 | 무료 |

YNAB은 ZBB의 정석 앱으로 널리 알려져 있습니다 — 이 방법론에 맞게 설계되어 있고, 수백만 명의 부채 감소와 저축 증가에 기여했습니다.

## 제로 기반 예산 꿀팁

### '잡비' 항목 만들기
소소한 예상 외 지출을 위해 5–10만 원의 잡비 항목을 만드세요. 3만 원짜리 돌발 지출 때문에 전체 예산이 무너지는 것을 막아줍니다.

### '즐기는 돈' 반드시 배분
여가비를 예산에서 없애면 결국 예산 자체가 깨집니다. 카페, 영화, 배달 음식도 의식적으로 예산에 넣으세요.

### 불규칙 지출 미리 준비
자동차 검사비, 연간 보험료, 명절 비용 — 연간 비용을 12로 나눠 매달 적립하면 '갑자기 생긴 지출'이 사라집니다.

### 3개월은 버텨야 체감
대부분의 사람들은 3개월 후 ZBB가 자연스러워진다고 합니다. 첫 달이 가장 어렵고(그리고 가장 놀랍고), 3개월 후엔 제2의 본능이 됩니다.

## ZBB vs 전통적 비율 기반 예산 비교

| 특징 | 제로 기반 예산 | 비율 기반 (50/30/20 법칙) |
|------|--------------|--------------------------|
| 유연성 | 높음 (매달 재설계) | 중간 (고정 비율) |
| 노력 | 높음 (세부적) | 낮음 (단순함) |
| 통제력 | 최대 | 중간 |
| 적합한 대상 | 소비 습관 개선이 필요한 분 | 수입이 일정한 분 |

## 실전 예시 (월 400만 원 수입)

| 항목 | 금액 |
|------|------|
| 월세 | 70만 원 |
| 식비 | 30만 원 |
| 공과금 | 10만 원 |
| 교통비 | 10만 원 |
| 통신비 | 5만 원 |
| 구독 서비스 | 3만 원 |
| 비상금 적립 | 20만 원 |
| 연금/투자 | 80만 원 |
| 외식 | 20만 원 |
| 여가/취미 | 20만 원 |
| 의류/쇼핑 | 15만 원 |
| 미용/자기계발 | 15만 원 |
| 잡비 | 5만 원 |
| 여행 적금 | 20만 원 |
| 부채 추가 상환 | 77만 원 |
| **합계** | **400만 원** |

모든 돈에 역할이 있습니다. 수입 − 배분액 = **0원** ✅

## 마치며

제로 기반 예산은 대부분의 예산 방법보다 훨씬 손이 많이 갑니다 — 하지만 그만큼 결과도 확실합니다. 기존의 수동적인 가계부 방식으로 실패를 반복했다면, ZBB의 의도성과 구조가 돈 관리의 새로운 돌파구가 될 수 있습니다.

**첫 달은 힘듭니다. 세 번째 달은 자연스러워집니다. 일 년 후엔 재정이 바뀝니다.**
