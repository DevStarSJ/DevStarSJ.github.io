## Notion AI란 무엇인가요?

Notion AI는 Notion 워크스페이스에 직접 내장된 인공지능 레이어입니다. 도구 간 전환 없이:

- **초안 작성 및 재작성** — 페이지를 떠나지 않고 문서 작성
- **요약** — 긴 노트나 회의록을 빠르게 정리
- **액션 아이템 추출** — 비구조화된 텍스트에서 할 일 항목 자동 식별
- **번역** — 수십 개 언어로 콘텐츠 번역
- **아이디어 생성** — 즉석에서 아이디어와 개요 생성
- **워크스페이스에 질문** — 자신의 Notion 데이터베이스에 AI로 질문

마치 당신의 '제2의 뇌' 안에 내장된 탁월한 어시스턴트라고 생각하면 됩니다.

## Notion AI 핵심 기능

### 1. AI 글쓰기 어시스턴트

텍스트 블록을 선택하고 AI 메뉴(스페이스바 또는 `AI에게 물어보기`)에 접근하면:

- **맞춤법 및 문법 교정** — 즉각적인 교정
- **텍스트 길이 조정** — 더 짧게 또는 더 길게
- **어조 변경** — 격식체에서 구어체로 또는 반대로
- **번역** — 30개 이상의 언어 지원
- **글 이어쓰기** — AI가 멈춘 지점에서 계속 작성

영어가 모국어가 아닌 사용자가 빠르게 전문적인 수준의 글을 쓸 때 특히 유용합니다.

### 2. 요약 및 추출

Notion AI의 가장 실용적인 기능 중 하나는 **문서 요약**입니다. 2,000자 분량의 회의록을 붙여 넣으면 몇 초 만에 5개의 핵심 요약 항목이 나옵니다.

마찬가지로 **액션 아이템 추출**은 원시 노트에서 작업, 담당자, 마감일을 자동으로 식별합니다.

```
입력: "Q2 로드맵을 논의했습니다. John은 금요일까지 디자인 목업을 
완성할 예정입니다. Sarah는 스프린트 종료 전에 새 CI 파이프라인을 
설정해야 합니다. 마케팅팀은 수요일까지 뉴스레터 초안을 Tom에게 
검토 요청해야 합니다."

출력:
✅ John → 디자인 목업 완성 (금요일까지)
✅ Sarah → CI 파이프라인 설정 (스프린트 종료 전)
✅ 마케팅팀 → 뉴스레터 초안을 Tom에게 전달 (수요일까지)
```

### 3. AI Q&A (워크스페이스에 질문하기)

Notion AI의 가장 야심찬 기능: **자신의 데이터에 대해 AI에게 질문하기**. 검색 증강 생성(RAG)을 사용하여 페이지와 데이터베이스를 검색해 관련 답변을 찾아줍니다.

예시 질의:
- *"가격 모델에 대해 우리가 어떤 결정을 내렸나요?"*
- *"Q1 고객 인터뷰의 모든 피드백을 요약해 주세요"*
- *"지난 주 미팅에서 나온 미완료 액션 아이템이 뭐예요?"*

### 4. 데이터베이스 자동 채우기

Notion 고급 사용자를 위한 **AI 자동 채우기**는 페이지 내용을 기반으로 AI가 생성한 속성을 데이터베이스 항목에 자동으로 채웁니다.

다음에 적합합니다:
- CRM 시스템 (연락처 요약 자동 생성)
- 프로젝트 데이터베이스 (결과물 자동 추출)
- 콘텐츠 캘린더 (메타 설명 자동 생성)

## 시작하는 방법

### 설정

1. 어떤 Notion 워크스페이스든 열기
2. 빈 줄에서 **스페이스바** 누르기 (또는 텍스트를 하이라이트하고 AI 아이콘 클릭)
3. 액션 메뉴에서 선택하거나 커스텀 프롬프트 입력
4. Notion AI가 인라인으로 콘텐츠 생성

Notion AI는 **모든 유료 플랜**에서 사용 가능하며 무료 사용자는 애드온으로 추가할 수 있습니다 (멤버당 월 $8).

### 실전 워크플로우 예시

**아침 브리핑 템플릿:**
```
AI에게 질문: "오늘 내 작업 데이터베이스와 최근 회의 노트를 
기반으로 오늘 할 일을 요약해 주세요."
```

**회의록 → 액션 아이템:**
```
1. 새 페이지에 회의 원시 기록 붙여넣기
2. 전체 선택 → AI에게 물어보기 → "담당자와 마감일을 포함한 액션 아이템 추출"
3. 결과를 프로젝트 데이터베이스에 복사
```

**콘텐츠 초안 작성:**
```
1. 제목과 3~5개의 개요 포인트로 페이지 생성
2. AI에게 물어보기: "이 개요를 전체 블로그 포스트 초안으로 확장해 주세요"
3. 검토, 편집 후 게시
```

## 파워 유저를 위한 팁

### 1. AI 기반 SOP 구축하기
AI 프롬프트가 내장된 표준 운영 절차(SOP) 템플릿을 만드세요. 신규 팀원이 AI를 사용해 개인화된 안내를 받을 수 있습니다.

### 2. 커스텀 AI 프롬프트 사용하기
데이터베이스 자동 채우기에서 데이터에 맞는 구체적인 프롬프트 작성:
- *"이 인터뷰에서 언급된 고객 불편 사항을 2문장으로 요약해 주세요"*
- *"이 스펙 문서에서 언급된 기술 요구사항을 나열해 주세요"*

### 3. Notion 자동화와 결합하기
AI 자동 채우기를 Notion의 자동화 트리거와 결합하여 새 항목이 생성되는 즉시 자동으로 요약합니다.

### 4. 글로벌 팀을 위한 언어 다리
워크스페이스를 떠나지 않고 언어 장벽을 넘어 비동기 커뮤니케이션에 즉시 번역 기능을 활용하세요.

## 알아두어야 할 제한 사항

- **컨텍스트 창:** AI Q&A는 잘 구성되고 연결된 페이지에서 가장 잘 작동합니다. 매우 크고 구조화되지 않은 위키에서는 어려울 수 있습니다.
- **정확도:** 모든 LLM과 마찬가지로 Notion AI는 환각(hallucination)이 발생할 수 있습니다. 항상 사실 정보를 검증하세요.
- **속도:** 대규모 워크스페이스에 대한 복잡한 쿼리는 10~20초가 걸릴 수 있습니다.
- **심층 리서치 대체 불가:** 웹 리서치나 최신 데이터의 경우 외부 도구가 여전히 필요합니다.
