## Pika Labs 2.0이란?

Pika Labs는 텍스트 설명, 이미지, 기존 영상 클립을 고품질 영상 콘텐츠로 변환하는 **AI 기반 영상 생성 플랫폼**입니다. 버전 2.0에서 크게 개선된 기능:

- **영상 품질** — 향상된 모션 일관성을 갖춘 최대 1080p 해상도
- **길이** — 최대 15초 영상 생성 (45초 이상으로 확장 가능)
- **카메라 제어** — 정밀한 팬, 줌, 회전 컨트롤
- **캐릭터 일관성** — 여러 장면에서 동일한 캐릭터 유지
- **사운드 디자인** — AI 생성 효과음 및 배경 오디오

## Pika 2.0의 주요 기능

### 1. 텍스트-투-비디오
가장 인기 있는 기능 — 자연어로 장면을 설명하면 Pika가 현실로 만들어줍니다.

**효과적인 프롬프트 예시:**
```
"황금빛 털의 어린 강아지가 가을 낙엽 사이를 달리는 슬로모션, 
 영화적 조명, 얕은 심도"

"아침부터 밤까지의 도시 거리 타임랩스, 
 젖은 포장도로에 반사되는 네온사인, 4K 품질"

"우주를 떠다니는 우주비행사, 아래에 보이는 지구, 
 반짝이는 별들, 렌즈 플레어, IMAX 스타일"
```

### 2. 이미지-투-비디오
이미지를 업로드하면 Pika가 애니메이션화합니다:
- 제품 사진 → 제품 데모 영상
- 인물 사진 → 애니메이션 헤드샷
- 풍경사진 → 스위핑 카메라 무브먼트
- 일러스트 → 애니메이션 아트

### 3. 비디오-투-비디오 (스타일 전환)
기존 영상 푸티지를 변환:
- 아트 스타일 적용 (애니메, 유화, 사이버펑크)
- 시간대 변경
- 날씨 조건 수정
- 캐릭터 외모 변경

### 4. 정밀한 카메라 제어
Pika 2.0의 카메라 제어 시스템은 업계 최고 수준:

| 제어 | 옵션 |
|------|------|
| 이동 | 좌/우 팬, 상/하 틸트, 줌 인/아웃 |
| 회전 | 롤, 오빗 |
| 속도 | 느리게, 보통, 빠르게 |
| 스타일 | 핸드헬드(흔들림), 부드러운(안정화), 영화적 |
| 초점 | 고정, 피사체 추적, 포커스 전환 |

### 5. 확장 및 편집
- **확장(Extend)**: 생성된 영상에 초 추가
- **리프레임(Reframe)**: 화면비 변경 (16:9 → 9:16 모바일용)
- **영역 수정**: 영상의 특정 부분만 편집
- **업스케일**: 해상도를 4K로 향상

### 6. AI 사운드 디자인
Pika 2.0에 내장 사운드 생성 기능 추가:
- 적절한 효과음 자동 감지 및 추가
- 배경 오디오 생성
- 오디오와 영상 모션 동기화
- 음악 스타일 매칭

## Pika 2.0 시작하기

### 1단계: Pika 접속
1. [pika.art](https://pika.art) 방문
2. Google 또는 Discord로 로그인
3. 무료 250 크레딧으로 시작 (매월 리셋)

### 2단계: 첫 번째 영상 만들기

**텍스트-투-비디오:**
1. **"Create"** 클릭
2. **"Text to Video"** 선택
3. 프롬프트 입력
4. 화면비 선택 (16:9, 9:16, 1:1)
5. 길이 선택 (3, 5, 10, 15초)
6. 모션 강도 선택 (낮음, 보통, 높음)
7. **"Generate"** 클릭

**이미지-투-비디오:**
1. **"Create"** 클릭
2. **"Image to Video"** 선택
3. 참고 이미지 업로드
4. 모션 설명 추가: "카메라가 천천히 줌인"
5. 모션 강도 조절
6. 생성

### 3단계: 결과 다듬기
첫 결과가 만족스럽지 않다면:
- 프롬프트에 더 많은 세부사항 추가
- 다른 모션 설정 시도
- "Modify Region"으로 특정 영역 수정
- 여러 버전 생성 후 가장 좋은 것 선택

## 개발자를 위한 API

Pika는 앱에 영상 생성을 통합하기 위한 개발자 API를 제공합니다:

```python
import requests

API_KEY = "your-pika-api-key"

def generate_video(prompt, duration=5, aspect_ratio="16:9"):
    response = requests.post(
        "https://api.pika.art/v2/generate",
        headers={"Authorization": f"Bearer {API_KEY}"},
        json={
            "prompt": prompt,
            "duration": duration,
            "aspectRatio": aspect_ratio,
            "motionStrength": "medium",
            "resolution": "1080p"
        }
    )
    return response.json()

video = generate_video(
    "나무 테이블 위에서 김이 나는 커피컵, 아침 햇살",
    duration=5
)
print(f"영상 URL: {video['url']}")
```
