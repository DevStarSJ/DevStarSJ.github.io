## Gamma AI란?

Gamma는 AI 기반 프레젠테이션 및 문서 제작 플랫폼입니다. 기존 슬라이드 도구와 달리, Gamma는 짧은 텍스트 설명에서 콘텐츠, 레이아웃, 비주얼, 포맷을 포함한 완성도 높은 프레젠테이션을 생성합니다.

**핵심 차별점:**
- 프롬프트에서 **약 30초** 만에 완전한 덱 생성
- 모든 기기에서 작동하는 반응형 디자인
- 뷰어 참여도를 추적하는 내장 애널리틱스
- 파일이 아닌 웹사이트로 공개

---

## Gamma가 만들 수 있는 것

Gamma는 슬라이드 덱만이 아닙니다 — 세 가지 주요 콘텐츠 유형을 만들 수 있습니다:

### 📊 프레젠테이션
전통적인 슬라이드 기반 덱, 더 스마트하게:
- 전문적인 레이아웃으로 자동 생성
- Unsplash/AI의 스마트 이미지 제안
- 애니메이션 전환 효과와 인터랙티브 요소
- 발표자 노트 생성

### 📄 문서
시각적 포맷의 장문 콘텐츠:
- 제품 명세서 및 RFP
- 연구 보고서
- 내부 위키 및 가이드
- 사례 연구

### 🌐 웹페이지
웹사이트로 직접 공개:
- 랜딩 페이지
- 포트폴리오
- 이벤트 페이지
- 제품 쇼케이스

## Gamma 사용 방법

### 1단계: 프롬프트로 시작
[gamma.app](https://gamma.app)에 접속해서 **새로 만들기** 클릭. 다음 중 선택:
- **생성**: AI가 설명에서 모든 것을 만듦
- **텍스트 붙여넣기**: 기존 콘텐츠를 슬라이드로 변환
- **템플릿**: 선별된 템플릿에서 시작

### 2단계: 원하는 것 설명
간단한 설명 입력:
```
"AI 재고 관리로 식당의 음식물 쓰레기를 줄이는 B2B SaaS 스타트업을 위한 
10슬라이드 피치 덱. 시장 규모, 문제/해결책, 비즈니스 모델, 팀 슬라이드 포함."
```

### 3단계: AI 생성 아웃라인 검토
생성 전에 제안된 아웃라인을 보여줍니다:
- 섹션 편집, 순서 변경, 삭제
- 슬라이드 수 조정
- 톤 지정 (전문적, 캐주얼, 학술적)

### 4단계: 생성 & 다듬기
**생성** 클릭 후 30-60초 내에 완성된 프레젠테이션이 만들어집니다. 그 후:
- 텍스트 인라인 편집
- 클릭 한 번으로 이미지 교체
- 클릭 한 번으로 전체 테마 변경
- AI에게 특정 섹션 재작성 요청

## Gamma 내부 AI 기능

### ✨ AI 카드 생성
카드를 클릭하고 AI에게 요청:
- "더 간결하게 만들어줘"
- "여기에 관련 통계 추가해줘"
- "기술적인 청중을 위해 다시 써줘"
- "마지막에 CTA 추가해줘"

### 🎨 스마트 이미지 제안
Gamma가 자동으로 관련 이미지 제안:
- Unsplash 라이브러리 (무료, 고품질)
- AI 생성 이미지
- Giphy 애니메이션
- 아이콘 및 일러스트레이션

### 📊 자동 생성 차트
시각화할 데이터 설명:
```
"월별 수익이 6개월에 걸쳐 5000만원에서 2억원으로 성장하는 막대 차트 추가"
```
Gamma가 자동으로 차트를 생성합니다 — 데이터 포맷 작업 불필요.

### 🔄 테마 & 스타일 제어
- 20개 이상의 전문적인 테마
- 원클릭 테마 변경 (콘텐츠 유지)
- 커스텀 브랜드 색상 및 폰트
- 다크/라이트 모드 토글

## 협업 기능

Gamma는 협업 도구로서도 빛납니다:
- **실시간 공동 편집**: 여러 사람이 동시 편집
- **댓글**: 특정 카드에 피드백
- **공유 링크**: 공유 가능한 URL 전송 (뷰어는 계정 불필요)
- **어디서나 임베드**: Notion, 웹사이트, 이메일에 Gamma 임베드

## 애널리틱스 — 숨겨진 보석

전통적인 프레젠테이션 도구와 달리, Gamma는 추적합니다:
- 몇 명이 덱을 봤는지
- 슬라이드당 평균 체류 시간

이는 영업 덱, 투자자 피치, 마케팅 자료에 매우 유용합니다.

## 실전 활용 사례

### 🚀 스타트업 피치 덱
스타트업을 설명하면 즉시 투자 준비 덱을 만들 수 있습니다. Gamma의 템플릿은 검증된 피치 덱 구조를 따릅니다 (문제, 해결책, 시장, 견인력, 팀, 요청).

### 📈 영업 프레젠테이션
각 잠재 고객을 위한 맞춤 덱을 분 단위로 생성:
```
"[회사명]을 위한 제안서 생성, AI로 고객 지원 응답 시간을 개선하려는 
중규모 이커머스 기업"
```

### 📚 교육 자료
긴 텍스트 교육 문서를 시각적이고 매력적인 슬라이드 모듈로 변환 — 신규 직원 온보딩에 완벽합니다.

### 🎓 학술 발표
학생과 연구자들이 논문을 컨퍼런스와 수업 발표용 명확하고 시각적인 프레젠테이션으로 변환.

### 📋 상태 보고서
실제로 읽히는 주간/월간 비즈니스 업데이트:
```
"2026년 1분기 마케팅 성과 보고서 작성, 주요 지표, 성과, 과제, 2분기 계획 포함"
```

## 프로 팁

**1. 프롬프트를 구체적으로**
```
❌ "마케팅에 관한 프레젠테이션 만들어줘"
✅ "B2B SaaS 기업을 위한 콘텐츠 마케팅 전략에 관한 12슬라이드 프레젠테이션, 
   CMO를 대상으로, 데이터 중심 접근 방식, 퍼널 각 단계별 실행 가능한 전술 포함"
```

**2. 붙여넣기 기능 활용**
Word 문서나 Google Doc이 있다면? Gamma에 직접 붙여넣으면 자동으로 프레젠테이션으로 변환됩니다.

**3. AI 카드 편집 활용**
첫 번째 생성을 최종본으로 받아들이지 마세요. AI를 사용해 각 카드를 완벽해질 때까지 반복적으로 다듬으세요.

**4. 카드 유형 혼합**
Gamma는 한 덱에서 다양한 카드 유형을 지원합니다: 텍스트 카드, 이미지 카드, 비디오 임베드, 코드 블록, 테이블. 다양성을 위해 혼합하세요.

**5. 필요할 때 내보내기**
전통적인 파일이 필요한 고객을 위해:
- PDF로 내보내기
- PowerPoint(.pptx)로 내보내기 — 유료 플랜
- 웹 링크로 공유
