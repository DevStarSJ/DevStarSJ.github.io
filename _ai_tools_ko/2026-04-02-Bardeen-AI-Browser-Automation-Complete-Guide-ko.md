**Bardeen**은 Chrome 확장 프로그램으로 실행되는 AI 기반 브라우저 자동화 도구로, 코드 없이 반복적인 웹 작업을 자동화할 수 있습니다. Zapier가 API 간 자동화를 하고 Make가 복잡한 워크플로우를 처리한다면, Bardeen은 **브라우저 자체 내에서의 작업 자동화** — 클릭, 스크래핑, 폼 작성, 데이터 추출 등 — 에 특화되어 있습니다.

## Bardeen이란?

Bardeen은 다음을 결합한 **브라우저 자동화 플랫폼**입니다:

- **플레이북**: 사전 제작 또는 맞춤형 자동화 워크플로우
- **스크래퍼**: 모든 웹사이트에서 데이터 추출
- **AI Magic Actions**: AI를 사용해 데이터 처리, 변환, 분류
- **통합**: 70개 이상의 도구와 연결 (CRM, Google Sheets, Notion, Slack 등)
- **백그라운드 자동화**: 브라우저를 닫아도 자동화 실행

Bardeen을 웹을 위한 "스마트 매크로 레코더"라고 생각하세요 — 단지 클릭을 기록하는 것이 아니라 AI가 컨텍스트를 이해합니다.

## 핵심 기능

### 1. 플레이북 — 자동화 워크플로우
플레이북은 Bardeen의 자동화 시퀀스입니다 — Zapier의 워크플로우에 해당합니다.

**플레이북 구조:**
```
트리거 → 액션 → 출력

예시:
트리거: LinkedIn 프로필 클릭
액션: 
  1. 스크래핑: 이름, 직함, 회사, 이메일
  2. AI Magic: 회사 규모 분류, 개인화 메시지 작성
  3. Salesforce 연락처로 저장
  4. 작업 추가: "3일 후 팔로우업"
출력: LinkedIn 잠재 고객 → 클릭 하나로 Salesforce CRM
```

**플레이북 실행 위치:**
- **온디맨드**: 수동으로 클릭 실행
- **예약**: 설정된 시간에 실행
- **백그라운드**: 조건이 충족될 때 실행
- **트리거**: 특정 URL이나 페이지 방문 시 활성화

### 2. 스크래퍼 — 코드 없는 웹 데이터 추출
Bardeen의 스크래퍼는 모든 웹사이트에서 구조화된 데이터를 추출합니다:

**작동 방식:**
1. 웹 페이지로 이동
2. Bardeen 스크래퍼 열기
3. 추출할 요소 클릭 (이름, 가격, 이메일 등)
4. Bardeen이 패턴을 자동으로 파악
5. 하나의 레코드 추출, 또는 수백 개를 페이지네이션으로 추출

**처리하는 데이터 유형:**
- 텍스트 (이름, 설명, 가격)
- URL과 링크
- 이미지
- 테이블과 목록
- 페이지네이션된 데이터 (자동으로 "다음" 클릭)
- 무한 스크롤 콘텐츠

**출력 대상:**
- Google Sheets
- Airtable
- Notion 데이터베이스
- CSV 다운로드
- 모든 연결된 통합

**실용적인 스크래핑 예시:**
```
LinkedIn 프로필 → 잠재 고객 데이터베이스
Google Maps 목록 → 영업 리드
Amazon 리뷰 → 경쟁사 분석
채용 공고 → 인재 파이프라인
이커머스 가격 → 경쟁사 가격 모니터링
뉴스 기사 → 리서치 데이터베이스
```

### 3. AI Magic Actions
여기서 Bardeen이 단순 자동화 도구와 차별화됩니다. AI Magic Actions는 GPT-4 또는 Claude를 사용해 데이터를 지능적으로 처리합니다:

**AI Magic Actions 종류:**

| 액션 | 기능 |
|------|------|
| 분류 | 정의한 카테고리로 항목 분류 |
| 추출 | 비정형 텍스트에서 특정 정보 추출 |
| 요약 | 긴 콘텐츠를 핵심 포인트로 압축 |
| 작성 | 컨텍스트 기반 콘텐츠 생성 |
| 번역 | 텍스트를 다른 언어로 변환 |
| 점수 | 기준에 따라 항목 평가 또는 순위 매기기 |
| 리서치 | 사람/회사에 대한 추가 정보 조회 |

**AI Magic을 사용한 예시 워크플로우:**
```
LinkedIn 프로필 50개 스크래핑
→ AI Magic: 프로필에서 회사 규모, 펀딩 단계, 기술 스택 추출
→ AI Magic: ICP 기준으로 각 리드를 1-10점으로 평가
→ AI Magic: 각각에 대해 개인화된 아웃리치 메시지 작성
→ 상위 20개 리드를 HubSpot으로 push
→ Gmail 초안 생성
```

영업 담당자가 수동으로 8-10시간 걸리는 작업을 Bardeen이 20-30분에 자동으로 처리합니다.

### 4. 백그라운드 자동화
탭이 열려 있어야 하는 많은 브라우저 확장 프로그램과 달리, Bardeen은 백그라운드에서 자동화를 실행할 수 있습니다:

- 일정 설정: "매주 월요일 오전 9시에 경쟁사 가격 스크래핑"
- 탭을 닫아도 계속 실행
- 야간 자동화 실행
- 노트북을 켜두지 않아도 됨 (클라우드 실행 가능)

### 5. 통합 허브
Bardeen은 70개 이상의 도구와 연결됩니다:

**CRM**: Salesforce, HubSpot, Pipedrive, Close, Zoho

**데이터베이스**: Airtable, Notion, Google Sheets, Coda

**커뮤니케이션**: Slack, Gmail, Outlook, Discord

**프로젝트 관리**: Linear, Jira, Asana, Trello, Monday.com

**기타**: Zapier (수천 개 앱 확장), Webhooks, Apollo, Hunter.io

## 역할별 실제 활용 사례

### 영업 개발 담당자 (SDR)
```
LinkedIn 잠재 고객 발굴 자동화:
1. LinkedIn Sales Navigator에서 ICP 기준 검색
2. Bardeen이 매칭 프로필 스크래핑 (이름, 직함, 회사, 이메일)
3. AI Magic 강화: 회사 규모, 기술 스택, 최근 뉴스
4. AI Magic ICP 적합도 점수 (1-10)
5. AI Magic 개인화된 3문장 오프너 작성
6. 상위 리드 → Salesforce
7. 이메일 초안 → Gmail 초안

소요 시간: 수동 = 8시간 / Bardeen = 25분
비용: 리드당 $0.08 (Bardeen 크레딧 비용)
```

### 콘텐츠 & 마케팅 팀
```
경쟁사 모니터링 자동화:
일정: 매주 월요일 오전 8시
1. 경쟁사 웹사이트 10개 방문
2. 스크래핑: 새 블로그 게시물, 제품 업데이트, 가격
3. AI Magic: 지난 주 대비 변경 사항 요약
4. Slack에 push: "경쟁사 업데이트 - 4월 7일 주간"
5. Notion에서 중요한 변경 사항 표시

결과: 3시간 주간 감사 → 5분 검토
```

### 채용 담당자
```
인재 파이프라인 구축:
1. 직업 설명에 맞는 후보자 LinkedIn 검색
2. Bardeen 스크래핑: 이름, 현재 직책, 스킬, 위치
3. AI Magic: 직무 요건과 매칭 점수 (%)
4. AI Magic: 핵심 스킬 및 격차 파악
5. 상위 후보자를 ATS(Greenhouse/Lever)에 push
6. 개인화된 메시지 템플릿으로 아웃리치 작업 생성

소요 시간: 며칠 → 몇 시간
```

### 리서치 분석가
```
시장 리서치 자동화:
1. 리서치할 회사 목록 정의 (예: SaaS 스타트업 200개)
2. Bardeen이 Crunchbase, LinkedIn, 회사 사이트 스크래핑
3. AI Magic 추출: 펀딩, 직원 수, 제품 포커스, 리더십
4. AI Magic: 서브 버티컬과 단계별 분류
5. Airtable에 포괄적인 경쟁사 현황 구축
6. 뉴스와 변경 사항으로 매주 자동 업데이트

보통 2-3일 걸리던 것: 4-6시간
```

## 시작하기

### 1단계: Bardeen 설치
1. [bardeen.ai](https://bardeen.ai) 방문
2. Chrome 확장 프로그램 설치
3. 가입 (무료)

### 2단계: 플레이북 라이브러리 탐색
Bardeen에는 100개 이상의 사전 제작 플레이북이 있습니다:
1. Bardeen 확장 클릭
2. "Playbook Store" 클릭
3. 카테고리별 검색: 영업, 리서치, 마케팅, 생산성
4. 사전 제작 플레이북 설치 → 필요에 맞게 커스터마이즈

### 3단계: 첫 번째 스크래퍼 만들기
1. 웹사이트로 이동 (예: LinkedIn 검색 결과 페이지)
2. Bardeen 확장 → "Scraper" 클릭
3. 페이지에서 요소를 클릭해 추출할 항목 정의
4. 추출된 데이터 미리보기
5. 출력 선택: Google Sheets, Airtable 등
6. 실행

### 4단계: AI Magic 추가
1. 플레이북에서 AI Magic 액션 추가
2. 액션 유형 선택: 분류, 추출, 작성 등
3. 프롬프트 정의:
   ```
   "회사 설명을 기반으로 회사 규모를 분류하세요:
   - 스타트업 (1-50명)
   - SMB (51-500명)  
   - 엔터프라이즈 (500명 이상)
   카테고리 이름만 반환하세요."
   ```
4. 입력 및 출력 필드 매핑
5. 테스트 및 배포

## 개인정보 및 법적 고려사항

**중요**: 웹 스크래핑은 일부 플랫폼의 서비스 이용 약관을 위반할 수 있습니다.

**스크래핑 안전한 경우:**
- 자신의 데이터/계정
- 공개 비즈니스 디렉토리
- 뉴스 사이트 및 공개적으로 이용 가능한 콘텐츠
- 명시적인 스크래핑 허가가 있는 API

**스크래핑 전 약관 확인 필요:**
- LinkedIn (엄격한 반스크래핑 정책)
- 소셜 미디어 플랫폼
- 이커머스 플랫폼
- 인증이 있는 모든 사이트

**모범 사례:**
- 스크래핑 속도 제한 (사이트에 과부하 주지 않기)
- robots.txt 준수
- 동의 없이 개인 데이터 스크래핑 금지 (GDPR 준수)
- 개인 데이터가 아닌 비즈니스 정보에 사용
