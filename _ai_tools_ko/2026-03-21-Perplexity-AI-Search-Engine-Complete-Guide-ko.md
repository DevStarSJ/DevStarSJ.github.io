## Perplexity AI란?

Perplexity AI는 대형 언어 모델과 실시간 웹 검색을 결합한 **AI 기반 답변 엔진**입니다. 제공하는 모든 답변에 출처 기사로 연결되는 번호 인용이 포함되어 있어, 가장 투명한 AI 도구 중 하나입니다.

## 2026년 주요 기능

### 1. 인용이 포함된 답변 엔진
어떤 질문을 해도 번호가 달린 참조 [1][2][3]와 함께 잘 구조화된 답변을 받습니다. 번호를 클릭하면 출처 기사로 바로 이동해 팩트체크가 매우 쉽습니다.

### 2. 포커스 모드
필요에 따라 다양한 검색 모드로 전환:
- **Web** — 일반 인터넷 검색
- **Academic** — 동료 심사 논문 (PubMed, Semantic Scholar 등)
- **YouTube** — 타임스탬프가 포함된 영상 기반 답변
- **Reddit** — 커뮤니티 토론 및 실제 경험
- **Wolfram Alpha** — 수학적, 사실적 계산
- **뉴스** — 실시간 최신 뉴스

### 3. 스페이스 (Pro 기능)
팀을 위한 공유 리서치 공간 생성:
- 문서 업로드 (PDF, Word, 스프레드시트)
- 커스텀 AI 페르소나 설정
- 연구 프로젝트 협업
- 링크로 결과 공유

### 4. Pro 검색
Pro 티어에서는 향상된 검색 모드 이용 가능:
- 복잡한 주제 답변 전 명확화 질문
- 더 많은 출처를 읽는 심층 리서치
- 더 포괄적이고 섬세한 답변
- 파일 업로드 지원 (PDF, 이미지, CSV 분석)

### 5. Perplexity 어시스턴트 (2026)
최신 기능으로 Perplexity가 능동적인 AI 어시스턴트로 진화:
- 예약된 리서치 리포트
- 이메일 및 캘린더 통합
- 선제적 뉴스 브리핑
- 개발자를 위한 API 접근

## 직업별 활용 사례

### 📊 비즈니스 애널리스트
- 출처가 인용된 업계 리포트로 시장 조사
- 경쟁사 분석: "[A사] vs [B사] 가격 전략 비교"
- 출처 추적이 가능한 트렌드 파악

### 🎓 학생 및 연구원
- 학술 모드로 동료 심사 출처 찾기
- 적절한 인용이 포함된 문헌 검토
- 논문에 포함하기 전 사실 확인

### 💼 저널리스트 및 작가
- 실시간 뉴스 조사
- 기업/인물 배경 조사 (출처 포함)
- 빠른 사실 확인

### 👨‍💻 개발자
- 기술 문서 검색
- 에러 메시지 조사 ("Express.js CORS 403 에러 원인?")
- API 비교 및 선택

## 파워 유저를 위한 팁

**1. @ 기호로 출처 선택**
`@youtube`로 YouTube에서만 검색하거나, `@reddit`으로 Reddit 토론 검색.

**2. 질문에 맥락 추가**
"SMB 타겟 SaaS 회사의 마케팅 디렉터로서, 2026년 가장 효과적인 LinkedIn 마케팅 전략은?"

**3. 표와 비교 요청**
"2026년 상위 5개 프로젝트 관리 도구를 가격, 주요 기능, 최적 사용 사례를 포함해 비교표로 만들어줘."

**4. '위 내용을 바탕으로...'로 체인 리서치**
초기 답변 후 후속 질문: "위 내용을 바탕으로 주의해야 할 잠재적 위험은?"

## Perplexity AI vs 구글 (2026)

대부분의 사실 기반, 리서치 중심 쿼리에서 Perplexity가 구글보다 선호되고 있습니다:

**Perplexity가 우위인 경우:**
- 여러 출처의 합성이 필요한 리서치
- 섬세하거나 기술적인 답변이 필요한 질문
- 학술 및 전문 리서치
- 출처를 확인해야 하는 모든 경우

**구글이 여전히 우위인 경우:**
- 로컬 검색 ("근처 맛집")
- 특정 웹사이트 찾기
- 쇼핑 및 가격 비교
- 실시간 이벤트 (스포츠 점수, 주가)
