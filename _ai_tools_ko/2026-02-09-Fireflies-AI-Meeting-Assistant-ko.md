## Fireflies.ai란?

Fireflies.ai는 회의를 자동으로 녹음, 트랜스크립션, 요약하는 **AI 기반 회의 어시스턴트**입니다. 화상 통화에 참가자로 참여해 모든 것을 캡처하고, 대화를 검색 가능하고 실행 가능한 노트로 변환합니다.

### 팀들이 Fireflies를 사랑하는 이유

- **자동 녹음**: Zoom, Google Meet, Teams 등에 참여
- **정확한 트랜스크립션**: 화자 식별과 함께 90%+ 정확도
- **AI 요약**: 핵심 포인트, 액션 아이템, 결정사항 추출
- **검색 가능한 히스토리**: 키워드 검색으로 모든 대화 찾기
- **통합 준비**: 50개 이상 도구와 연결 (Slack, Notion, CRM)

## 작동 방식

### 1. 캘린더 연결

Fireflies가 캘린더를 읽고 예약된 회의에 자동 참여:

```
1. fireflies.ai에서 가입
2. Google Calendar 또는 Outlook 연결
3. 회의 접근 권한 부여
4. Fireflies가 회의에 자동 참여
```

### 2. 봇이 통화에 참여

"Fireflies.ai Notetaker"라는 참가자가 회의에 참여:

- Zoom, Google Meet, Microsoft Teams, Webex와 작동
- 오디오(활성화 시 비디오도) 녹음
- 백그라운드에서 조용히 실행

### 3. 노트 받기

회의 종료 후 Fireflies가 녹음 처리:

- **트랜스크립트**: 타임스탬프와 함께 단어 단위 트랜스크립션
- **요약**: AI가 생성한 핵심 포인트 개요
- **액션 아이템**: 통화 중 언급된 작업
- **토픽**: 논의 주제 자동 분류

## 주요 기능

### 1. 스마트 검색

모든 회의에서 무엇이든 찾기:

```
검색: "Q4 예산 논의"
결과: 예산이 논의된 3개 회의, 정확한 타임스탬프와 함께
```

### 2. AI 필터

회의에 대해 질문하기:

- "존이 타임라인에 대해 뭐라고 했어?"
- "나에게 할당된 액션 아이템이 뭐야?"
- "이번 달 모든 마케팅 논의 요약해줘"

### 3. 토픽 트래커

논의 주제 자동 감지 및 분류:

- 가격 논의
- 기술적 이슈
- 고객 피드백
- 다음 단계
- 블로커

### 4. 대화 인텔리전스

회의 역학에 대한 인사이트:

- 말하기 비율 (누가 가장 많이 말했나)
- 질문 빈도
- 감정 분석
- 참여 지표

### 5. 사운드바이트

중요한 순간 클립 및 공유:

```
[00:15:32] "Q2 출시 목표, 4월 15일 이전"
→ 이 사운드바이트를 Slack으로 팀과 공유
```

## 사용 사례

### 1. 영업팀

고객 세부사항 놓치지 않기:

```
영업 통화 후 → Salesforce에 자동 동기화
- 연락처에 회의 요약 추가
- 액션 아이템을 작업으로 생성
- 키워드 플래그 (경쟁사 언급, 이의)
```

### 2. 제품팀

사용자 리서치 캡처:

- 사용자 인터뷰 녹음
- 모든 피드백에서 패턴 검색
- 엔지니어링에 사운드바이트 공유
- 시간에 따른 기능 요청 추적

### 3. 매니저

모든 회의에 참석하지 않고도 정보 파악:

- 팀 회의의 AI 요약 받기
- 리포트에 할당된 액션 아이템 추적
- 1:1 전 대화 검토
- 회의 효율성 이슈 식별

### 4. 법무 & 컴플라이언스

공식 기록 생성:

- 타임스탬프가 있는 트랜스크립트
- 화자 식별
- 보안 스토리지
- 내보내기 기능

### 5. 원격 팀

모두가 정렬되도록:

- 비동기 회의 따라잡기
- 검색 가능한 지식 베이스
- 시간대 간 하이라이트 공유
- "그 회의 놓쳤어" 마찰 줄이기

## 시작하기

### 빠른 설정 (5분)

```
1. fireflies.ai 방문해서 가입
2. 캘린더 연결 (Google/Outlook)
3. 어떤 회의를 녹음할지 선택
4. 알림 설정
5. 완료! Fireflies가 다음 회의에 참여
```

### 커스터마이징 옵션

- **자동 참여 규칙**: 내부만, 외부만, 모든 회의
- **알림 설정**: 실시간 또는 일일 다이제스트
- **프라이버시 제어**: 녹음 알림, 민감한 회의 숨기기
- **출력 형식**: 트랜스크립트, 요약, 또는 둘 다

## 프로 팁

### 1. 커스텀 토픽 생성

자동 플래그할 키워드 설정:

```
토픽: "가격", "경쟁사", "블로커", "데드라인"
→ 회의에서 이런 것들이 나오면 알림 받기
```

### 2. Chrome 확장 프로그램 사용

캘린더 통합 없이 임시 통화 녹음:

- 확장 프로그램 클릭
- 녹음 시작
- 오디오가 있는 모든 브라우저 탭에서 작동

### 3. 지식 베이스 구축

시간이 지나면 Fireflies가 팀의 기억이 됩니다:

- "API 재설계에 대해 뭘 결정했었지?"
- 수개월의 회의를 즉시 검색

### 4. Slack과 통합

팀 채널에 요약 자동 게시:

```
#sales-calls → 모든 고객 통화 요약
#engineering → 기술 논의 하이라이트
```

## 한계점

- **봇 가시성**: 일부 고객이 불편해할 수 있음
- **오디오 품질 의존**: 안 좋은 오디오 = 안 좋은 트랜스크립션
- **학습 곡선**: 검색에서 가치 얻는 데 시간 필요
- **스토리지 제한**: 무료 티어 빨리 참

## 결론

Fireflies.ai는 **회의에 빠져 있는 팀에게 필수**입니다. 자동 녹음, 정확한 트랜스크립션, AI 기반 요약의 조합이 주당 몇 시간을 절약합니다. 영업팀에게는 게임 체인저이고, 연속 회의가 있는 누구에게나 정신 건강 구원자입니다.

### Fireflies를 사용해야 할 사람

✅ 고객 대화를 추적하는 영업팀
