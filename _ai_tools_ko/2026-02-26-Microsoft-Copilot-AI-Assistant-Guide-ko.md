# Microsoft Copilot: 이미 사용하는 모든 것에 내장된 AI 어시스턴트

![컴퓨터와 생산성 도구가 있는 현대적인 사무실 작업 공간](https://images.unsplash.com/photo-1633419461186-7d40a38105ec?w=800)
*Photo by [Microsoft](https://unsplash.com/@microsoft) on Unsplash*

Microsoft Copilot은 어디에나 있습니다. 선도적인 AI 챗봇을 구동하는 것과 동일한 GPT-4 모델을 기반으로 구축된 Copilot은 수십억 명이 매일 사용하는 도구 — Windows, Word, Excel, PowerPoint, Outlook, Teams, Edge — 에 깊이 내장되어 있습니다. Microsoft 생태계 안에 있다면, Copilot이 당장 가장 유용한 AI 업그레이드가 될 수 있습니다.

## Microsoft Copilot이란?

Microsoft Copilot은 여러 형태로 제공되는 AI 어시스턴트입니다:

- **Copilot (무료)** – bing.com, Windows 11, Copilot 앱의 AI 어시스턴트
- **Copilot Pro** – Microsoft 365 통합이 강화된 Copilot (월 $20/사용자)
- **Microsoft 365 Copilot** – 모든 M365 앱에 걸친 전체 기업 통합 (월 $30/사용자)
- **보안용 Copilot** – AI 기반 사이버보안 (기업 가격)
- **GitHub Copilot** – AI 코딩 어시스턴트 (별도 제품)

모든 버전은 Microsoft 자체 확장 기능을 갖춘 OpenAI의 GPT-4 패밀리로 구동됩니다.

## Copilot 시작하기

### 접근 경로

**Windows 11:**
- `Win + C`를 눌러 Copilot 사이드바 열기
- 작업 표시줄에서 Copilot 아이콘 클릭
- 모든 앱에서 텍스트 선택 후 우클릭 → "Copilot에 묻기"

**Microsoft Edge:**
- 툴바에서 Copilot 아이콘 (✦) 클릭
- 읽고 있는 웹페이지에 대해 질문
- "작성" 모드로 콘텐츠 작성

**Bing.com:**
- bing.com/chat 방문
- 소스 인용과 함께 AI 강화 검색

**Microsoft 365 앱:**
- 리본에서 Copilot 버튼 찾기
- Word, Excel 등에 나타나는 Copilot 사이드바 사용

### Copilot 무료 — 주요 기능

유료 구독 없이도 Copilot은 강력한 기능을 제공합니다:

**1. 대화형 AI (GPT-4o)**
무엇이든 질문 — 조사, 글쓰기, 수학, 코딩, 분석.

**2. 웹 검색 + AI 종합**
Copilot이 웹을 검색하고 인용과 함께 답변을 종합합니다 — Perplexity와 유사.

**3. 이미지 생성 (DALL-E 3)**
Bing Image Creator를 통해 자연어 프롬프트로 하루 최대 15개의 이미지 생성.

**4. 노트북 모드**
더 긴 컨텍스트 (최대 18,000단어)의 경우 대용량 문서 심층 분석을 위해 노트북으로 전환.

**5. 플러그인 및 액션**
- 항공편, 호텔, 레스토랑 검색
- 날씨 예보 받기
- 이미지 콜라주 생성
- 업로드된 이미지 분석

## Microsoft 365 앱의 Copilot

### Word의 Copilot

문서 작성 및 편집 방식 변환:

**Copilot으로 초안 작성:**
1. Word 열기, "Copilot으로 초안 작성" 클릭
2. 필요한 것 설명: "영업 성과, 과제, 2분기 목표를 다루는 분기별 비즈니스 리뷰용 500단어 경영진 요약 작성"
3. Copilot이 완전한 초안 생성
4. 필요에 따라 편집, 다듬기, 섹션 재생성

**재작성 및 변환:**
- 텍스트 선택 → Copilot 사이드바 → "재작성"
- 톤 변경: 격식체 → 대화체, 또는 반대
- 긴 문서를 글머리 기호로 요약
- 섹션을 다른 언어로 번역

**파일 참조:**
Microsoft 365에서 `/`를 입력하여 다른 문서, 이메일 또는 회의 참조:
- "[/프로젝트 브리프.docx]의 핵심 사항 요약"
- "[/회의-노트.docx]를 기반으로 후속 이메일 초안 작성"

**시도해볼 명령:**
```
모바일 앱 개발 프로젝트 제안서를 초안 작성해 줘,
타임라인, 예산, 팀 구조 포함

이 문서를 경영진 대상 5개 글머리 기호로 요약해 줘

이 단락을 더 설득력 있고 행동 지향적으로 재작성해 줘

이 문서의 문법, 명확성, 일관성 문제를 확인해 줘
```

### Excel의 Copilot

자연어로 데이터 분석 및 조작:

**수식 생성:**
- 셀 클릭 → Copilot → "수식 생성"
- "각 제품 카테고리의 전년 대비 성장률 계산"
- Copilot이 정확한 수식을 작성하고 설명

**데이터 인사이트:**
1. 데이터 범위 선택
2. 리본에서 Copilot 클릭
3. "이 판매 데이터의 주요 추세는 무엇인가요?"
4. Copilot이 패턴, 이상값, 인사이트 강조

**데이터 정제:**
- "B열의 중복 항목 식별 및 강조"
- "A열의 모든 날짜를 YYYY-MM-DD 형식으로 변환"
- "누락된 값을 열 평균으로 채우기"

**차트 생성:**
- "지역별 월간 수익을 보여주는 차트 생성"
- "분기별 제품 성과를 비교하는 피벗 테이블 작성"

**유용한 프롬프트:**
```
이 데이터를 분석하고 상위 3개 제품 식별

평균 주문 가치, 구매 빈도, 고객 수명을 기반으로
고객 생애 가치를 계산하는 수식 생성

평균에서 2 표준 편차 이상인 셀 강조

지역별, 월별 판매를 보여주는 요약 테이블 작성
```

### PowerPoint의 Copilot

어느 때보다 빠르게 프레젠테이션 생성:

**프롬프트에서 생성:**
1. PowerPoint 열기 → "프레젠테이션 생성"
2. 입력: "지속 가능한 패션 스타트업을 위한 10슬라이드 피치 덱 생성, 문제, 솔루션, 시장 규모, 비즈니스 모델, 견인력 포함"
3. Copilot이 레이아웃, 콘텐츠, 시각 자료 제안이 포함된 전체 프레젠테이션 생성

**문서에서 생성:**
1. "[/제품 로드맵.docx]에서 프레젠테이션 생성"
2. Copilot이 문서를 구조화된 프레젠테이션으로 변환

**기존 슬라이드 개선:**
- 슬라이드 선택 → "더 시각적으로 만들기"
- "이 슬라이드에 발표자 노트 추가"
- "이 콘텐츠에 더 나은 레이아웃 제안"
- "모든 슬라이드의 일관성 확인"

### Outlook의 Copilot

이메일을 더 효율적으로 관리:

**이메일 초안 작성:**
1. "새 이메일" 클릭 → Copilot → "Copilot으로 초안 작성"
2. 이메일 설명: "지난주 제안서를 요청한 클라이언트에게 지연을 인정하고 금요일까지 전달을 약속하는 후속 이메일 작성"
3. 톤 설정: 직접적, 캐주얼, 격식, 중립
4. 길이 설정: 짧음, 보통, 길음

**이메일 요약:**
- 긴 이메일 스레드 열기 → Copilot → "요약"
- 몇 초 만에 핵심 포인트와 실행 항목 추출

**코칭:**
- 이메일 작성 → Copilot → "Copilot 코칭"
- 톤, 명확성, 감성에 대한 피드백
- "이 이메일은 공격적으로 보일 수 있습니다 — 더 부드러운 버전입니다"

### Teams의 Copilot

Microsoft 365 Copilot 구독자를 위한:

**회의 인텔리전스:**
- 실시간 전사 및 번역
- 사이드바에서 실시간 회의 요약
- "따라잡기" — 늦게 참여하면 즉시 컨텍스트 받기
- 회의 후: 전체 노트, 결정 사항, 실행 항목

**채팅 요약:**
- "이번 주 이 채널의 대화 요약"
- "제품 출시에 대해 어떤 결정이 내려졌나요?"
- "나에게 할당된 모든 실행 항목 찾기"

**비즈니스 채팅:**
- 교차 앱 AI: 이메일, 회의, 채팅, 파일 전체 검색
- "최근 세 번의 회의에서 4분기 예산에 대해 무엇을 논의했나요?"
- "이번 달 공유된 프로젝트 피닉스 관련 모든 문서 찾기"

## Copilot 프롬프트 모범 사례

### PROSE 프레임워크

- **P**ersonalize (개인화): 역할 설정 ("제품 관리자로서…")
- **R**esult (결과): 원하는 것 정의 ("1페이지 경영진 브리프 작성…")
- **O**verview (개요): 맥락 제공 ("…새 모바일 앱 출시에 대해…")
- **S**tyle (스타일): 형식 지정 ("…글머리 기호, 격식 있는 톤…")
- **E**xample (예시): 참조 제공 ("…[파일]과 유사한 형식으로")

### 예시 고품질 프롬프트

**Word용:**
> "당신은 비즈니스 컨설턴트입니다. 연간 보고서를 위한 2페이지 경영진 요약을 작성해 주세요: 1) 재무 하이라이트 2) 주요 성과 3) 내년 전략 우선순위 4) 과제와 대응 방법. 톤: 전문적이고 낙관적. 형식: 각 3-4개의 글머리 기호가 있는 소제목."

**Excel용:**
> "날짜, 지역, 제품, 수익, 단위 열이 있는 판매 데이터셋이 있습니다. 다음을 포함한 종합 분석을 만들어 주세요: 월별 추세, 수익 기준 상위 제품, 지역별 성과 비교, 이상값 식별. 결과를 글머리 기호로 제시."

**PowerPoint용:**
> "시리즈 A 자금 조달 라운드를 위한 12슬라이드 투자자 프레젠테이션 생성. 포함: 경영진 요약, 문제, 솔루션, 제품 데모 개요, 시장 기회 ($500억 TAM), 비즈니스 모델, 견인력 (사용자 1만 명, MRR $10만), 팀, 자금 사용처, 마무리. 전문적이고 미니멀한 디자인."

## 개인정보 보호 및 데이터 보안

Microsoft는 기업 고객을 위해 중요한 약속을 했습니다:
- **데이터 거주지**: 데이터는 Microsoft 365 테넌트에 유지
- **훈련 없음**: 프롬프트와 출력은 Copilot 훈련에 사용되지 않음
- **컴플라이언스**: M365 컴플라이언스 정책 (ISO 27001, SOC 2, GDPR) 상속
- **관리자 컨트롤**: IT가 사용자 또는 그룹별로 Copilot 활성화/비활성화 가능
- **감사 로그**: 모든 Copilot 상호작용이 컴플라이언스를 위해 기록됨

## 제한 사항

- **컨텍스트 창**: 대용량 컨텍스트에서도 매우 긴 문서 분석이 잘릴 수 있음
- **환각**: Copilot은 실수를 할 수 있음 — 중요한 출력은 항상 확인
- **가용성**: 일부 기능은 M365 비즈니스/엔터프라이즈 라이선스 필요
- **실시간 아님**: M365 앱의 Copilot은 실시간 데이터를 위해 웹을 검색하지 않음
- **학습 곡선**: 최선의 결과를 얻으려면 프롬프트 기술 개발 필요

## 결론

Microsoft Copilot은 Microsoft 생태계에서 사는 사람들을 위한 AI 어시스턴트입니다. Word에서 글쓰기, Excel에서 수치 분석, PowerPoint에서 프레젠테이션, Outlook과 Teams에서 커뮤니케이션 관리 등 어디서든 Copilot이 함께합니다 — 컨텍스트를 인식하고, 통합되어 있으며, 놀랍도록 강력합니다. 이미 Microsoft 365 비용을 지불하는 조직의 경우 Copilot의 생산성 향상은 일반적으로 첫 달 안에 추가 사용자당 비용을 정당화합니다.
