# Superhuman: 인박스 제로를 달성하게 해주는 AI 이메일 클라이언트

![Superhuman 이메일](https://images.unsplash.com/photo-1563986768494-4dee2763ff3f?w=800)
*Photo by [Solen Feyissa](https://unsplash.com/@solenfeyissa) on Unsplash*

이메일은 여전히 전문가들의 가장 큰 생산성 저하 요인 중 하나입니다. **Superhuman**은 빠른 성능과 이메일 처리 속도를 2배로 높여주는 AI 기능으로 이를 바꾸겠다고 약속합니다.

## Superhuman이란?

Superhuman은 고성능 전문가를 위해 설계된 프리미엄 이메일 클라이언트입니다:

- **속도 우선 설계** - 100ms 미만 인터랙션
- **키보드 중심 워크플로우** - 마우스 터치 불필요
- **AI 기반 기능** - 스마트한 작성과 정리
- **아름다운 인터페이스** - 깔끔하고 방해 없는 디자인

## 왜 Superhuman인가?

### 이메일 문제

평균적인 전문가는:
- 업무 시간의 28%를 이메일에 사용
- 하루 74번 이메일 확인
- 이메일 알림 후 업무 복귀까지 64초 소요

### Superhuman의 솔루션

- 설계에 내장된 **인박스 제로** 마인드셋
- 자동 분류하는 **스플릿 인박스**
- 더 빠르고 스마트하게 작성하는 **AI 기능**
- 모든 것에 대한 **키보드 단축키**

## 주요 기능

### 1. Superhuman AI

**AI로 작성:**
- 요점에서 전체 이메일 초안 작성
- 다른 톤으로 다시 쓰기
- 문법 수정 및 다듬기
- 텍스트 줄이기 또는 늘리기

**자동 요약:**
- 긴 이메일 스레드 즉시 요약
- 대화 빠르게 따라잡기
- 핵심 포인트 놓치지 않기

### 2. 스플릿 인박스

들어오는 이메일 자동 분류:
- **중요** - 실제 사람에게서 온 것
- **기타** - 뉴스레터, 알림, 프로모션
- **커스텀 분류** - 자신만의 카테고리 생성

### 3. 키보드 퍼스트 설계

모든 액션에 키보드 단축키:

| 액션 | 단축키 |
|------|--------|
| 아카이브 | E |
| 답장 | R |
| 전체 답장 | A |
| 전달 | F |
| 실행 취소 | Z |
| 완료 표시 | E |
| 스누즈 | H |
| 리마인드 | H |

### 4. 읽음 확인 & 인사이트

수신자가 언제:
- 이메일을 열었는지
- 링크를 클릭했는지
- 데스크탑 또는 모바일로 읽었는지

인사이트를 활용해 완벽한 타이밍에 팔로업하세요.

### 5. 스니펫

재사용 가능한 텍스트 템플릿 생성:

```
/intro → 소개 이메일 전체
/meeting → 미팅 요청 템플릿
/followup → 팔로업 메시지
```

### 6. 예약 발송

최적의 시간에 이메일 발송:
- 업무 시간에 예약
- 수신자 시간대 맞추기
- 발송 시간 A/B 테스트

## 시작하기

### 1단계: 접근 요청

Superhuman은 대기자 명단이 있습니다. [superhuman.com](https://superhuman.com)에서 접근을 요청하세요.

### 2단계: 온보딩 콜

신규 사용자는 30분 온보딩 콜을 받습니다:
- 키보드 단축키 학습
- 인박스 설정
- 환경설정 구성

### 3단계: 단축키 마스터

단축키 학습에 시간을 투자하세요. 투자 대비 기하급수적으로 보상됩니다.

### 4단계: 스플릿 인박스 구성

노이즈를 줄이기 위한 자동 분류를 설정하세요.

## AI 작성 기능

### AI로 초안 작성

1. `Cmd+J`로 AI 열기
2. 의도 입력: "이 미팅 정중하게 거절해줘"
3. AI가 이메일 초안 작성
4. 편집 후 발송

### 다시 쓰기

텍스트 선택 후 AI로:
- 더 짧게
- 더 길게
- 톤 변경 (격식, 친근, 직접적)
- 문법 수정

### 자동 완성

Superhuman이 작성 스타일을 학습하여 제공:
- 문구 완성
- 일반적인 응답 패턴
- 개인화된 제안

## 파워 유저 팁

### 1. 커맨드 팔레트 활용

`Cmd+K`를 눌러 특정 단축키를 기억하지 않고도 모든 기능에 접근하세요.

### 2. 스누즈 마스터

`H`로 이메일 스누즈:
- 오늘 나중에
- 내일
- 이번 주말
- 다음 주
- 특정 날짜

### 3. VIP 분류 생성

다음을 위한 분류 설정:
- 상사
- 주요 클라이언트
- 중요 프로젝트

### 4. 배치 처리

이메일 처리 특정 시간 설정:
- 아침 (오전 8시)
- 점심 후 (오후 1시)
- 퇴근 시 (오후 5시)

하루 종일 계속 확인하는 것 피하기.

## 누가 Superhuman을 사용해야 할까?

**적합한 사람:**
- 하루 100+ 이메일 받는 임원
- 아웃리치 추적하는 영업 전문가
- 다양한 이해관계자 관리하는 창업자
- 시간당 $50+ 가치가 있는 누구든

**적합하지 않은 사람:**
- 이메일 가볍게 사용하는 사람
- 예산 의식하는 사용자
- 고급 협업 기능 필요한 팀

## 한계점

- 높은 가격대
- 단축키 학습 곡선
- 주로 Gmail/Outlook만 지원
- 모바일 앱이 데스크탑보다 덜 강력
- 캘린더 통합 없음 (아직)

## 결론

Superhuman은 단순한 이메일 클라이언트가 아닙니다—생산성 시스템입니다. 빠른 속도, 사려 깊은 디자인, AI 기능의 조합은 실제로 기분 좋은 이메일 경험을 만들어냅니다.

월 $30 가격은 모든 사람을 위한 것은 아니지만, 이메일에 빠져 있는 전문가에게는 시간 절약이 빠르게 비용을 정당화합니다. 이메일이 업무의 상당 부분이라면, Superhuman은 체험해볼 가치가 있습니다.
