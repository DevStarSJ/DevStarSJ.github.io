# Otter.ai: 한 마디도 놓치지 않는 AI 회의 어시스턴트 완벽 가이드

하루 종일 연속 회의에 참석합니다. 오후 5시가 되면 결정사항의 절반을 잊어버리고 액션 아이템 세 개를 기록하지 못했습니다. Otter.ai는 이 문제를 정확히 해결하기 위해 존재합니다 — 모든 회의를 자동으로 전사, 요약하고 액션 아이템을 추출합니다.

## Otter.ai란 무엇인가?

Otter.ai는 Zoom, Google Meet, Microsoft Teams 통화에 참여해 실시간으로 대화를 녹음·전사·요약하는 AI 기반 회의 어시스턴트입니다. 발언자를 식별하고 핵심 순간을 강조하며 액션 아이템이 포함된 회의 요약을 자동 생성합니다.

**핵심 기능:**
- 발언자 식별 기능이 있는 실시간 전사
- AI 자동 회의 요약 생성
- 액션 아이템 추출
- 검색 가능한 회의 라이브러리
- 회의와 대화하기 (OtterPilot AI)
- 통합: Zoom, Google Meet, Teams, Slack, Salesforce

---

## Otter.ai 작동 방식

### 1. OtterPilot (봇 참가자)
Otter의 AI 봇이 자동으로 회의에 참가합니다:
- 오디오 녹음
- 실시간 전사
- 각 발언자 식별 및 레이블 지정
- 주제 및 키워드 강조

회의 중 수동 설정 필요 없음 — OtterPilot이 모든 것을 처리합니다.

### 2. 실시간 전사
사람들이 말하는 대로 텍스트가 나타납니다. 참석하지 못한 팀원이 실시간으로 따라갈 수 있습니다:
- 접근성 (청각 장애 팀원)
- 영어가 모국어가 아닌 글로벌 팀
- 빠른 논의 중 참고용

### 3. AI 회의 요약
회의 후 Otter가 자동으로 생성:
- **압축 요약** (단락 형식)
- **타임스탬프가 있는 개요**
- **액션 아이템** (누가, 무엇을, 언제)
- **결정된 주요 사항**

### 4. AI 채팅 (OtterPilot Q&A)
```
나: 예산에 대해 어떤 결정을 했나요?
Otter: 23:14에 Sarah가 Q2 마케팅 예산을 
       CFO 승인 조건으로 $150K로 제한할 것이라고 확인했습니다.
```

과거 모든 회의에 대해 질문하고 인용된 즉각적인 답변을 받으세요.

## Otter.ai 설정하기

### 1단계: 계정 만들기
1. [otter.ai](https://otter.ai)에 접속
2. Google/Microsoft로 가입 (캘린더 동기화를 위해 권장)

### 2단계: 캘린더 연결
- 설정 → 캘린더 → Google 캘린더/Outlook 연결
- Otter가 다가오는 회의를 자동으로 감지하고 참가 제안

### 3단계: OtterPilot 활성화
- 설정 → OtterPilot → 회의 자동 참가
- 선택: "모든 회의" 또는 "내가 주최자인 경우만"

### 4단계: 회의로 테스트
- Zoom/Meet 통화 시작
- OtterPilot이 30초 이내에 참가
- otter.ai에서 실시간 전사 확인

## 주요 기능 심층 분석

### 발언자 식별
Otter가 시간이 지나면서 목소리를 인식합니다. 몇 번의 회의 후:
- 이름으로 발언자 레이블 지정
- 이후 회의에서 자동으로 이름 할당
- 각 세션마다 정확도 향상

### 회의 템플릿
다양한 회의 유형에 맞는 맞춤 요약 템플릿 생성:
- **스탠드업**: 어제 / 오늘 / 블로커
- **영업 전화**: 고충 / 예산 / 결정 타임라인
- **1:1**: 목표 / 피드백 / 액션

### Otter AI 채팅 (회의 간 검색)
```
"지난 달 John이 제품 로드맵에 대해 무슨 말을 했나요?"
"이번 분기 프로젝트 X에 대해 내린 모든 결정을 요약해줘."
```

자연어로 모든 회의를 검색하세요.

### Slack 통합
- 회의 후 관련 Slack 채널에 요약 자동 게시
- Otter에 가입하지 않아도 팀원이 요약 확인

## 모범 사례

### 회의 전
- 캘린더 초대에 회의 어젠다 추가 — Otter가 컨텍스트로 활용
- OtterPilot이 참가 예정인지 확인

### 회의 중
- 특정 항목 캡처 요청: *"Otter, 이 액션 아이템 기록해줘"*
- 실시간으로 별 클릭해 중요한 순간 강조

### 회의 후
- 24시간 이내에 액션 아이템 검토
- 이해관계자에게 전체 전사록 대신 요약 링크 공유
- 잘못 식별된 발언자 수정

### 원격/하이브리드 팀
- 원격 참석자가 따라갈 수 있도록 실시간 전사 링크 공유
- "무슨 말을 했는지 들었어요?" 메시지 대신 Q&A 기능 사용

## 한계점

- **정확도**: 약 90–95% 정확도; 강한 억양과 기술 용어는 정확도를 낮춤
- **언어**: 영어에서 최고; 한국어, 스페인어, 프랑스어 등 지원하지만 정확도 낮음
- **소음 민감도**: 배경 소음이 전사 품질 저하
- **동영상 녹음 없음**: 오디오와 전사만 (Grain처럼 동영상 없음)
