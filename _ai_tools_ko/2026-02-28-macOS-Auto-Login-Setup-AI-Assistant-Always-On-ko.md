맥미니에 AI 어시스턴트나 홈 서버를 올려놨다면 한 번쯤 이런 상황을 겪었을 거예요. 정전이 났다 복구되거나, 맥이 재부팅됐는데 AI한테 연락이 안 됨. 원인은 맥OS가 로그인 화면에서 멈춰서 당신을 기다리고 있기 때문이에요.

이 글에서는 그 문제를 딱 한 번에 해결하는 방법을 알려드려요. **자동 로그인**을 설정하면 전원을 꽂는 것만으로 맥이 알아서 로그인하고 서비스들이 올라옵니다.

---

## 왜 이런 일이 생기나요?

맥OS는 사용자 레벨 서비스를 **LaunchAgent**라는 방식으로 자동 시작합니다. 문제는 LaunchAgent가 *사용자가 로그인한 다음에야* 실행된다는 거예요. 로그인 화면에서 멈춰 있으면 아무것도 시작되지 않아요.

보안 때문에 의도적으로 설계된 동작이지만, 헤드리스 맥미니나 항상 켜두는 홈 서버 용도로는 그냥 걸림돌이죠.

---

## 1단계: FileVault 상태 확인

FileVault는 맥OS의 전체 디스크 암호화 기능이에요. 보안엔 좋지만 **자동 로그인을 막습니다**. 부팅 시 디스크 복호화에 비밀번호가 필요하기 때문이에요.

터미널에서 상태를 확인해보세요:

```bash
fdesetup status
```

결과는 둘 중 하나예요:
- `FileVault is On.` — 먼저 꺼야 해요
- `FileVault is Off.` — 바로 2단계로 가세요

---

## 2단계: FileVault 끄기 (켜져 있는 경우)

FileVault가 켜져 있다면:

1. **시스템 설정** 열기
2. **개인 정보 보호 및 보안** 선택
3. 아래로 스크롤해서 **FileVault** 찾기
4. **끄기…** 클릭
5. 안내에 따라 진행 후 재시작

> ⚠️ **보안 참고:** FileVault를 끄면 디스크 암호화가 해제돼요. 집 안에 잠겨 있는 맥미니라면 충분히 감수할 만한 트레이드오프입니다. 노트북이나 공유 환경이라면 신중하게 판단하세요.

디스크 복호화는 용량에 따라 시간이 걸릴 수 있어요. 복호화 중에도 맥은 계속 사용할 수 있습니다.

---

## 3단계: 자동 로그인 설정

FileVault가 꺼졌으면:

1. **시스템 설정** 열기
2. **일반 → 사용자 및 그룹** 선택
3. **자동으로 다음으로 로그인** (또는 **자동 로그인**) 드롭다운 찾기
4. 사용할 계정 선택
5. 로그인 비밀번호 입력
6. **확인** 클릭

끝이에요. 다음 재부팅이나 전원 연결 후엔 맥OS가 자동으로 로그인합니다. 키보드 필요 없어요.

---

## 4단계: 서비스 자동 시작 확인

**OpenClaw**나 다른 LaunchAgent 기반 서비스를 쓰고 있다면, 로그인 시 자동 시작하도록 이미 설정되어 있을 거예요. 재부팅 후 상태를 확인해보세요:

```bash
openclaw status
```

다른 LaunchAgent라면:

```bash
launchctl list | grep <서비스-이름>
```

---

## 보너스: 원격 접속도 해두면 더 좋아요

자동 로그인과 함께 원격 접속까지 설정해두면 만약의 상황에서 맥을 원격으로 관리할 수 있어요:

- **원격 로그인 (SSH):** 시스템 설정 → 일반 → 공유 → 원격 로그인
- **화면 공유 (VNC):** 시스템 설정 → 일반 → 공유 → 화면 공유

SSH + 자동 로그인 조합이면 전원만 꽂아도 서비스 시작, 문제 생겨도 원격으로 확인 — 완벽한 헤드리스 서버 셋업이 됩니다.

## 요약

| 단계 | 작업 |
|------|------|
| 1 | FileVault 상태 확인: `fdesetup status` |
| 2 | 켜져 있으면 비활성화 (개인 정보 보호 및 보안 설정) |
| 3 | 사용자 및 그룹에서 자동 로그인 활성화 |
| 4 | 재부팅 후 서비스 정상 시작 확인 |

설정 한 번 해두면 그 다음부터는 전선 꽂는 것만으로 충분해요. 1~2분 안에 AI 어시스턴트가 알아서 올라와 있을 거예요.
