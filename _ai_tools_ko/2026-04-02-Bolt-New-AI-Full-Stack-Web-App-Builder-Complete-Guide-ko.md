## Bolt.new란?

Bolt.new는 StackBlitz의 **WebContainers 기술**을 기반으로 하는 브라우저 기반 AI 개발 환경입니다. 브라우저 탭 안에서 완전한 Node.js 환경이 실행됩니다 — 클라우드 VM도, 로컬 설치도 필요 없습니다.

핵심 차별점:
- **풀스택 실행**: 단순 코드 생성이 아니라 브라우저에서 앱을 실제로 실행
- **반복 빌드**: AI와 대화하며 개선, 버그 수정, 기능 추가 가능
- **원클릭 배포**: Netlify나 Cloudflare Pages로 즉시 프로덕션 배포
- **프레임워크 무관**: React, Vue, Svelte, Next.js, Astro 등 지원
- **패키지 설치**: npm 패키지가 브라우저 안에서 실시간으로 설치됨

## 무엇을 만들 수 있나?

Bolt.new가 특히 잘 하는 것들:
- **랜딩 페이지** 및 마케팅 사이트
- **SaaS 대시보드** (데이터 시각화 포함)
- **CRUD 앱** (데이터베이스 연결 포함)
- **API 연동** (Stripe, Supabase, Firebase 등)
- **이커머스 스토어**
- **관리자 패널**
- **포트폴리오 사이트**
- **아이디어 검증용 프로토타입**

구체적일수록 결과가 좋아집니다.

"모바일에서 내비게이션 메뉴가 링크 클릭 후 닫히지 않아 — 고쳐줘"

Bolt는 이전 대화 맥락을 이해하므로 앱 전체를 다시 쓰지 않고 요청한 부분만 수정합니다.

## 핵심 기능 자세히 살펴보기

### WebContainers: 비밀 무기
ChatGPT나 Copilot 같은 전통적인 AI 코딩 도구는 코드를 생성하지만 실행은 못 합니다. Bolt는 브라우저 탭 안에 살아있는 **WebContainer** — 샌드박스 Node.js 환경에서 코드를 실행합니다.

이것이 의미하는 바:
- 실시간 라이브 프리뷰
- 에러를 즉시 감지
- AI가 실제 에러 출력을 보고 자동으로 수정
- "내 컴퓨터에선 잘 됐는데" 문제 없음

### 멀티 파일 프로젝트 관리
Bolt는 복잡한 프로젝트 구조를 관리합니다:

```
my-saas-app/
├── src/
│   ├── components/
│   │   ├── Header.tsx
│   │   ├── Dashboard.tsx
│   │   └── Sidebar.tsx
│   ├── pages/
│   │   ├── index.tsx
│   │   └── settings.tsx
│   ├── lib/
│   │   └── supabase.ts
│   └── styles/
│       └── globals.css
├── public/
├── package.json
└── next.config.js
```

파일 트리에서 직접 파일을 편집하면서 AI 채팅으로 더 큰 변경도 할 수 있습니다.

### 자동 오류 복구
앱에서 오류가 발생하면 Bolt가 자동으로 수정할 수 있습니다:

1. 프리뷰 패널에 오류 표시
2. Bolt가 오류 메시지 감지
3. "Fix Error" 클릭 또는 수정 내용 설명
4. AI가 문제 파일을 패치

이 피드백 루프는 기존 디버깅보다 훨씬 빠릅니다.

**언제 Bolt.new를 쓸까 vs 대안:**
- **Bolt.new**: 빠른 프로토타이핑, 데모, 처음부터 전체 앱
- **v0**: 기존 프로젝트에 React 컴포넌트만 필요할 때
- **Lovable**: 비기술자에게 더 친화적인 유사 도구
- **Cursor**: 기존 코드베이스로 전문 개발

## 한계점

- **복잡한 상태 관리**: Redux/Zustand 로직이 복잡한 대형 앱에서 AI가 혼란스러울 수 있음
- **커스텀 백엔드 로직**: 무거운 서버사이드 로직은 직접 개발하는 것이 나음
- **데이터베이스 마이그레이션**: 스키마 변경이 앱을 망가뜨릴 수 있음
- **긴 세션**: 매우 긴 채팅 히스토리는 AI가 컨텍스트를 잃게 할 수 있음
- **비용**: 많이 쓰면 크레딧이 빨리 소모됨

Bolt.new는 웹 애플리케이션 개발 방식에서 진정한 패러다임 전환을 이끌고 있습니다. 단순한 코드 생성기가 아니라 브라우저에서 실행되는 완전한 AI 기반 개발 환경입니다.
