## Bardeen이란?

Bardeen은 코드 작성 없이 웹사이트에서 반복 작업을 자동화할 수 있는 **브라우저 기반 자동화 플랫폼**입니다. 클릭하고, 복사하고, 폼을 채워주는 로봇 어시스턴트 같은 거죠 - 동적 웹 페이지를 처리하는 AI로 구동됩니다.

### Bardeen을 선택하는 이유

- **코드 불필요**: 포인트 앤 클릭으로 자동화 구축
- **AI 웹 스크래핑**: 어떤 웹사이트에서든 지능적으로 데이터 추출
- **브라우저 네이티브**: Chrome 확장 프로그램으로 실행
- **사전 제작 플레이북**: 500개 이상의 바로 사용 가능한 자동화
- **매직 박스**: 원하는 것을 일반 영어로 설명

## 작동 방식

### 1. 확장 프로그램 설치

```
1. bardeen.ai 방문
2. Chrome 확장 프로그램 설치
3. 무료 가입
4. 확장 프로그램을 툴바에 고정
```

### 2. 자동화 생성 또는 사용

**옵션 A: 사전 제작 플레이북 사용**
- 자동화 라이브러리 탐색
- "Use Playbook" 클릭
- 입력 커스터마이징
- 실행

**옵션 B: 직접 구축**
- 브라우저에서 액션 녹화
- 로직과 조건 추가
- 개인 자동화로 저장

**옵션 C: 매직 박스 (AI)**
- Ctrl+J 누르기
- 원하는 것을 영어로 설명
- Bardeen이 자동화 생성

## 주요 기능

### 1. 매직 박스 AI

Bardeen에게 일반 영어로 할 일을 알려주세요:

```
"이 LinkedIn 검색에서 모든 채용 공고를 스크래핑해서 Google Sheets에 저장해"

"새 고객에게서 이메일을 받으면, 그 정보로 Notion 페이지 만들어"

"매주 월요일, 이번 주 Google Calendar 요약을 보내줘"
```

### 2. 웹 스크래핑

코딩 없이 어떤 웹사이트에서든 데이터 추출:

- **자동 감지**: AI가 리스트, 테이블, 데이터 패턴 식별
- **페이지네이션 처리**: 여러 페이지에 걸쳐 스크래핑
- **동적 콘텐츠**: JavaScript가 많은 사이트에서도 작동
- **스케줄 스크래핑**: 일정에 따라 추출 실행

스크래핑된 데이터 예시:

| 이름 | 직함 | 회사 | LinkedIn URL |
|------|------|------|--------------|
| Jane Doe | VP Sales | TechCorp | linkedin.com/in/... |
| John Smith | CTO | StartupXYZ | linkedin.com/in/... |

### 4. 트리거

자동으로 자동화 시작:

- **시간 기반**: 매시간, 매일 오전 9시, 매주
- **웹 기반**: 특정 사이트 방문 시
- **앱 기반**: 이메일, Slack 메시지 수신 시
- **수동**: 클릭해서 실행

### 5. 스크래퍼 템플릿

인기 사이트용 사전 제작 추출기:

- LinkedIn (프로필, 회사, 채용)
- Product Hunt (제품, 메이커)
- Amazon (제품, 리뷰)
- Google (검색 결과, 지도)
- Twitter (프로필, 트윗)

## 사용 사례

### 1. 영업 잠재고객 발굴

자동으로 리드 목록 구축:

```
자동화 흐름:
1. LinkedIn Sales Navigator 검색 결과 방문
2. 모든 프로필 추출 (이름, 직함, 회사, 가능하면 이메일)
3. Google Sheets에 추가
4. 후속 조치를 위해 Salesforce에 작업 생성
```

**절약 시간**: 주당 3-4시간

### 2. 리서치 & 경쟁 인텔리전스

경쟁사 모니터링:

```
자동화 흐름:
1. 매일 경쟁사 가격 페이지 스크래핑
2. 어제 데이터와 비교
3. 가격 변경 시 Slack으로 알림
4. Airtable에 히스토리 기록
```

### 3. 채용

후보자 소싱 간소화:

```
자동화 흐름:
1. 취업 사이트에서 후보자 프로필 스크래핑
2. LinkedIn과 교차 참조
3. 기준에 따라 후보자 점수 매기기
4. 자격 있는 후보자를 ATS에 추가
```

### 4. 콘텐츠 큐레이션

콘텐츠 수집 자동화:

```
자동화 흐름:
1. RSS로 업계 블로그 모니터링
2. 새 글이 키워드와 매치하면 Notion에 저장
3. AI로 요약
4. 주간 뉴스레터 초안에 추가
```

### 5. 이커머스

제품과 가격 추적:

```
자동화 흐름:
1. 모니터링할 제품 URL 목록 구축
2. 매일 현재 가격 스크래핑
3. 가격이 임계값 아래로 떨어지면 알림 전송
4. 가격 히스토리 스프레드시트 유지
```

## 시작하기

### 첫 자동화: LinkedIn에서 Google Sheets로

```
1. LinkedIn 검색 결과 페이지 열기
2. Ctrl+J 누르기 (매직 박스)
3. 입력: "이 페이지의 모든 사람을 Google Sheets로 스크래핑해"
4. Bardeen이 자동화 생성
5. Run 클릭
6. Google Sheet 확인
```

### 커스텀 자동화 구축

단계별:

```
1. Bardeen 확장 프로그램 아이콘 클릭
2. "Create new automation" 선택
3. 트리거 선택 (수동, 스케줄 등)
4. 액션 추가:
   - 데이터 스크래핑
   - 폼 채우기
   - 버튼 클릭
   - 요소 대기
5. 목적지 앱에 연결
6. 저장하고 테스트
```

## 프로 팁

### 1. 변수 사용

자동화를 재사용 가능하게:

{% raw %}
```
대신: linkedin.com/in/specific-person 스크래핑
사용: {{LinkedIn URL}}을 스크래핑, URL은 입력값
```
{% endraw %}

### 2. 딜레이 추가

웹사이트를 존중하고 차단 방지:

```
액션: 프로필 스크래핑
대기: 2-5초 (랜덤)
액션: 다음 프로필
```

### 3. 에러 핸들링

자동화를 견고하게:

```
시도: "Load More" 버튼 클릭
없으면: 다음 단계로 계속
```

### 4. 수동 단계와 결합

모든 것을 자동화할 필요는 없습니다:

```
1. [자동] 후보자 목록 스크래핑
2. [수동] 검토하고 상위 10명 선택
3. [자동] 선택된 사람에게 개인화된 이메일 전송
```

## 한계점

- **Chrome만**: Firefox나 Safari 지원 없음
- **일부 사이트 차단**: 특히 LinkedIn은 안티스크래핑 조치 있음
- **머신에서 실행**: 스케줄 작업에는 컴퓨터가 켜져 있어야 함
- **학습 곡선**: 복잡한 자동화는 구축에 시간 필요
- **요율 제한**: 무료 티어 제한적

## 결론

Bardeen은 Zapier와 Make가 할 수 없는 **브라우저 레벨 자동화**의 빈틈을 채웁니다. 웹사이트를 클릭하고, 폼을 채우고, 데이터를 스크래핑하는 작업에 비교할 수 없습니다. 매직 박스 AI가 비기술 사용자에게도 접근 가능하게 하고, 사전 제작 플레이북이 즉시 시작할 수 있게 합니다.

### Bardeen을 사용해야 할 사람

✅ 잠재고객 목록을 구축하는 영업팀
✅ 후보자를 소싱하는 채용담당자
✅ 데이터를 수집하는 연구원
✅ 경쟁사를 추적하는 마케터
✅ 반복적인 브라우저 작업을 하는 모든 분

### Bardeen을 건너뛰어야 할 사람

❌ 서버 사이드 자동화가 필요한 분 (Zapier/Make 사용)
❌ Firefox/Safari 사용자
❌ 엄격한 IT 보안 정책이 있는 팀
