## Fireflies.ai란?

Fireflies.ai는 회의를 자동으로 녹음, 녹취, 분석하는 AI 회의 어시스턴트입니다. 화상 회의에 참가자로 참여하여 모든 것을 캡처하고 지능형 요약과 함께 검색 가능한 녹취록을 생성합니다.

**핵심 기능:**
- 자동 회의 녹음 및 녹취
- AI 생성 요약 및 액션 아이템
- 검색 가능한 대화 데이터베이스
- CRM 및 프로젝트 관리 연동
- 팀 협업 기능
- 대화 인텔리전스 분석

## 팀들이 Fireflies를 선택하는 이유

### 1. 회의 디테일 놓치지 않기

Fireflies가 모든 단어 캡처:
- 타임스탬프 포함 전체 녹취
- 화자 식별
- 사운드 바이트 추출
- 자동 하이라이트

### 2. 실행 가능한 인텔리전스

녹취를 넘어서:
- **액션 아이템** 자동 추출
- **핵심 주제** 식별 및 태그
- **감정 분석** 고객 통화용
- **발언 시간 분석** 팀 인사이트

### 3. 어디서나 연동

기존 스택과 호환:
- 화상: Zoom, Meet, Teams, Webex
- CRM: Salesforce, HubSpot
- PM: Asana, Trello, Notion
- 커뮤니케이션: Slack, Discord

## 시작하기

### 1단계: 계정 만들기

1. [fireflies.ai](https://fireflies.ai) 방문
2. Google 또는 이메일로 가입
3. 캘린더 연결 (Google/Outlook)
4. 자동 참가 설정

### 2단계: 자동 참가 설정

```
Settings → Auto-join
- 모든 회의 참가: ON/OFF
- 캘린더 회의만 참가: ON
- 확인 필요: 선택사항
- 참가할 회의 유형: 전체/선택
```

### 3단계: 연동 설정

**화상 회의:**
```
Integrations → Video Conferencing
- Zoom (OAuth 연결)
- Google Meet (캘린더 기반)
- Microsoft Teams (앱 설치)
```

**비즈니스 앱:**
```
Integrations → Business Apps
- CRM: Salesforce, HubSpot
- PM: Asana, Notion, Monday
- 스토리지: Google Drive, Dropbox
```

### 4단계: Fred (Fireflies 봇) 초대

수동 초대:
- 회의에 `fred@fireflies.ai` 추가
- Fred가 참가자로 참여
- 녹음 자동 시작

## 핵심 기능 상세

### 스마트 검색

모든 회의에서 무엇이든 찾기:


- **질문** - 회의 중 제기된 질문

3. 링크 공유 또는 임베드
4. 오디오 클립 다운로드

적합한 용도:
- 교육 자료

- 인사이트 공유
- 문서화

### 대화 인텔리전스

분석 대시보드 표시:

## 문제 해결

### Fred가 참가 안 함

**확인:**
- 캘린더 올바르게 연결됨
- 회의에 화상 링크 있음
- 회의 유형에 자동 참가 활성화
- 관리자 정책에 차단되지 않음

**해결:**
수동으로 `fred@fireflies.ai` 초대

### 녹취 품질 저하

**개선 방법:**
- 화상 앱에서 원본 오디오 활성화
- 품질 좋은 마이크 사용
- 배경 소음 줄이기
- 커스텀 어휘 추가

### 액션 아이템 누락

**확인:**
- 화자가 작업을 명확히 언급
- "액션 아이템" 또는 "할 일" 같은 문구 사용
