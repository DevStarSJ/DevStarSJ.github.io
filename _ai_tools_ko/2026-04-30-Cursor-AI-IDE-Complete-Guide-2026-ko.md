## Cursor란?

Cursor는 VS Code를 기반으로 만들어진 AI 퍼스트 코드 에디터입니다. 강력한 언어 모델을 편집 경험 안에 직접 통합하여, 코드베이스와 대화하고, 인라인으로 코드를 생성하고, AI 에이전트가 전체 파일을 리팩토링하거나 기능을 처음부터 끝까지 구현할 수 있습니다.

2023년에 출시된 후 수만 명의 개발자들에게 빠르게 채택되었으며, 현재는 현대 개발자의 필수 도구 중 하나로 자리잡았습니다.

## 주요 기능

### 1. 코드베이스와 대화 (Ctrl+L)
Cursor의 채팅 사이드바에서 전체 코드베이스에 대해 질문할 수 있습니다. "이 프로젝트에서 인증은 어떻게 동작해?"라고 입력하면 Cursor가 관련 파일을 읽고 정확한 맥락 기반 답변을 제공합니다.

### 2. 인라인 AI 편집 (Ctrl+K)
코드 블록을 선택하고 `Ctrl+K`를 누른 후 원하는 내용을 설명하세요. Cursor가 지시에 따라 선택 영역을 재작성합니다. 다음에 매우 강력합니다:
- 레거시 코드 리팩토링
- 프로그래밍 패러다임 간 변환
- 에러 처리 또는 로깅 추가
- 다른 언어로 코드 번역

### 3. Composer (Ctrl+I) — 멀티 파일 에이전트
Composer는 Cursor의 에이전트 모드입니다. 기능이나 작업을 설명하면, Cursor가 자율적으로 파일을 읽고, 여러 파일에 걸쳐 편집을 수행하며, 터미널 명령까지 실행하여 작업을 완료합니다.

### 4. 자동완성 (Tab)
Cursor의 자동완성은 단순한 다음 줄 예측이 아닙니다. 여러 줄 편집을 예측하고, 최근 편집 패턴을 기반으로 다음에 변경할 내용까지 예측합니다.

### 5. `.cursorrules` — 커스텀 지시
프로젝트 루트에 `.cursorrules` 파일을 만들어 AI에게 지속적인 컨텍스트를 제공하세요. 코딩 표준, 프레임워크 선택, 네이밍 컨벤션, 모델이 항상 알아야 할 모든 것을 담을 수 있습니다.

## Cursor를 최대한 활용하는 팁

1. **`.cursorrules`를 적극 활용하세요** — 기술 스택, 선호 패턴, 스타일 가이드를 상세히 작성하세요.
2. **채팅에서 `@` 기호 사용** — `@file`, `@folder`, `@web`, `@docs`로 정확한 컨텍스트를 제공하세요.
3. **큰 작업은 Composer로** — 새 기능을 만들 때는 Composer가 단계별로 계획하고 실행하게 하세요.
4. **모든 diff를 검토하세요** — Cursor는 빠르게 변경을 만듭니다. 수락 전 항상 검토하세요.
5. **채팅 + 인라인 조합** — 채팅으로 탐색하고, 인라인 편집으로 구체적인 변경을 실행하세요.
