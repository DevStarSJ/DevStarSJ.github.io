# Bardeen AI 완벽 가이드: 당신의 업무를 이해하는 브라우저 자동화 도구

대부분의 자동화 도구는 사용하기 전에 그 플랫폼을 배워야 합니다. **Bardeen**은 이것을 완전히 뒤집습니다 — 브라우저 확장 프로그램으로 살며, 당신이 어떻게 일하는지 보고, 단순히 원하는 것을 평범한 영어로 설명하면 작업을 자동화할 수 있습니다. 2026년, 자동화 엔지니어가 되지 않고도 반복 작업을 없애고 싶은 지식 근로자들을 위한 가장 강력한 도구 중 하나가 되었습니다.

## Bardeen이란?

Bardeen은 다음을 결합한 **브라우저 확장 + AI 자동화 플랫폼**입니다:
- **브라우저 자동화** — 로봇처럼 웹 페이지 제어
- **AI 기반 스크래핑** — 모든 웹사이트에서 구조화된 데이터 추출
- **통합 허브** — 100개 이상 앱 연결 (Salesforce, HubSpot, Notion, Slack 등)
- **AI 매직 액션** — 자연어로 워크플로우를 설명하면 자동으로 구축

브라우저 자동화(Selenium과 유사), 워크플로우 자동화(Zapier와 유사), AI 기반 데이터 추출이 — 브라우저 확장 프로그램에서 제어하는 하나의 도구로 합쳐진 것입니다.

---

## 핵심 개념

### 플레이북
플레이북은 Bardeen의 자동화 워크플로우 — 자동으로 실행되는 일련의 액션입니다. 가능한 것들:
- 일정, 단축키, 또는 특정 URL 방문 시 트리거
- 웹 페이지에서 데이터 스크래핑
- CRM/데이터베이스 도구에 레코드 생성
- 메시지 또는 이메일 전송
- AI로 데이터 처리

### AI 매직 액션
자연어로 작업을 설명하면 Bardeen의 AI가 자동화를 구축합니다:
> *"LinkedIn 프로필에 있을 때 이름, 직함, 회사, 이메일을 HubSpot CRM에 새 연락처로 저장해주세요"*

Bardeen이 자동으로 워크플로우를 생성합니다.

## 주요 기능

### 1. AI 웹 스크래퍼
Bardeen의 스크래퍼는 거의 모든 웹사이트에서 데이터를 추출할 수 있습니다:
- 페이지로 이동
- 추출하고 싶은 것을 설명
- Bardeen이 데이터 요소를 식별하고 스크래퍼를 구축
- 자동으로 실행되도록 예약하거나 온디맨드로 실행
- Google Sheets, Airtable, Notion 또는 연결된 앱으로 내보내기

**예시:** 컨퍼런스 웹사이트에서 모든 연사의 이름, 회사, LinkedIn URL, 발표 제목을 스크래핑 — 몇 초 만에 Google Sheet로 내보내기.

### 2. LinkedIn 자동화
Bardeen의 LinkedIn 통합이 킬러 사용 사례입니다:
- LinkedIn 검색 결과 스크래핑
- 대규모 프로필 세부 정보 추출
- 개인화된 메시지로 자동 연결 요청 전송
- 통화 전 리드 조사
- 잠재 고객 데이터를 CRM에 동기화

### 3. 조사 자동화
수동으로 수 시간이 걸리는 조사 워크플로우 자동화:
- 회사 목록에 대해 Google 검색
- 각 결과에 대해 웹사이트 방문
- 연락처 정보 추출
- 관련 인물을 위해 LinkedIn 확인
- 모든 것을 스프레드시트로 컴파일

조사원이 2~3시간 걸리던 작업이 백그라운드에서 20분 안에 실행됩니다.

### 4. CRM 자동 강화
회사 웹사이트나 LinkedIn 프로필에 있을 때:
- 단축키 하나로 Bardeen 트리거
- 관련 정보 스크래핑
- Salesforce, HubSpot, 또는 Pipedrive에 자동으로 레코드 생성/업데이트
- 수동 데이터 입력 없음

### 5. AI 데이터 처리
Bardeen은 AI를 사용해 추출된 데이터를 처리할 수 있습니다:
- 회사 페이지 요약
- 업종별 리드 분류
- 프로필 데이터를 기반으로 개인화된 이메일 초안 생성
- 정의한 기준을 기반으로 리드 점수 매기기

## 시작하기

### 설치
1. Chrome 웹 스토어에서 **Bardeen Chrome 확장 프로그램** 설치
2. bardeen.ai에서 무료 계정 생성
3. 브라우저에서 Bardeen 아이콘을 클릭해 대시보드 열기

### 첫 번째 플레이북 만들기

**옵션 A: AI 빌더 사용**
1. "새 플레이북" → "AI 빌더" 클릭
2. 워크플로우 설명: *"이 페이지에서 채용 공고를 스크래핑하고 내 Notion 데이터베이스에 추가해주세요"*
3. Bardeen이 워크플로우 생성
4. 검토하고 활성화

**옵션 B: 템플릿 사용**
1. **플레이북 라이브러리** 탐색 (사전 제작 자동화 1,000개 이상)
2. 사용 사례에 맞는 것 찾기
3. 앱 연결
4. 커스터마이징 후 실행

## 주요 활용 사례

### 영업 & 리드 생성

**자동화된 LinkedIn 잠재 고객 발굴:**
1. LinkedIn Sales Navigator 검색 실행
2. Bardeen이 모든 결과 스크래핑 (이름, 직함, 회사, 프로필 URL)
3. 회사 데이터로 강화 (웹사이트, 규모, 업종)
4. CRM에 리드 생성
5. AI로 개인화된 아웃리치 이메일 초안 작성

**절약 시간:** 적극적인 영업 팀에게 하루 3~4시간

### 경쟁 인텔리전스

**시장 조사 자동화:**
1. 가격 변경을 위해 경쟁사 제품 페이지 모니터링
2. 경쟁사 채용 공고 추적 (채용 신호)
3. 감정 분석을 위해 G2/Capterra 리뷰 스크래핑
4. Notion에서 주간 경쟁 인텔리전스 보고서 컴파일

### 채용

**후보자 조사 파이프라인:**
1. LinkedIn 검색에서 후보자 소싱
2. 프로필 세부 정보, 기술, 경험 스크래핑
3. 포트폴리오 작업을 위해 GitHub 프로필 확인
4. 기준에 따라 후보자 점수 매기기
5. 자격을 갖춘 리드를 ATS 시스템에 추가

## 프라이버시 및 윤리 참고사항

Bardeen은 강력합니다 — 책임감 있게 사용하세요:
- **robots.txt 존중** — 명시적으로 금지한 사이트 스크래핑 금지
- **속도 제한** — 서버 과부하 금지
- **GDPR 준수** — 개인 데이터 수집 시 적절한 법적 근거 확보
- **LinkedIn ToS** — LinkedIn은 자동화를 제한합니다; 계정 정지를 피하기 위해 신중하게 사용
- **데이터 저장** — 추출된 데이터 저장 위치에 주의
