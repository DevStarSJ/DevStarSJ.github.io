# Sider AI: 모든 작업을 위한 올인원 AI 브라우저 어시스턴트

![브라우저 확장 프로그램](https://images.unsplash.com/photo-1551650975-87deedd944c3?w=800)
*Photo by [Sigmund](https://unsplash.com/@sigmund) on Unsplash*

Sider AI는 ChatGPT, Claude, Gemini를 포함한 여러 AI 모델을 브라우징 경험에 직접 통합하는 브라우저 확장 프로그램입니다. 400만 명 이상의 사용자를 보유하며, 탭을 전환하지 않고 AI 지원을 받는 가장 인기 있는 방법 중 하나가 되었습니다.

## Sider AI란?

Sider (Sidebar의 줄임말)는 현재 보고 있는 웹페이지 옆에 강력한 AI 어시스턴트를 배치합니다. ChatGPT에 텍스트를 복사-붙여넣기하는 대신, Sider를 사용하면:

- 기사를 즉시 요약
- 콘텐츠를 실시간 번역
- 이메일 답장 생성
- 복잡한 주제 설명
- 브라우징하면서 리서치
- 텍스트 작성 및 다시 쓰기

모두 현재 페이지를 떠나지 않고 가능합니다.

### 핵심 장점

- **컨텍스트 인식**: AI가 읽고 있는 내용을 파악
- **멀티 모델**: GPT-4, Claude, Gemini 등 접근
- **즉시 접근**: 항상 한 번의 클릭으로
- **탭 전환 없음**: 작업 흐름 유지

## 핵심 기능

### 1. 스마트 사이드바

주요 인터페이스는 사이드바 패널로 열립니다:
- 현재 페이지에 대해 AI와 채팅
- 텍스트 선택으로 즉시 액션
- 지속적인 대화 기록
- 조절 가능한 너비와 위치

### 2. 텍스트 선택 도구

웹페이지의 어떤 텍스트든 하이라이트하면:
- **요약**: 선택한 콘텐츠의 빠른 요약
- **번역**: 어떤 언어로든 즉시 변환
- **설명**: 복잡한 개념 분해
- **다시 쓰기**: 개선하거나 톤 변경
- **답장**: 응답 초안 생성

### 3. 멀티 모델 접근

여러 AI 제공업체 선택 가능:

| 모델 | 강점 | 적합한 용도 |
|------|------|------------|
| GPT-4 | 일반 지식, 코딩 | 복잡한 작업 |
| GPT-4o | 빠름, 멀티모달 | 빠른 쿼리 |
| Claude 3 | 긴 컨텍스트, 글쓰기 | 문서, 분석 |
| Gemini | 최신 정보, 리서치 | 뉴스, 사실 |
| Llama | 오픈 소스, 프라이빗 | 프라이버시 중시 |

### 4. 글쓰기 어시스턴트

내장된 글쓰기 도구:
- 이메일 작성
- 기사 작성
- 소셜 미디어 포스트
- 문법 수정
- 톤 조정

### 5. 페이지 리더

Sider는 전체 웹페이지 처리 가능:
- 전체 기사 요약
- 핵심 포인트 추출
- 콘텐츠에 대한 Q&A
- 전체 페이지 번역

### 6. 이미지 분석

이미지 업로드 또는 스크린샷:
- 이미지 설명
- 텍스트 추출 (OCR)
- 차트 분석
- 시각적 Q&A

## 시작하기

### 설치

1. [sider.ai](https://sider.ai) 또는 Chrome 웹 스토어 방문
2. "Chrome에 추가" 클릭 (Edge, Firefox도 가능)
3. 계정 생성 또는 로그인
4. 빠른 접근을 위해 툴바에 확장 프로그램 고정

### 기본 사용법

**Sider 열기:**
- 툴바의 Sider 아이콘 클릭
- 키보드 단축키 사용 (Cmd/Ctrl + P)
- 우클릭 후 "Ask Sider" 선택

**빠른 액션:**
1. 웹페이지에서 텍스트 선택
2. Sider 팝업 자동 표시
3. 액션 선택 (요약, 번역 등)
4. 사이드바 또는 팝업에서 결과 확인

### 커스터마이징

워크플로우에 맞게 Sider 구성:
- **기본 모델**: 선호하는 AI 선택
- **키보드 단축키**: 커스텀 핫키 설정
- **외관**: 라이트/다크 모드, 사이드바 위치
- **자동 액션**: 텍스트 선택 시 기본 동작 설정

## 최상의 결과를 위한 팁

### 1. 구체적으로
"이거 요약해줘" 대신:
> "이 기사를 3가지 핵심 포인트로 요약해줘, 주요 주장과 근거에 집중해서"

### 2. 적절한 모델 사용
- **빠른 쿼리**: GPT-4o 또는 Gemini
- **긴 문서**: Claude (200K 컨텍스트)
- **최신 이벤트**: 웹 접근이 있는 Gemini
- **코딩**: GPT-4 또는 Claude

### 3. 페이지 컨텍스트 활용
현재 페이지를 참조할 때 Sider가 가장 잘 작동:
> "이 기사에 따르면, [주제]에 대한 시사점은 무엇인가요?"

### 4. 프롬프트 라이브러리 구축
자주 사용하는 프롬프트 저장:
- "한국어로 번역해줘, 격식체 유지"
- "이 분야 초보자에게 설명하듯이"
- "트윗 길이의 요약 5개 생성"

## 프라이버시 및 보안

Sider의 데이터 처리:
- 엔드투엔드 암호화
- 페이지 콘텐츠 저장 안 함 (무료 티어)
- 선택적 로컬 처리 (Llama 사용)
- GDPR 준수

사용자가 제어:
- Sider가 접근할 수 있는 사이트
- 데이터 보존 설정
- 작업별 모델 선택

## 일반적인 문제

### "Sider가 페이지를 인식하지 못해요"
- 확장 프로그램이 사이트에 대한 권한이 있는지 확인
- 페이지 새로고침 시도
- 사이트가 확장 프로그램을 차단하는지 확인

### "응답이 느려요"
- 더 빠른 모델 시도 (GPT-4 대신 GPT-4o)
- 쿼리 복잡도 확인
- 인터넷 연결 확인

### "일부 사이트에서 기능 제한"
- 일부 사이트 (뱅킹 등)는 확장 프로그램 차단
- 이런 경우 스크린샷/복사 사용
