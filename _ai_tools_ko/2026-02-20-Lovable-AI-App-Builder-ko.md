# Lovable: AI로 풀스택 앱 만들기 — 코딩 없이도 OK

![코드 화면](https://images.unsplash.com/photo-1555066931-4365d14bab8c?w=800)
*Photo by [Luca Bravo](https://unsplash.com/@lucabravo) on Unsplash*

Lovable(구 GPT Engineer)은 현재 가장 강력한 AI 중심 앱 빌더 중 하나로 부상했습니다. 기존의 노코드 도구와 달리, Lovable은 소유하고 확장하고 배포할 수 있는 실제 프로덕션 품질의 코드를 생성합니다. 개발팀 없이도 SaaS 제품, 내부 도구, 웹앱을 만들고 싶었다면 Lovable이 답이 될 수 있습니다.

## Lovable이란?

Lovable은 AI 기반 풀스택 개발 플랫폼으로:

- 자연어 설명에서 **React 앱을 생성**
- 데이터베이스, 인증, 스토리지를 위해 **Supabase와 연결**
- 공유 가능한 URL로 **즉시 배포**
- 소유하고 편집할 수 있는 **코드 생성** — 독자적 형식에 잠기지 않음
- 피드백 기반으로 **실시간 반복**

### "바이브 코딩" 혁명

Lovable은 원하는 것을 자연어로 설명하고 AI가 구현을 처리하는 "바이브 코딩"의 새로운 패러다임을 대표합니다. *어떻게*가 아닌 *무엇*에 집중하세요.

## 핵심 기능

### 1. 자연어 → React 앱

원하는 앱을 설명하기만 하면:

> "칸반 보드가 있는 프로젝트 관리 도구를 만들어주세요. 사용자가 프로젝트를 만들고, 작업을 추가하고, 팀원에게 할당하고, 할 일/진행 중/완료 컬럼을 통해 상태를 추적할 수 있게요."

Lovable이 생성하는 것:
- Tailwind CSS 스타일의 React 컴포넌트
- 상태 관리 로직
- CRUD 작업
- 반응형 레이아웃

### 2. Supabase 통합

몇 초 만에 앱을 실제 데이터베이스에 연결:

- **인증**: 이메일/비밀번호, Google OAuth, 매직 링크
- **데이터베이스**: 자동 생성 스키마의 PostgreSQL
- **스토리지**: 파일 업로드 및 관리
- **실시간**: WebSocket으로 라이브 업데이트
- **Row Level Security**: 적절한 데이터 접근 제어

Lovable이 Supabase 설정을 자동으로 처리 — 계정만 연결하면 됩니다.

### 3. GitHub 동기화

내 코드, 내 방식:

- 생성된 코드를 GitHub 저장소에 푸시
- 변경사항을 Lovable로 다시 가져오기
- 자체 CI/CD 파이프라인 사용
- VS Code에서 로컬로 코드 편집 후 동기화

### 4. 즉시 배포

모든 프로젝트에:
- 공유 가능한 미리보기 URL
- 커스텀 도메인 지원 (유료 요금제)
- 자동 HTTPS
- Lovable CDN 인프라

### 5. 시각적 편집 + AI 채팅

반복하는 두 가지 방법:

**채팅 모드**: 자연어로 변경사항 설명
> "헤더에 다크 모드 토글 추가해주세요"
> "스켈레톤 로딩 상태 추가해서 대시보드 로딩을 빠르게 해주세요"

**시각적 선택**: 원하는 요소를 클릭하고 AI에게 직접 수정 요청

## 첫 번째 앱 만들기

### 1단계: 컨셉 정의

명확한 설명 작성. 포함 내용:
- 어떤 문제를 해결하는지
- 사용자가 누구인지
- 핵심 기능 (3-5개 목록)
- 특별한 UI 선호도

**예시 프롬프트:**
> "사용자가 카테고리별로 수입과 지출을 기록하고, 차트로 월간 요약을 보고, 예산 한도를 설정하고 한도에 가까워지면 알림을 받을 수 있는 개인 재정 추적기를 만들어주세요. 녹색/흰색 색상 테마의 깔끔하고 모던한 디자인으로요."

### 2단계: 생성 및 검토

Lovable이:
1. 앱 구조 계획
2. 모든 컴포넌트 생성
3. 미리보기 URL에 배포
4. 코드 표시

### 3단계: Supabase 연결

데이터 지속성이 필요한 앱:
1. supabase.com에서 무료 Supabase 프로젝트 생성
2. 프로젝트 URL과 anon 키를 Lovable에 붙여넣기
3. Lovable에게 "데이터베이스 스키마 설정"을 요청
4. 자동으로 모든 테이블, 인덱스, RLS 정책 생성

### 4단계: 채팅으로 반복

대화를 통해 앱 다듬기:
- "지출 양식에 날짜 선택기가 필요해요"
- "거래 목록에 페이지네이션 추가해주세요"
- "대시보드의 모바일 레이아웃 수정해주세요"
- "사용자 프로필 설정 페이지 추가해주세요"

### 5단계: 배포

준비가 되면:
1. 커스텀 도메인 연결
2. 프로덕션 환경 변수 설정
3. 링크 공유!

## 파워 유저를 위한 팁

### 1. 기술 스택에 대해 구체적으로

> "데이터 페칭에 React Query, 폼 유효성 검사에 Zod, shadcn/ui 컴포넌트를 사용해주세요"

구체적일수록 출력 코드가 더 깔끔합니다.

### 2. 단계적으로 빌드

전체 앱을 한 번에 설명하려 하지 말고:
1. **1단계**: 핵심 UI 및 레이아웃
2. **2단계**: 데이터베이스 연결
3. **3단계**: 인증 추가
4. **4단계**: 기능 및 마무리

### 3. 스크린샷 → 앱

마음에 드는 앱의 스크린샷을 찍어 Lovable에 붙여넣기:
> "이 레이아웃과 비슷하게 만들되 [내 사용 사례]에 맞게 해주세요"

### 4. 버전 관리에 GitHub 활용

큰 변경 전에 GitHub에 동기화. AI가 뭔가 망가뜨리면 되돌릴 수 있습니다.

### 5. 생성된 코드 읽기

개발자가 아니더라도 코드를 훑어보면 Lovable이 무엇을 만들었는지 이해하는 데 도움이 됩니다. 더 나은 피드백을 줄 수 있게 됩니다.

## 한계

- **복잡한 비즈니스 로직**: 매우 정교한 알고리즘은 수동 코딩이 필요할 수 있음
- **서드파티 통합**: 결제 게이트웨이, 외부 API는 수동 설정 필요
- **성능 최적화**: 생성된 코드는 확장성을 위해 튜닝이 필요할 수 있음
- **크레딧 소비**: 대형 앱은 크레딧을 빠르게 소진
- **React 전용**: 현재 Vue, Angular 등 다른 프레임워크 미지원

## 시작하기

1. lovable.dev에서 **가입**
2. 프롬프트 박스에 **앱 아이디어 설명**
3. 미리보기 URL에서 **생성된 앱 검토**
4. 데이터베이스 기능을 위해 **Supabase 연결**
5. 채팅 인터페이스를 통해 **반복 및 개선**
6. 준비가 되면 커스텀 도메인으로 **배포**
