AI 이미지 생성 분야에서 **Midjourney**는 항상 최고의 기준을 제시해 왔습니다. **Version 7**로 이 도구는 이전에는 AI로 불가능했던 새로운 수준의 포토리얼리즘, 창의적 제어, 일관성을 달성했습니다.

## Midjourney V7의 새로운 기능

Version 7은 V6 대비 획기적인 개선을 이루었습니다:

### 🎨 향상된 포토리얼리즘
V7 모델은 다음 부분에서 크게 향상되었습니다:
- **피부 텍스처와 얼굴 세부 묘사** — 거의 사진에 가까운 품질
- **직물 및 소재 렌더링** — 옷감, 금속, 유리가 물리적으로 정확하게 표현
- **조명의 일관성** — 복잡한 다중 광원 시나리오를 자연스럽게 처리
- **배경-전경 통합** — 피사체가 더 이상 장면에 "합성"된 느낌이 없음

### 🧠 향상된 프롬프트 이해
- **긴 프롬프트**가 이제 더 정확하게 파싱됨
- **모호한 용어**가 컨텍스트를 통해 더 지능적으로 해결됨
- **네거티브 프롬프트** 더 안정적으로 작동 (`--no` 파라미터)
- **스타일 참조**가 더 예측 가능하게 블렌딩됨

### 🔄 향상된 일관성
새로운 `--cref` (캐릭터 참조)와 `--sref` (스타일 참조) 파라미터로 여러 생성 이미지에 걸쳐 캐릭터와 스타일 일관성을 유지할 수 있습니다 — 스토리텔링과 브랜드 작업에서 엄청난 혁신입니다.

### ⚡ 속도 및 해상도
- **Draft 모드** (빠름, 저비용): ~15초 만에 생성
- **Standard 모드**: ~45초 만에 4배 세부 묘사 생성
- **최대 해상도**: 네이티브로 최대 4096×4096px

## Midjourney V7 접근 방법

Midjourney는 주로 **Discord**와 웹앱 [midjourney.com](https://midjourney.com)을 통해 운영됩니다.

### 빠른 시작
1. [midjourney.com](https://midjourney.com)에서 가입
2. Midjourney Discord 서버에 참가
3. `#general-` 채널 사용 또는 개인 서버 생성 후 Midjourney 봇 추가
4. `/imagine`을 입력하고 프롬프트 입력

### V7 선택하기
```
/imagine prompt: [프롬프트] --v 7
```
또는 기본값으로 설정:
```
/settings → "MJ version 7" 선택
```

## 프롬프트 마스터 가이드

좋은 프롬프트는 간단한 구조를 따릅니다:

```
[피사체] + [스타일/매체] + [조명] + [구도] + [품질 수정자]
```

### 예시 프롬프트

**인물 사진:**
```
/imagine prompt: 전통 실크 기모노를 입은 일본 여성의 클로즈업 초상화, 
골든아워 햇빛, 얕은 피사계 심도, 후지필름 벨비아 필름 그레인, 
초고해상도 디테일 --v 7 --ar 3:4
```

**컨셉 아트:**
```
/imagine prompt: 밤의 미래형 메가시티, 젖은 도로에 반사되는 네온빛, 
비행 차량, 사이버펑크 미학, 매트 페인팅 스타일, 영화적 구도 
--v 7 --ar 16:9 --stylize 750
```

**제품 사진:**
```
/imagine prompt: 검은 대리석 표면 위의 고급 향수병, 단일 스포트라이트, 
완벽한 반사, 상업 사진, 8K --v 7 --ar 1:1
```

## 필수 파라미터

| 파라미터 | 사용법 | 예시 |
|---------|-------|------|
| `--ar` | 종횡비 | `--ar 16:9` |
| `--v 7` | 버전 선택 | `--v 7` |
| `--stylize` | 예술적 해석 (0-1000) | `--stylize 500` |
| `--chaos` | 변형 정도 (0-100) | `--chaos 30` |
| `--no` | 요소 제외 | `--no blur, grain` |
| `--quality` | 렌더링 품질 (.25, .5, 1, 2) | `--quality 2` |
| `--seed` | 재현성 | `--seed 42069` |
| `--cref` | 캐릭터 참조 URL | `--cref [url]` |
| `--sref` | 스타일 참조 URL | `--sref [url]` |
| `--tile` | 원활한 패턴 | `--tile` |

## 고급 기법

### 멀티 프롬프트 가중치
`::` 를 사용하여 다른 요소에 가중치 부여:
```
forest :: 2 cabin :: 1 snow :: 0.5
```
이는 "cabin"보다 약 2배 더 "forest"적인 이미지를 생성합니다.

### 리믹스 모드
리믹스를 활성화하면 프롬프트를 변경하여 생성된 이미지를 수정할 수 있습니다. 마음에 드는 구도를 반복적으로 개선하는 데 적합합니다.

### 이미지 프롬프팅
기존 이미지를 스타일 또는 구도 가이드로 참조:
```
/imagine prompt: [image_url] 산 위의 일몰, 유화 스타일 --iw 0.7
```
`--iw` (이미지 가중치) 0~2로 참조 이미지가 출력에 미치는 영향력 조절.

### 영역 변경 (Vary Region)
**Vary Region** 기능으로 이미지의 특정 부분을 선택하여 재생성 — 어색한 손 고치기, 배경 바꾸기, 전체 이미지를 다시 생성하지 않고 의상 색상 변경.

## 용도별 Midjourney 활용

### 마케터 & 콘텐츠 크리에이터
- 정확한 크기로 **소셜 미디어 비주얼** 생성 (`--ar 9:16`으로 스토리용)
- YouTube/블로그 포스트용 **썸네일 컨셉** 제작
- 제품 광고용 **목업 이미지** 생성
- `--cref`를 사용하여 일관된 **브랜드 캐릭터** 구축

### 디자이너
- **빠른 컨셉 작업** — 수분 내에 100가지 아이디어 반복
- **텍스처 생성** — 3D 도구에서 사용하기 위해 내보내기
- **무드보드** — 빠르게 비주얼 방향 탐색
- **클라이언트 프레젠테이션** — 제작에 착수하기 전 컨셉 다듬기

### 작가 & 스토리텔러
- **캐릭터 시각화** — 당신의 캐릭터에 생명을 불어넣기
- **장면 설정** — 주요 장면의 시각적 표현 생성
- **책 표지** — 일러스트레이터 고용 전 표지 디자인 탐색
- 캐릭터 + 스타일 참조로 **일관된 세계관 구축**

## 가격

| 플랜 | 월 이미지 수 | 속도 | 가격 |
|------|------------|------|------|
| Basic | ~200장 (빠름) | 빠름만 | 월 $10 |
| Standard | ~900장 (빠름) + 무제한 (릴랙스) | 빠름 + 릴랙스 | 월 $30 |
| Pro | ~1800장 (빠름) + 무제한 (릴랙스) | 빠름 + 터보 | 월 $60 |
| Mega | ~3600장 (빠름) + 무제한 (릴랙스) | 모든 모드 | 월 $120 |

**팁:** Standard 플랜으로 시작하세요. 릴랙스 모드로 급하지 않은 작업은 사실상 무제한 생성이 가능합니다.

## 흔히 하는 실수 피하기

1. **프롬프트 과부하** — 단어가 많다고 좋은 결과가 나오는 게 아닙니다. 구체적이되 간결하게.
2. **종횡비 무시** — 항상 용도에 맞게 `--ar` 설정.
3. **업스케일링 건너뛰기** — 마음에 드는 결과는 항상 업스케일 (U1-U4 버튼).
4. **반복 작업에 씨드 미사용** — 결과가 마음에 들면 씨드 번호를 메모하여 발전시키기.
5. **스타일 참조 잊기** — 일관된 캐릭터/브랜딩에는 `--cref`가 필수.
