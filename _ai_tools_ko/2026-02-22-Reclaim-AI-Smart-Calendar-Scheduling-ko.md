# Reclaim.ai: 당신의 시간을 자동으로 지켜주는 AI 스케줄러

![정리된 책상 위의 캘린더와 플래너](https://images.unsplash.com/photo-1506784365847-bbad939e9335?w=800)
*Photo by [Manasvita S](https://unsplash.com/@manasvita) on Unsplash*

대부분의 캘린더 앱은 당신이 약속한 것을 보여준다. **Reclaim.ai**는 당신의 시간을 위해 싸운다. 손가락 하나 까딱하지 않고도 회의, 마감, 캘린더 충돌을 피해 집중 업무, 습관, 개인 우선순위를 위한 공간을 자동으로 보호하는 AI 스케줄링 어시스턴트다. 회의만 하다가 한 주를 보낸 적이 있다면, Reclaim이 그것을 바꿔줄 도구가 될 수 있다.

## Reclaim.ai란?

Reclaim.ai는 다음을 하는 AI 기반 캘린더 최적화 플랫폼이다:

- 할 일 목록의 **작업을 가용 슬롯에 자동 스케줄링**
- 건강 검진이나 점심 같은 **습관을 보호** (단, 지능적으로만 변경 가능)
- 생산성 패턴에 기반해 **집중 시간 창을 차단**
- 파편화를 피하면서 **모든 참여자에게 최적 슬롯을 찾는 스마트 미팅 기능**
- **구글 캘린더와 양방향 실시간 동기화**

핵심 철학: 캘린더는 단순한 약속이 아닌 당신의 우선순위를 반영해야 한다.

## 주요 기능

### 1. 작업 — 자동 스케줄링되는 할 일 항목

태스크 매니저를 연결하거나 Reclaim에서 직접 작업 생성:

- **우선순위** (P1~P4), **기간**, **마감일** 설정
- Reclaim이 가용 슬롯을 찾아 자동으로 스케줄링
- 회의가 작업 슬롯을 차지하면, Reclaim이 마감 전에 다른 곳으로 재스케줄링
- 네이티브 연동: **Asana, Todoist, Linear, Jira, ClickUp, Google Tasks**

**예시:** "Q1 보고서 작성"을 4시간 필요, 금요일 마감으로 추가. Reclaim이 금요일 전 가용 창에 자동으로 4시간을 분산 배치하고, 일정이 바뀌면 다시 조정.

### 2. 습관 — 반복되는 유연한 블록

습관은 정기적으로 이루어져야 하지만 창 안에서 유연할 수 있는 반복 활동이다:

- **운동**: 매일 45분, 오전 9시 전이 이상적, 12시까지는 이동 허용
- **집중 업무**: 평일 매일 2시간, 오전 시간대
- **학습**: 30분, 오후만, 주 3회
- **점심**: 45분, 12시~2시 사이, 회의로부터 보호

습관에는 **이상적인 시간**과 **허용 가능한 창**이 있다. Reclaim은 이상적인 시간에 스케줄링하지만 충돌 시 창 안에서 이동 가능하다.

### 3. 스마트 미팅

Reclaim의 스마트 미팅 기능은 타인과의 스케줄링을 크게 향상시킨다:

- **스케줄링 링크**: 개인 링크 공유; Reclaim이 최적 회의 시간에 맞는 슬롯 표시
- **팀 스케줄링**: 일정 파편화를 최소화하면서 모든 참여자에게 맞는 슬롯 찾기
- **버퍼 시간**: 회의 전후 이동/준비 시간 자동 추가
- **회의 휴식**: 버퍼 슬롯을 유지해 연속 회의 방지

### 4. 집중 시간 보호

Reclaim은 최고 생산성 시간을 파악하고 지킨다:

- 히스토리 캘린더를 분석해 패턴 파악
- 고에너지 창 동안 집중 시간 차단
- **회의 금지 구역**으로 회의가 하루를 파편화하지 않도록 방지
- 집중 시간 블록을 Slack **방해 금지** 상태와 자동 동기화 가능

### 5. 워라밸 컨트롤

Reclaim이 존중하는 강제 경계 설정:

| 설정 | 예시 |
|------|------|
| 근무 시간 | 월~금, 오전 9시~오후 6시만 |
| 개인 시간 | 저녁과 주말 차단 |
| 출퇴근 버퍼 | 업무 블록 전후 30분 |
| 하루 최대 회의 수 | 하루 4개 이상 회의 불가 |

## 시작하기

### 설정 단계

1. [reclaim.ai](https://reclaim.ai) 방문 후 가입
2. **구글 캘린더** 연결 (필수; Outlook 지원 예정)
3. **근무 시간** 및 **개인 시간** 설정
4. 첫 번째 **습관** 생성 (예: 점심, 운동)
5. **태스크 매니저** 연결 또는 직접 작업 추가
6. Reclaim이 생성하는 자동 스케줄 블록 검토

초기 설정은 약 15분이 걸린다. 첫날 끝에 캘린더가 의미 있게 달라질 것이다.

### 습관 설정

**습관**으로 이동해 **새 습관** 클릭:

```
이름: 아침 운동
기간: 45분
빈도: 평일 매일
이상적인 시간: 오전 7:00 – 8:00
허용 창: 오전 6:00 – 10:00
우선순위: 보통
```

Reclaim이 이상적인 시간에 배치하고 필요할 때만 창 안에서 이동한다.

### 작업 우선순위와 시간 창

작업 생성 시 제약 설정:

| 필드 | 설명 |
|------|------|
| 우선순위 | P1 = 반드시 해야 함; P4 = 하면 좋음 |
| 기간 | 예상 총 작업 시간 |
| 마감일 | 최신 완료 날짜 |
| 스케줄링 창 | 이 작업을 배치할 수 있는 시간 |
| ~까지 보류 | 이 날짜 전에는 스케줄링하지 않음 |

높은 우선순위와 타이트한 마감의 작업이 먼저 스케줄링되고, 낮은 우선순위는 남은 빈자리를 채운다.

## 연동

Reclaim은 이미 사용 중인 도구와 깊이 연동된다:

### 태스크 매니저
- **Asana**: 작업과 마감일 양방향 동기화
- **Todoist**: 우선순위를 포함한 작업 동기화
- **Linear**: 엔지니어링 팀에 적합
- **Jira**: 스프린트 티켓을 캘린더 작업으로 가져오기
- **ClickUp**: 상태 업데이트가 있는 전체 작업 동기화
- **Google Tasks**: 네이티브 구글 워크플로우

### 커뮤니케이션
- **Slack**: 상태 동기화 (집중 = 방해 금지), 회의 알림
- **Zoom**: 회의에 자동 Zoom 링크

## 팀을 위한 Reclaim

팀 기능에서 Reclaim이 진정으로 강력해진다:

### 팀 동기화
팀 전체가 Reclaim을 사용하면:
- 서로의 집중 시간을 보고 그 위에 회의 잡는 것 방지
- 모든 사람의 집중 업무 블록을 존중하는 회의 스케줄링
- 팀 시간 배분 분석 ("우리는 주의 60%를 회의에 쓴다")

### 1:1 미팅
스마트 1:1 스케줄링:
- 두 사람 모두에게 맞는 반복 슬롯 찾기
- 충돌 시 자동 재스케줄링
- 관계 건강 지표 유지

## Reclaim vs 경쟁사

| 기능 | Reclaim | Motion | Clockwise | Calendly |
|------|---------|--------|----------|---------|
| AI 작업 스케줄링 | ✅ | ✅ | ❌ | ❌ |
| 습관 보호 | ✅ | 부분적 | ❌ | ❌ |
| 스마트 미팅 | ✅ | ✅ | ✅ | ✅ |
| 팀 분석 | ✅ | 제한적 | ✅ | ❌ |
| 작업 연동 | ✅ (6+) | ✅ (제한적) | ❌ | ❌ |
| 무료 플랜 | ✅ | ❌ | ✅ | ✅ |
| 가격 (유료) | $8/월 | $19/월 | $6.75/월 | $8/월 |

**Reclaim vs Motion**: Motion은 더 독단적인 AI로 완전한 일정을 자동 구성한다. Reclaim은 더 유연하고 커스터마이징 가능하며 팀 기능이 더 뛰어나다.

## 최상의 결과를 위한 팁

1. **먼저 습관부터 시작** — 협상 불가한 것을 먼저 정의하고 작업 추가
2. **작업 기간을 현실적으로** — 과소평가하면 연쇄 효과 발생
3. **작업에 스케줄링 창 사용** — P4 작업이 아침 집중 시간을 소비하지 않도록
4. **일주일 신뢰** — AI가 패턴을 학습하는 데 시간이 필요
5. **주간 다이제스트 검토** — Reclaim이 시간 사용 요약을 이메일로 발송
6. **팀 연결** — 모두가 사용하면 가치가 배가됨

## 결론

Reclaim.ai는 대부분의 지식 노동자가 직면하는 캘린더 문제를 해결한다: 캘린더가 회의와 반응적 약속으로 채워져 실제로 중요한 업무를 할 시간이 없는 문제. 습관, 집중 업무, 작업을 — 보호된 시간을 받는 — 1등급 캘린더 시민으로 취급함으로써, Reclaim은 매주 목표를 실질적으로 진전시키며 마칠 수 있도록 돕는다. 구글 캘린더를 사용하고 집중 업무에서 계속 뒤처지고 있다면, 무료 플랜을 바로 시도해볼 가치가 있다.
