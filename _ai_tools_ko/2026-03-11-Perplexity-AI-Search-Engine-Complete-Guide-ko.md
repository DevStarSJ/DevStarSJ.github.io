## Perplexity AI란?

Perplexity AI는 **AI 기반 답변 엔진**으로:
- 실시간으로 웹을 검색
- 여러 출처의 정보를 종합
- **인용 출처가 있는 검증 가능한 답변** 제공 (환각 없음)
- 대화형 쓰레드에서 후속 질문 지원
- 무료 및 Pro 티어 제공

기존 검색 엔진이 링크 목록을 보여주는 것과 달리, Perplexity는 그 링크들을 *직접 읽고* 출처와 함께 직접 요약된 답변을 제공합니다.

## 2026년 주요 기능

### 1. 딥 리서치 모드
Perplexity Pro의 **딥 리서치(Deep Research)** — 수십 개의 출처를 읽고 다단계 리서치를 자동으로 수행하여 종합 보고서를 생성합니다. 다음에 적합:
- 학술 연구
- 시장 분석
- 기술적 심층 분석

### 2. 포커스 모드
검색 범위를 선택하세요:
- **All** — 전체 웹
- **Academic** — 학술 논문 (Semantic Scholar, PubMed)
- **YouTube** — 동영상 콘텐츠 검색
- **Reddit** — 커뮤니티 토론
- **Writing** — 웹 검색 없이 순수 AI 생성

### 3. Spaces (협업 리서치)
팀 리서치 프로젝트를 위한 비공개 또는 공유 **Spaces** 생성. 문서, PDF, URL을 업로드하면 Perplexity가 모든 자료를 인덱싱하여 통합 질의응답 제공.

### 4. 멀티 모델 백엔드
Pro 사용자는 기반 모델 선택 가능:
- **기본 (Perplexity Sonar)** — 속도 최적화
- **Claude 3.5 Sonnet / GPT-4o** — 정교한 추론
- **Grok** — X/트위터 실시간 데이터

## Perplexity AI 효과적으로 사용하는 법

### 팁 1: 후속 질문 활용
큰 주제에서 시작해 점점 구체화하기:
```
"양자 컴퓨팅의 최신 돌파구는 무엇인가요?"
→ "IBM 오류 정정 논문을 더 쉽게 설명해 주세요"
→ "이것이 2030년 암호화에 어떤 의미를 갖나요?"
```

### 팁 2: 포커스 모드 활용
학술 주제에서는 **Academic 모드**로 전환하면 품질이 크게 향상됩니다.

### 팁 3: 문서 업로드 활용
Pro에서 PDF(연구 논문, 계약서, 연간 보고서 등)를 업로드하고 구체적인 질문:
```
"이 사업 보고서에서 언급된 주요 위험 요소는 무엇인가요?"
```

### 팁 4: Spaces로 프로젝트 관리
진행 중인 프로젝트를 위한 Space를 생성하고 URL, 문서, 메모를 추가하세요. 모든 자료를 통합 검색할 수 있습니다 — 마치 개인 AI 리서치 어시스턴트처럼.

### 팁 5: 인용 출처 확인
Perplexity는 훌륭하지만, 중요한 정보는 항상 [1], [2], [3] 인용 출처를 클릭해 확인하세요.

## 개발자를 위한 Perplexity API

OpenAI 형식과 호환되는 **REST API** 제공:

```python
from openai import OpenAI

client = OpenAI(
    api_key="pplx-xxxxxxxxxxxx",
    base_url="https://api.perplexity.ai"
)

response = client.chat.completions.create(
    model="llama-3.1-sonar-large-128k-online",
    messages=[
        {"role": "system", "content": "정확하게 답변하고 출처를 인용하세요."},
        {"role": "user", "content": "2026년 3월 최신 AI 개발 동향은?"}
    ]
)
print(response.choices[0].message.content)
```
