## Otter.ai란?

Otter.ai는 음성을 실시간으로 텍스트로 변환하는 AI 기반 녹취 서비스입니다. Zoom 회의, 인터뷰, 강의 등 모든 음성을 캡처하고 지능형 요약을 생성합니다.

**핵심 기능:**
- 95% 이상 정확도의 실시간 녹취
- 자동 화자 구분
- AI 회의 요약 생성
- Zoom, Google Meet, Microsoft Teams 연동
- 검색 가능한 녹취록 아카이브
- 협업 편집 및 댓글

## Otter.ai의 차별점

### 1. 실시간 녹취

다른 도구들과 달리 Otter는 말하는 즉시 녹취합니다:
- 회의 중 실시간 확인 가능
- 특정 주제 즉시 검색
- 팀원과 실시간 녹취록 공유

### 2. OtterPilot 회의 기능

OtterPilot은 게임 체인저:
- 예약된 회의에 **자동 참가**
- 수동 개입 없이 **녹음 및 녹취**
- 액션 아이템과 함께 **요약 생성**
- **핵심 포인트 자동 추출**

## 시작하기

### 1단계: 계정 만들기

1. [otter.ai](https://otter.ai) 방문
2. Google, Microsoft, 이메일로 가입
3. 모바일 앱 다운로드 (iOS/Android)
4. 웹 회의용 Chrome 확장 프로그램 설치

### 2단계: 연동 설정

Otter를 캘린더에 연결:

```
설정 → 연동 → 캘린더
- Google 캘린더 ✓
- Microsoft Outlook ✓
```

회의 플랫폼 연결:
```
설정 → 연동 → 회의 앱
- Zoom (자동 참가는 관리자 승인 필요)
- Google Meet
- Microsoft Teams
```

### 3단계: OtterPilot 설정

```
설정 → OtterPilot
- 회의 자동 참가: ON
- 요약 이메일 발송: ON
- 액션 아이템 생성: ON
- 참가자와 공유: 사용자 지정
```

## 파워 유저 기능

### 맞춤 어휘

업계 특화 용어 추가로 정확도 향상:

```
설정 → 맞춤 어휘
- 회사명 추가
- 제품명 추가
- 전문 용어 추가
- 팀원 이름 추가
```

### 화자 인식 훈련

화자 인식 개선:

1. 녹취록 설정으로 이동
2. 잘못 식별된 화자 수정
3. Otter가 수정 내용 학습
4. 시간이 지나면서 정확도 향상

### 하이라이트 및 액션 아이템

회의 중 또는 후:
- 중요 순간 **하이라이트**
- 텍스트에서 **액션 아이템 생성**
- 맥락을 위한 **댓글 추가**
- 타임스탬프와 함께 **클립 공유**

## 모범 사례

### 원격 회의용

1. **좋은 오디오 장비 사용** - 입력이 좋아야 녹취도 좋음
2. Zoom에서 **원본 오디오 활성화**로 선명하게 캡처
3. 말하지 않을 때 **음소거**로 노이즈 감소
4. **명확하게 말하고** 끼어들지 않기

### 대면 회의용

1. **기기를 중앙에 배치**하여 균등한 화자 픽업
2. 휴대성을 위해 **모바일 앱 사용**
3. 회의 시작 전 **녹음 시작**
4. 쉬운 식별을 위해 **참가자 이름 지정**

### 인터뷰용

1. 미리 **오디오 레벨 테스트**
2. 다른 프로젝트용 **별도 워크스페이스 생성**
3. 검토 시 **타임스탬프 활용**
4. **원하는 형식으로 내보내기**

## 일반적인 문제 해결

### 녹취 품질 저하

**해결책:**
- 마이크 설정 확인
- 배경 소음 줄이기
- 맞춤 어휘 업데이트
- 적당한 속도로 말하기

### OtterPilot 참가 안됨

**해결책:**
- 캘린더 연동 확인
- 회의 플랫폼 권한 확인
- 예약된 회의인지 확인 (임시 회의 아님)
- 방화벽 설정 검토

### 화자 오인식

**해결책:**
- 수동으로 화자 수정
- 음성 프로필 훈련
- 화자별 명확한 오디오 확보
- 전용 마이크 사용
