# Bolt.new: AI로 브라우저에서 풀스택 웹 앱 만들기

![노트북 화면의 코드](https://images.unsplash.com/photo-1555066931-4365d14bab8c?w=800)
*Photo by [Chris Ried](https://unsplash.com/@cdr6934) on Unsplash*

평범한 한 문장 설명으로 2분 안에 완전히 실행 가능한 웹 앱을 만들 수 있다면 어떨까? 로컬 설치도, Docker도, 환경 설정 고통도 없이, 브라우저 탭 하나에서 전부 해결된다. 이것이 바로 StackBlitz의 WebContainers 기술 위에 구축된 AI 풀스택 개발 환경 **Bolt.new**의 약속이다.

## Bolt.new란?

Bolt.new는 다음 요소를 결합한 AI 코딩 플랫폼이다:

- **AI 코드 생성**: Claude 기반(다른 모델 선택도 가능)의 코드 합성
- **WebContainers 런타임**: 브라우저 탭에서 직접 실행되는 완전한 Node.js 환경
- **통합 파일 시스템**: 프로젝트 파일 탐색, 편집, 관리
- **실시간 미리보기**: 코드 옆에서 앱이 실시간으로 실행되는 화면
- **원클릭 배포**: Netlify 등의 플랫폼으로 즉시 배포

프론트엔드 스캐폴딩에 집중하는 Lovable이나 v0과 달리, Bolt.new는 실제 개발 서버를 실행한다 — npm, 패키지 설치, 환경변수까지 — 로컬 머신을 전혀 건드리지 않고.

## Bolt.new 작동 원리

내부적으로 Bolt.new는 **StackBlitz WebContainers**를 사용한다. WebAssembly를 이용해 브라우저 탭 안에서 완전한 운영체제 환경을 실행하는 기술이다. 이것이 가능한 것들:

- 실제 패키지를 resolve하는 진짜 `npm install`
- 핫 모듈 교체가 있는 라이브 Vite 개발 서버
- 세션 내에서 지속되는 파일 작업
- 수동 명령을 위한 터미널 접근

AI 레이어가 그 위에 앉아 프롬프트를 해석하고, 타겟 파일 편집을 수행하고, 명령을 실행하고, 변경사항이 작동하는지 검증한 후 결과를 보여준다.

## 시작하기

### 60초 만에 첫 앱 만들기

1. [bolt.new](https://bolt.new) 접속
2. GitHub 또는 이메일로 로그인
3. 중앙 입력창에 프롬프트 입력
4. **Start building** 클릭하고 마법 감상

**시도해볼 프롬프트 예시:**
- *"React와 Tailwind CSS로 포모도로 타이머 앱 만들어줘"*
- *"차트와 localStorage 저장이 있는 개인 가계부 만들어줘"*
- *"할 일 목록용 Express와 SQLite REST API 만들어줘"*
- *"실시간 미리보기가 있는 마크다운 노트 앱 만들어줘"*

Bolt가 프로젝트를 스캐폴딩하고, 의존성을 설치하고, 실시간 미리보기를 보여준다 — 전부 30~60초 안에.

### 인터페이스 살펴보기

Bolt.new UI는 세 가지 주요 패널로 구성된다:

| 패널 | 용도 |
|------|------|
| **채팅** | 기능 설명, 질문, 변경 요청 |
| **코드 에디터** | 생성된 파일 탐색 및 수동 편집 |
| **미리보기** | 핫 리로드가 있는 실시간 실행 앱 |

패널 크기 조절, 터미널 열기, 코드/미리보기 모드 전환이 가능하다.

## Bolt.new 활용하기

### 반복적 개발

초기 스캐폴드 후, 기능 추가를 위해 계속 대화하면 된다:

```
"헤더에 다크모드 토글 추가해줘"
"JWT로 사용자 인증 구현해줘"
"에러 메시지가 있는 폼 유효성 검사 추가해줘"
"OpenAI API에 연결하고 AI 응답을 인라인으로 표시해줘"
```

각 요청은 전체를 재생성하는 대신 외과적 편집을 수행한다. Bolt는 기존 코드베이스 컨텍스트를 이해한다.

### 수동 편집

생성된 구현이 마음에 안 들면? 코드 패널에서 직접 편집하면 된다. AI는 이후 프롬프트에서 네 변경사항을 반영한다 — 항상 파일의 현재 상태를 기반으로 작동한다.

### 터미널 접근

내장 터미널을 열어 커스텀 명령 실행:

```bash
npm install some-library
npx prisma migrate dev
git init && git add .
```

### 기존 프로젝트 가져오기

Bolt.new는 다음에서 가져올 수 있다:
- **GitHub 레포**: 공개 레포 URL을 붙여넣어 로드
- **npm 패키지**: 게시된 템플릿 참조
- **파일 업로드**: 프로젝트 zip을 드래그 앤 드롭

로컬 프로젝트를 디버깅하거나 이어서 작업할 때 강력하다.

## 지원 기술 스택

Bolt.new는 다양한 인기 스택에서 잘 작동한다:

### 프론트엔드
- React, Vue, Svelte, Angular
- Vite, Next.js, Astro, Remix
- Tailwind CSS, shadcn/ui, Chakra UI

### 백엔드
- Express, Fastify, Hono를 사용하는 Node.js
- Bun 런타임 지원
- Supabase, PocketBase, Firebase 연동

### 데이터베이스
- SQLite (sql.js를 통한 브라우저 내 실행)
- Supabase (API를 통한 Postgres)
- 간단한 영속성을 위한 localStorage

### 배포
- Netlify (원클릭)
- StackBlitz 호스팅
- 어디서든 배포 가능한 zip 내보내기

## 사용 가능한 AI 모델

Bolt.new는 모델 선택을 제공한다 (플랜에 따라 다름):

| 모델 | 강점 |
|------|------|
| Claude 3.5 Sonnet | 전체적으로 최고의 코딩 품질 |
| GPT-4o | 강력한 추론, 폭넓은 지식 |
| Gemini 1.5 Pro | 대용량 컨텍스트, 큰 프로젝트에 적합 |
| Mistral | 간단한 작업에 빠르고 효율적 |

상위 플랜은 우선 접근 및 요청당 더 많은 토큰을 제공한다.

## 요금제

| 플랜 | 가격 | 토큰/일 | 기능 |
|------|------|---------|------|
| Free | $0 | 제한적 | 기본 프로젝트, 워터마크 |
| Pro | $20/월 | ~1000만 | 무제한 프로젝트, 모든 모델 |
| Team | 문의 | 무제한 | 비공개 레포, SSO, 관리자 |

**팁:** 토큰은 세션이 아닌 AI 생성 단계마다 소비된다. 간단한 프로젝트는 복잡한 것보다 훨씬 적은 토큰을 사용한다.

| 기능 | Bolt.new | Lovable | v0 (Vercel) | Replit |
|------|----------|---------|------------|--------|
| 풀 백엔드 | ✅ | 부분적 | ❌ (프론트엔드) | ✅ |
| 브라우저 네이티브 런타임 | ✅ | ❌ | ❌ | ❌ |
| 실제 npm install | ✅ | ❌ | ❌ | ✅ |
| 원클릭 배포 | ✅ | ✅ | ✅ | ✅ |
| 로컬 설치 필요 | ❌ | ❌ | ❌ | ❌ |
| 멀티파일 편집 | ✅ | ✅ | 부분적 | ✅ |

Bolt.new의 핵심 차별화는 **브라우저 네이티브 풀스택 런타임**이다. 정적 코드를 생성하는 게 아니라 실제 서버를 실행한다.

## 실용적인 사용 사례

### 빠른 프로토타이핑
회의나 피칭을 위해 한 시간 안에 작동하는 프로토타입을 만들자. 목업이 아닌 실제로 클릭 가능한 앱을 이해관계자에게 보여줄 수 있다.

### 학습 프로젝트
학생들이 로컬 환경 설정의 고통 없이 풀스택 프로젝트를 만들 수 있다. 설정이 아닌 학습에 집중하자.

### 내부 도구
비개발자도 관리자 대시보드, 데이터 시각화 도구, 간단한 CRUD 앱을 독립적으로 만들 수 있다.

### 사이드 프로젝트
전체 개발 사이클에 투자하기 전에 아이디어를 빠르게 검증하자. 작동하면 코드를 내보내고 로컬에서 계속 개발하면 된다.

## 최상의 결과를 위한 팁

1. **첫 프롬프트에 구체적으로** — 원하는 기술 스택, 핵심 기능, UI 스타일을 포함하자
2. **한 번에 하나의 기능** — 작은 반복 프롬프트가 큰 것 하나보다 잘 작동한다
3. **해결책이 아닌 문제를 설명** — "필터할 때 차트가 업데이트 안 돼" > "onClick 핸들러 추가해줘"
4. **터미널 활용** — AI가 어려워하는 것은 직접 해결 (패키지 설치, 마이그레이션 실행)
5. **일찍 내보내기** — 만족스러우면 zip을 다운로드해 로컬 IDE에서 계속 작업하자

## 한계

- **세션 지속성**: 프로젝트가 브라우저 스토리지에 저장됨; 세션 간 유지를 위해 GitHub 내보내기 필요
- **토큰 제한**: 매우 큰 코드베이스는 대화 중간에 컨텍스트 제한에 걸릴 수 있음
- **데이터베이스**: 무료 플랜은 영구 호스팅 데이터베이스 없음; 프로덕션 데이터는 Supabase 연동 필요
- **성능**: 복잡한 AI 생성은 20~60초 걸릴 수 있음

## 결론

Bolt.new는 웹 애플리케이션을 프로토타입하고 만드는 방식에서 진정한 변화를 나타낸다. 브라우저 네이티브 실제 런타임과 강력한 AI 코드 생성을 결합해, 아이디어와 작동하는 애플리케이션 사이에 있던 마찰을 제거했다. 빠른 프로토타이핑, 학습, 내부 도구 만들기에서 이를 능가하는 도구는 없다 — 그리고 많은 사용 사례에서 생성되는 코드는 바로 배포해도 될 만큼 프로덕션 품질이다.
