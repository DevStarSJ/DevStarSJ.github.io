# n8n: 오픈소스 AI 자동화 플랫폼

**n8n** ("n-eight-n"으로 발음)은 강력한 AI 에이전트 기능, 셀프 호스팅 옵션, 작업당 과금 없는 가격 구조가 필요한 팀을 위한 선도적인 오픈소스 워크플로우 자동화 플랫폼입니다. Zapier와 Make의 개발자 친화적 대안으로, AI 오케스트레이션 영역에서 빠르게 성장하고 있습니다.

## n8n이란?

n8n은 **페어 코드 라이선스**의 워크플로우 자동화 도구로, 시각적 노드 기반 편집기를 사용하여 앱을 연결하고, 프로세스를 자동화하며, AI 기반 워크플로우를 구축할 수 있습니다. SaaS 전용 플랫폼과 달리 n8n은 다음과 같이 사용할 수 있습니다:

- **자체 서버에 셀프 호스팅** (Docker, VPS, Kubernetes)
- **n8n Cloud 사용** (관리형 호스팅)
- **기업 보안 요구사항을 위한 온프레미스 배포**

400개 이상의 네이티브 통합과 내장 AI 에이전트 프레임워크를 갖춘 n8n은 2026년 AI 네이티브 워크플로우를 위한 자동화 플랫폼입니다.

## 핵심 기능

### 1. 시각적 워크플로우 빌더
드래그 앤 드롭으로 노드를 연결하여 복잡한 다단계 워크플로우 생성. 각 노드는 앱 액션(이메일 발송, 데이터베이스 쿼리, API 호출 등)을 나타냅니다. 워크플로우에 포함 가능:
- 분기 로직 (If/Else)
- 루프 및 이터레이터
- 오류 처리 및 재시도
- 병렬 실행

### 2. AI 에이전트 프레임워크
n8n의 내장 **AI Agent 노드**로 다음이 가능한 자율 에이전트 구축:
- 도구 사용 (HTTP 요청, 데이터베이스 쿼리, 계산)
- 대화 전반에 걸친 메모리 유지
- 다른 모델을 사용한 다중 AI 호출 체인
- OpenAI, Anthropic, Google Gemini, Ollama(로컬 LLM)와 통합

### 3. 셀프 호스팅 & 데이터 프라이버시
n8n을 자체 인프라에서 완전히 실행. 의료, 금융, 기업 사용 사례에 필수적인 — 데이터가 서버를 떠나지 않습니다.

### 4. 400개 이상의 통합
모든 주요 서비스와 연결:
- CRM: Salesforce, HubSpot, Pipedrive
- 커뮤니케이션: Slack, Discord, Gmail, Outlook
- 데이터베이스: PostgreSQL, MySQL, MongoDB, Airtable
- 개발자: GitHub, Jira, Linear, Webhooks
- AI: OpenAI, Anthropic, Hugging Face, Pinecone

### 5. 필요할 때 코드 사용
각 노드는 복잡한 로직을 위한 **JavaScript 및 Python 표현식**을 지원합니다. 시각적 한계에 막히는 일이 없습니다.

## 인기 워크플로우 템플릿

### AI 고객 지원 에이전트
```
트리거: 새 지원 티켓 (Zendesk)
→ AI Agent: 분류 및 응답 초안 작성 (GPT-4)
→ 확신도 높으면 (>80%): 자동 답변 발송
→ 그 외: Slack으로 담당자 알림
```

### 리드 강화 파이프라인
```
트리거: 새 CRM 연락처 (HubSpot)
→ 회사 웹사이트 스크래핑
→ AI: 회사 요약 생성
→ 강화된 데이터로 CRM 업데이트
```

### 일일 뉴스 브리핑
```
트리거: 크론 (매일 오전 8시)
→ RSS 피드 가져오기 (20개 소스)
→ AI: 상위 5개 뉴스 요약
→ 이메일/Slack으로 다이제스트 발송
```

## 셀프 호스팅 시작 방법

```bash
# Docker 빠른 시작
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n
```

그런 다음 `http://localhost:5678`에서 n8n 인스턴스에 접속합니다.

## 장단점

**✅ 장점:**
- 셀프 호스팅은 완전 무료
- 강력한 AI 에이전트 기능 내장
- 데이터가 자체 인프라에 유지
- 시각적 방법이 부족할 때 코드 지원
- 활발한 오픈소스 커뮤니티

**❌ 단점:**
- 셀프 호스팅에는 DevOps 지식 필요
- Zapier보다 통합 수 적음
- 경쟁사 대비 UI 완성도 낮음
- 비개발자에게 가파른 학습 곡선
