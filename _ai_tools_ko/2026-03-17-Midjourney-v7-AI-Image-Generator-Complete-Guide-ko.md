# Midjourney v7: AI 이미지 생성의 최첨단

Midjourney는 항상 아티스트의 선택이었습니다 — 경쟁자보다 *미학*을 더 잘 이해하는 도구. 버전 7로 그 격차가 더 벌어졌습니다. v7은 사진 같은 디테일, 일관된 해부학, 극적으로 개선된 텍스트 렌더링, 그리고 취향을 학습하는 새로운 개인화 시스템을 제공합니다.

## Midjourney v7의 새로운 점은?

### 1. 사진 같은 인체 해부학

악명 높은 "Midjourney 손" 문제가 대부분 해결되었습니다. v7은 다음을 생성합니다:
- 자연스러운 비율의 정확한 손가락 개수
- 실감나는 피부 질감과 조명
- 물리적으로 타당해 보이는 자연스러운 포즈
- 이미지 변형 전반에 걸쳐 일관된 얼굴 특징

이것은 상업 사진작가와 광고주에게 가장 큰 품질 개선입니다.

### 2. 이미지 내 일관된 텍스트

AI가 생성한 텍스트는 악명 높게 뒤틀려 있었습니다. v7은 이제 다음을 렌더링할 수 있습니다:
- 도시 장면의 읽기 가능한 간판
- 읽기 가능한 텍스트가 있는 제품 라벨
- 명확한 제목이 있는 책 표지
- 자연스럽게 보이는 손으로 쓴 메모

모든 프롬프트에 완벽하지는 않지만, v6보다 극적으로 개선되었습니다.

### 3. 새로운 `--style` 파라미터

v7은 더 풍부한 스타일 어휘를 도입합니다:
- `--style raw` — 최소한의 AI 해석, 프롬프트에 더 가까움
- `--style expressive` — 더 창의적인 해석, 향상된 미학
- `--style cute` — 부드럽고 양식화된 미학
- `--style scenic` — 풍경과 환경 중점

### 4. 개인화 모드 (`--p`)

Midjourney가 이제 미학적 선호도를 학습할 수 있습니다:
1. 탐색 피드에서 시간이 지남에 따라 이미지 평가
2. 선호도가 개인 프로필 구축
3. 프롬프트에 `--p` 추가하여 취향 적용
4. 다른 사람들과 개인화 코드 공유

이것은 진정으로 변혁적입니다 — 프롬프트가 평균 사용자의 비전이 아닌 *당신*의 비전과 일치하는 이미지를 생성합니다.

### 5. 개선된 `--cref` (캐릭터 레퍼런스)

이미지 전반에 걸친 캐릭터 일관성이 이전에는 어려웠습니다. v7의 캐릭터 레퍼런스:
- 다양한 장면과 스타일에서 캐릭터 외모 유지
- 비사실적 캐릭터(일러스트, 애니메이션 등)에서 더 잘 작동
- 의상 세부 사항을 더 안정적으로 보존
- 한 장면에서 여러 캐릭터를 더 잘 처리

## v7을 위한 핵심 프롬프트 기법

### v7 프롬프트의 기본 구조

```
[주제], [행동/포즈], [배경], [스타일], [조명], [카메라]
--ar [비율] --style [모드] --v 7
```

**예시:**

```
도서관에서 책을 읽는 30대 일본 여성 초상화, 
햇빛이 드는 공간, 자연광, 라이카 85mm, 
얕은 피사계 심도 --ar 2:3 --style raw --v 7
```

```
비 온 뒤 포장 도로에 네온이 반사되는 미래적인 도쿄 야경, 
시네마틱 구도, 블레이드 러너 미학, 
부피감 있는 안개 --ar 16:9 --style expressive --v 7
```

### 필수 파라미터

| 파라미터 | 용도 | 예시 |
|----------|------|------|
| `--ar` | 화면 비율 | `--ar 16:9`, `--ar 1:1`, `--ar 2:3` |
| `--v 7` | v7 모델 사용 | 항상 포함 |
| `--style` | 스타일 모드 | `raw`, `expressive`, `cute`, `scenic` |
| `--q` | 품질 (속도 vs 디테일) | `--q .5` (빠름), `--q 2` (디테일) |
| `--chaos` | 변형 정도 | `--chaos 25` (0-100) |
| `--s` | 스타일화 강도 | `--s 250` (0-1000) |
| `--cref` | 캐릭터 레퍼런스 | `--cref [URL]` |
| `--sref` | 스타일 레퍼런스 | `--sref [URL]` |
| `--p` | 개인화 | `--p` |

### v7에서 이미지-투-이미지

레퍼런스 이미지를 업로드하여 생성 방향 제시:

```
/imagine [프롬프트] --iw 0.5 [업로드된 이미지 URL]
```

`--iw`는 레퍼런스 이미지가 출력에 미치는 영향을 제어합니다 (0.5 = 중간 영향).

## 고급 기법

### 스타일 레퍼런스 (`--sref`)

원하는 정확한 미학이 있는 이미지를 찾아 URL을 붙여넣기:
```
새벽의 아늑한 오두막 인테리어 --sref https://example.com/style.jpg --sref 300
```

`--sref` 뒤의 숫자는 스타일 영향을 제어합니다 (100-1000).

### 시리즈에서 일관성을 위한 프롬프팅

일관된 시각 시리즈(블로그 헤더, 소셜 포스트)를 위해:
```
// 고정 요소가 있는 기본 프롬프트:
"미니멀리스트 플랫 일러스트, [주제], 소프트 파스텔 
배경, 깔끔한 기하학적 도형, 그림자 없음
--ar 16:9 --style cute --s 100 --v 7"
```

각 이미지마다 `[주제]`만 교체; 다른 모든 요소는 일관성 유지.

### 네거티브 프롬프팅 (`--no` 사용)

원하지 않는 요소 제거:
```
황혼의 숲 장면, 마법 같은 분위기 --no 사람, 자동차, 전선 --v 7
```

**📸 상업 사진 대체**
스튜디오 없이 제품 라이프스타일 사진 생성: "대리석 주방 조리대 위의 프리미엄 커피 머그, 아침 빛, 탑뷰 사진"

**🎨 컨셉 아트 및 일러스트레이션**
게임, 영화, 책을 위한 캐릭터, 환경 또는 소품 디자인. v7의 미학적 품질은 전문 컨셉 아트에 필적합니다.

**📱 소셜 미디어 콘텐츠**
모든 게시물에 일관되고 브랜드에 맞는 이미지. 기본 스타일을 설정하고 주제를 변경합니다.

**🖼️ 마케팅 자산**
광고용 히어로 이미지, 블로그 헤더, 랜딩 페이지 배경 — 라이선스나 촬영 없이.

**📚 책 표지 디자인**
개선된 텍스트 렌더링으로 제목 배치를 포함한 완전한 커버 컨셉 생성.
