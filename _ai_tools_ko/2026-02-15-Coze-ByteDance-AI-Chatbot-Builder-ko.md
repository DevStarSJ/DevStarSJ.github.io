# Coze: 코드 없이 커스텀 AI 챗봇 만들기 (바이트댄스의 숨은 보석)

**커스텀 지식, 플러그인, 워크플로우를 가진 나만의 AI 챗봇을 코드 없이 만들고 싶으세요?** 바이트댄스(TikTok 만든 회사)가 개발한 Coze가 바로 그걸 가능하게 합니다. 그리고 가장 좋은 점? 놀라울 정도로 강력하면서 무료입니다.

## Coze란?

Coze는 "봇"이라 불리는 AI 챗봇을 노코드로 만드는 플랫폼입니다:
- 커스텀 지식 베이스 접근
- 외부 서비스 연결 플러그인 사용
- 직접 설계한 복잡한 워크플로우 실행
- Discord, Telegram, 웹사이트 등에 배포

Zapier와 ChatGPT가 만난 것 같은데, 대화형 AI 구축에 특화되었다고 보면 됩니다.

## Coze가 특별한 이유

### 1. 넉넉한 무료 티어
경쟁사들이 월 $20-100 청구하는 반면, Coze는:
- 무제한 봇 생성
- 여러 LLM 접근 (GPT-4, Claude 등)
- 무료 플러그인 사용
- 신용카드 불필요

### 2. 비주얼 워크플로우 빌더
드래그 앤 드롭 인터페이스로 복잡한 대화 흐름 설계:

### 3. 플러그인 마켓플레이스
봇에 연결 가능:
- 웹 검색과 브라우징
- 이미지 생성 (DALL-E, Stable Diffusion)
- 캘린더와 일정
- 코드 실행
- 데이터베이스
- 커스텀 API

### 4. 지식 베이스 통합
문서, 웹사이트, 데이터를 업로드하면 봇이 참조—응답을 내 정보에 기반시킴.

## 첫 번째 봇 만들기

### 1단계: 봇 생성
1. [coze.com](https://www.coze.com) 방문
2. 가입 (무료)
3. "Create Bot" 클릭
4. 이름과 설명 입력

### 2단계: 페르소나 설정
시스템 프롬프트로 정의:
- 봇이 누구인지
- 어떻게 응답해야 하는지
- 해야 할 것/하면 안 되는 것
- 톤과 성격

**예시:**
```
당신은 SaaS 회사의 친절한 고객 지원 상담원입니다.
친근하지만 전문적으로 대하세요. 가격, 기능, 문제 해결에 대한
질문에 답하세요. 모르는 것은 솔직히 말하고
담당자 연결을 제안하세요.
```

### 3단계: 지식 추가
봇이 참조할 파일이나 URL 업로드:
- 제품 문서
- FAQ
- 가격표
- 회사 정책

### 4단계: 플러그인 추가
봇에 필요한 플러그인 활성화:
- **Web Search**: 실시간 정보용
- **Image Generation**: 비주얼 생성용
- **Calculator**: 수학 연산용
- **Custom API**: 자체 서비스용

### 5단계: 워크플로우 구축 (선택)
복잡한 상호작용용:
1. Workflow 에디터 열기
2. 다양한 액션 노드 추가
3. 조건으로 연결
4. 흐름 테스트

### 6단계: 배포
배포 가능 플랫폼:
- Coze 내장 채팅 인터페이스
- Discord 서버
- Telegram 봇
- 웹사이트 임베드
- API 접근

## 더 나은 봇을 위한 꿀팁

1. **프롬프트는 구체적으로**: 모호한 지시 = 모호한 응답
2. **다단계 작업은 워크플로우 사용**: LLM에만 의존하는 것보다 제어력 좋음
3. **지식 베이스는 집중적으로**: 데이터 너무 많으면 느리고 부정확
4. **충분히 테스트**: 배포 전 프리뷰 기능 활용
5. **사용 기반 개선**: 대화 로그 확인하고 개선

## Coze vs 대안

| 기능 | Coze | GPTs (OpenAI) | Botpress |
|------|------|---------------|----------|
| 비용 | 무료 | $20/월 | 프리미엄 |
| 노코드 | ✅ | ✅ | ⚠️ 일부 코드 |
| 플러그인 | ✅ 다양 | ⚠️ 제한적 | ✅ 있음 |
| 워크플로우 | ✅ 비주얼 | ❌ 없음 | ✅ 있음 |
| 멀티 LLM | ✅ 가능 | ❌ GPT만 | ⚠️ 제한적 |
| 배포 옵션 | ✅ 다양 | ❌ ChatGPT만 | ✅ 다양 |

## 제한 사항

- **학습 곡선**: 워크플로우가 복잡해질 수 있음
- **바이트댄스 소유**: 일부 사용자는 프라이버시 우려
- **모델 가용성**: 모든 LLM이 모든 지역에서 이용 가능하진 않음
- **사용량 제한**: 무료 티어는 고사용량에 제한 있음
